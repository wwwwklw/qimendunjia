# 八门概述

八门是奇门**人盘**上的八个门，代表人事吉凶和行动方向。

## 金函玉镜补充

> 出自《金函玉镜奇门遁甲秘笈全书》卷二十二——八门吉凶诗诀。

### 八门吉凶诗诀（金函玉镜版）

**休门**：一一气盈室，富贵子孙田土吉，祭祀修营入宅基，赴官迁徙事周悉，产招逃绝入兴隆，北旺冬时数六一，南北婚姻有远亲，送来六畜增官秩。

**生门**：八八气盈星，凶煞皆降尊土精，因待女财人寄物，从兹致富子孙兴，三年定有贵儿产，出入外州泉货盈，嫁娶种萌并造作，消灾发福有奇灵。

**伤门**：气短数三三，寅卯旺方音角间，渔猎捕征搜索债，更宜赌博追亡还，官司口舌重丧至，六畜邅瘟火盗艰，夫妇血光灾眼症，三旬产厄祸力残，刑名死以兼疯疾，蛇虎伤人居不安。

**杜门**：四四星凶恶，木性时方寅卯泊，闭堤绝水事封培，追邪伐盗并勾捉，出亡逃难断欲宜，隐伏邀遮俱可托，去佞远藏埋闭藏，克绝阴私能久约，用动似防盗贼侵，官刑财散瘟疫伤，蛇伤雷打疥疮浓，焚廪人亡家退落。

**景门**：九九紫气盈，巳午旺南寅戌结，遣使上书能解危，求谋修造访寻谒，葬埋嫁娶吉中斗，给赏吏人如手捉，献策求名墀陛亲，举科文士藻文洁。

**死门**：二二凶星逆，戊己坤艮方位即，穿猎渔网刑戳宜，送丧吊死葬埋益，修营妨长及平房，忤逆重丧亡产憾，所求不利不宜行，动见败亡官落职。

**惊门**：无化气为逆，旺在庚辛申酉地，罗网张疑立狱讼，攻门刑击一齐到，逃亡掩捕得功能，市贾营修皆可忌，致讼虚惊疾疫兴，败囚军贼牛羊毙。

**开门**：六六气营奇，谒贵求谋利有为，立宅扦修官职进，外来财帛马牛肥，蜂蜜窖冶横财发，富盛子孙名利齐，金上庚辛秋月旺，奴田畜产贾商宜。

## 上元经补充

> 出处：《奇门遁甲上元经》 — 参见 [[奇门遁甲上元经（张大春）]]八门九门章

### 门盘与天干的关系

门与干皆为人盘，门为静、干为动，一阴一阳，备人事之全。门为人行之路、为通道。干和门构成了一对阴阳矛盾统一体——天干是动态的、物质性的、占据主导地位的；门是通道，必须由"门"而入。

### 八门命名的易学根据

八门的命名实质上根据**甲木周游不同宫位产生的强弱状态**而来：

| 门 | 宫位 | 甲木状态 | 命名缘由 |
|----|------|----------|----------|
| [[开门]] | 乾宫亥 | 长生 | 甲木运行轨迹起始，申被亥穿庚金受伤 |
| [[休门]] | 坎宫子 | 沐浴 | 甲木沐浴、庚金死地，修养生息 |
| [[生门]] | 艮宫寅 | 临官（禄） | 甲木禄地、庚金墓，生机最旺 |
| [[伤门]] | 震宫卯 | 帝旺（刃） | 阳刃所在，过犹不及，双面性 |
| [[杜门]] | 巽宫辰巳 | 衰/病 | 甲木由盛转衰，庚金长生 |
| [[景门]] | 离宫午 | 死 | 内中生气耗尽，外呈繁茂绚烂之景 |
| [[死门]] | 坤宫未申 | 墓/庚禄 | 甲木墓地+庚金禄地，至凶 |
| [[惊门]] | 兑宫酉 | 胎 | 弱甲逢旺庚，惊恐心态 |

### 门的旺衰辨析（核心观点）

张大春先生驳斥了三种错误观点：

1. **门依据月令衰旺**：错误——春季生门土旺衰破，难道春天不能赚钱吗？
2. **门有长生禄旺入墓**：错误——开门金墓于丑，临艮宫受宫生其实反吉；开门临巽宫虽"长生"但门宫相迫反凶。不能把天干周游十二宫的原理硬套在门盘系统
3. **门衰旺与九星相关**：错误——星是天象，作用在示象而非直接与门宫构成生克。天体对地球的影响主要体现在太阳与月亮

### 门迫——唯一需要注意的门之凶象

门立于地上，与地的关系最紧密。"地气不可犯，犯之必有灾殃"。门克宫即为**门迫**：
- 吉门克宫（门迫）→ 吉性大减
- 凶门克宫 → 凶顽之性更强
- 宫克门 → 影响远小于门迫，实际预测中可忽略不计

> 上元经的结论：门与月令、星辰没有直接关系，也无生旺墓之别。唯一需要注意的就是**门迫**。

## 奇门宝鉴补充

> 出处：《御定奇门遁甲·奇门宝鉴》（金志文点校）卷一·释义四十四则 — 参见 [[御定奇门遁甲奇门宝鉴（金志文点校）]]

### 释门（八门命名之五行理据）

五行之理，畏克喜生。甲木位于东，庚金位于西，东西相对，木之畏金也甚矣，故用奇以制庚。庚制而退休于坎，以就水之生，故正北为[[休门]]。休于北而对于南，有向明而治之象。景者大也，故正南为[[景门]]。水能滋木，金能生水。生则金气泄，泄则木气舒。故金水之间，西北为[[开门]]。有开必有阖，故对开为[[杜门]]，杜者，言阳气欲尽也。木既休于水，则水气畅，故水木之间，东北为[[生门]]。有生必有死，故对生为[[死门]]，死者，言落其实而取其材也。庚欲犯甲，甲既休于北，而对之者惟有卯木，不无受伤之患，此伤而彼亦惊，故正西为[[惊门]]，正东为[[伤门]]。

### 释迫（门迫定义）

迫者，门制其宫也。

| 八门 | 迫宫 |
|------|------|
| 开门 | 临三、四宫 |
| 休门 | 临九宫 |
| 生门 | 临一宫 |
| 景门 | 临六、七宫 |
| 伤门、杜门 | 临二、八宫 |
| 死门 | 临一宫 |
| 惊门 | 临三、四宫 |

凡此为迫，不利诸事。《经》云：「吉门被迫，吉事成凶。凶门被迫，凶灾愈甚。」值此惟宜安静，不宜举动。

### 释阴阳刑德开阖

阴刑阳德，阳开阴阖也。

| 节气 | 德所在 | 刑所在 |
|------|--------|--------|
| 冬至 | 卯 | 酉 |
| 夏至 | 酉 | 卯 |
| 春分 | 午 | 子 |
| 秋分 | 子 | 午 |
| 立春 | 辰 | 戌 |
| 立秋 | 戌 | 辰 |
| 立夏 | 未 | 丑 |
| 立冬 | 丑 | 未 |

凡刑德所在，三气共之。刑德不及寅申巳亥者，以四孟为四生，故不及也。

**五阳星**：蓬、任、冲、辅、禽——凡五阳星加时为**开**
**四阴星**：英、芮、柱、心——凡四阴星加时为**阖**

将兵以开阖分主客，以刑德定坐击：**阖为主、开为客，坐阳德、击阴刑**。

### 释三甲（孟甲仲甲季甲）

三甲者，孟甲、仲甲、季甲也。

| 三甲 | 直符 | 入局 |
|------|------|------|
| 仲甲 | 甲子、甲午 | 上元入局 |
| 孟甲 | 甲寅、甲申 | 中元入局 |
| 季甲 | 甲辰、甲戌 | 下元入局 |

三元三甲直符之时，举事视刑德为动静，将兵视刑德为战守，皆以**在门**决之。在门者，刑德在直使之门也。

- 德在门之时，宜动宜战
- 刑在门之时，宜静宜守

凡德在门之时，阳星加之为**尽开**，阴星加之为**半开**；刑在门之时，阳星加之为**半阖**，阴星加之为**尽阖**。

> 《经》云：「能知三甲，一开一阖。不知三甲，六甲尽阖。」

### 统宗版特点

- 统宗卷二八门所主详列各门**宜作之事**与**不宜作之事**，较卷一歌诀更详

- 强调「**吉门有气益吉，无气减吉；凶门有气益凶，无气减凶**」——门气旺衰影响吉凶程度

## 奇门启悟补充

> 出处：《奇门启悟》第一篇第四章"奇门信息类象"之"八门的万物类象" — 参见 [[奇门启悟（刘文元）]]

### 八门的万物类象（奇门启悟版）

#### 开门

- **宫位**：西北乾宫
- **五行**：金
- **门性**：大吉之门
- **易理**：开门属金，以天地肃杀之气，万物俱尽之时，何以谓之吉？开门之金，固是万物杀尽之时，却不知万物杀尽而有复生。开门属乾，乾中有亥，乾纳甲壬，金动水生，水生而生万物，故为资生万物之初，又为天门，所以吉也。
- **古云**：凡得开门，见官得理，做事欣然，觅人得见，大利上官，求财必遂，病人易妥，出行合伴，行人将遂，贸易开张，移徙欣然，谒贵利济，造作获安，百事悉吉，无不洞然。
- **类象**：开始、最初、原始、开创、创始人、开业、领导、法官、飞机、门面、办公室、官运、公开

#### 休门

- **宫位**：北方坎宫
- **五行**：水
- **门性**：大吉之门
- **易理**：休门之水固为至阴之地，实系宝瓶宫，万物以水为生煞而发摺于外，以水为死气收敛归根而藏精于内。子者，乃一阳复始之初，草木值此而萌动，返本还源之门，所以吉也。
- **古云**：「休门最好聚资财，牛马猪羊自送来。外口婚姻南方应，迁官职位坐京台。定进羽音人产业，居家安庆永无灾。」
- **类象**：休养生息、休息冬眠、退休之人、婚姻、谒贵、酒、油、盐、酱、醋、江、河、湖、海、水产养殖、休闲、肾、血液、流动性强、一切流动性性质的事物、一切液体

#### 生门

- **宫位**：东北方艮宫
- **五行**：土
- **门性**：大吉、至吉之门
- **易理**：生门艮卦，五行属土，少阳之方。艮者寅位，天开于子，地辟于丑，人生于寅，天气至此而三阳俱足开泰，从此而万物皆生。阳回气转，天地好生之情而广及万物，仁道生焉，所以为至吉之门。
- **古云**：生门临着土星辰，人财资旺各称情。子丑年中三七月，牛羊鞍马进门庭。蚕谷丝绵皆丰足，朱紫儿郎任帝京。南方商音田土进，子孙禄位至公卿。
- **应用**：宜上官、修造、嫁娶、求财、牧养，皆大吉
- **类象**：生产、生育、养殖、房屋、房地产、利润、利息、经营求财、活物、新生事物、生长、生生不息、诞生、生日、生存、种植、建造、制造、制作

#### 伤门

- **宫位**：东方震宫
- **五行**：木
- **门性**：凶门
- **易理**：伤门之木，正值春分之气，精液自内而出，发阳于外，以致根本泄之太过，所谓以外华而内虚，而不能胜其旁，况二月中嫩甲不能当霜露之寒，因谓之伤，所以凶也。
- **古云**：「伤门不可说，夫妇主灾遁。疮病行不得，折损血财牲。天灾人枉死，经年有病人。商音难得得，余事不堪陈。」
- **类象**：伤灾、疾病、跑动、响声、伤害、残疾、车辆、船只、打鬥、战争、赌博
- **应用**：凡伤门所临之宫，不利经商、出行、婚嫁，只宜索债、狩猎、捕捉盗贼、赌博取胜

#### 杜门

- **宫位**：东南方巽宫
- **五行**：木
- **门性**：小凶之门或中平
- **易理**：杜门阳木，时值夏季，发生于外而津液已泄，阳气亢极，一阴将至，木性至此而力屈，欲收敛而不能收敛，欲生旺而力已尽，又不能不泄其力以实其子，而待阴伏藏其子于坚密之处，恐有伤于子，故谓之杜门小凶。
- **古云**：杜门原属木，犯著灾祸频。亥卯未年月，遭官入狱迍，生离死别事，六畜也多瘟。跌打见脓血，祸害及子孙。
- **类象**：保密、技术、警察、公安、安全部门、不通、堵塞
- **应用**：杜门为藏形之方，最宜躲灾避难藏形隐匿，余事皆不利

#### 景门

- **宫位**：南方离宫
- **五行**：火
- **门性**：中平、小凶之门
- **易理**：景门夏令之气，万物壮旺将老之时，与死门坤宫相近，又为阳之盛气，天数至此時，将有杀物之情，虽主上明下亮之方，亦不全吉，惟利文书之事，因为次吉。
- **古云**：景门主血光，官符卖田庄。祸灾应多有，子孙受苦殃。外凶并恶死，六畜也见伤。生离并死别，用者须提防。
- **类象**：文书、字据、合同、景致、风景、血光、光明、火电、计划、前景、行情、眼睛
- **应用**：惟宜上书献策、奏对、选拔将士吉，余皆不利

#### 死门

- **宫位**：西南坤宫
- **五行**：土
- **门性**：大凶之门
- **易理**：死门之凶，天地令行大肆肃杀之威，草拂色变，木逢叶落，故为凶象。若得奇相助，面吊死刑捕捉畋猎之事，有得吉者，顺天之序而然也，不可弃。
- **古云**：死门之宿最为凶，人命逢之祸不轻，犯者年年财产退，更防孝服死人丁。
- **类象**：死亡、刑戮、战争、伤疤、疼痛、痛苦、压抑、死气沉沉、结束、最后、最终、死者、尸体、锁头
- **应用**：死门所临之处只宜吊丧、行刑等，余事皆不利

#### 驚门

- **宫位**：西方兑宫
- **五行**：金
- **门性**：凶门
- **易理**：惊门气肃，物数苍老，本无生气，固凶。但天地存好生之心，不欲杀尽而生蒜、麦，亦不得已而杀也。此门虽凶，若误词献诈，捕捉设疑、伏兵，皆吉，亦不可弃。
- **古云**：惊门主争讼，瘟疫死人丁，辰年并酉月，飞祸近门庭。惟宜讼事、捕捉、博戏吉，余皆凶。
- **类象**：口舌、官非、破损、争吵、惊恐、打官司、律师、演说、翻译、主持人、赌博游戏、设疑伏兵、蛊惑人心、辩论演讲、吃饭、能说会道、说大话、恐吓

### 奇门启悟版特点

- 刘文元版八门万物类象**详述每门的易理依据**，解释为何吉门为何吉、凶门为何凶
- 引用古籍歌诀（古云）作为佐证，传承性强
- 每门均有明确的**应用宜忌**（宜作之事与不宜作之事）
- 类象对应现代事物（如开门为飞机、办公室、官运；杜门为公安、安全部门等）
