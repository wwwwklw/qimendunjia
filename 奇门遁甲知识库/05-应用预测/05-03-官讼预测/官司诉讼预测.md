# 官司诉讼预测

## 定义与基本属性

官司诉讼预测是通过奇门遁甲判断诉讼双方的强弱、案件走势、判决结果以及律师水平等问题。以值符为原告、天乙（值符下临地盘之星）为被告，开门为法官，惊门为律师，景门为诉状——形成了一个完整的诉讼角色体系。

> **核心原则**：值符为原告主动方，天乙为被告被动方。开门为审判者，惊门为辩论，景门为文书。各方生克关系决定诉讼走向。

## 核心用神

| 用神 | 含义 | 特征 |
|------|------|------|

| [[天乙]] | **被告** | 被诉方、被动方、防守方 |

> **天乙说明**：天乙 = 值符落宫地盘之星。值符所临之宫的地盘星就是天乙。

## 取用神方法

### 第一步：确定双方用神
```
值符落宫 = 原告方
天乙落宫 = 被告方（值符下临地盘之星）
```

### 第二步：判断力量对比
1. **[[开门]]生[[值符（八神）|值符]]**：法官倾向原告（▲原告有利）
2. **[[开门]]生[[天乙]]**：法官倾向被告（▲被告有利）
3. **[[值符（八神）|值符]]克[[天乙]]**：原告占上风，可能胜诉
4. **[[天乙]]克[[值符（八神）|值符]]**：被告占上风，可能反诉成功

### 第三步：看律师能力
1. **[[惊门]]生何方**：律师对谁有利
2. **[[惊门]]旺相且临吉星**：律师能力强
3. **[[惊门]]休囚且临凶星**：律师能力差

### 取用流程
```
排盘 → 定位值符 → 定位天乙 → 对比双方生克 
     → 看开门偏向 → 看惊门律师 → 看景门文书 
     → 综合判断胜负应期
```

## 判断要点

### 胜负判断
1. **[[值符（八神）|值符]]旺相，[[天乙]]休囚**：原告赢面大
2. **[[天乙]]旺相，[[值符（八神）|值符]]休囚**：被告赢面大
3. **双方比和**：和解可能性高
4. **[[开门]]生何方**：法官偏袒何方

### 律师判断
1. **[[惊门]]生值符**：原告律师得力（▲原告有利）
2. **[[惊门]]生天乙**：被告律师得力（▲被告有利）
3. **[[惊门]]克何方**：律师对何方不利
4. **[[惊门]]临[[死门]]**：律师无能，帮倒忙

### 诉状/文书判断
1. **[[景门]]生值符**：原告诉状有力，证据充分
2. **[[景门]]生天乙**：被告答辩有利
3. **[[景门]]临[[杜门]]**：证据不足，文书有漏洞
4. **[[景门]]旺相**：证据链条完整

### 诉讼走向判断
1. **[[值符（八神）|值符]]临[[开门]]**：原告公开起诉，案件受理顺利
2. **[[天乙]]临[[开门]]**：被告主动应诉
3. **双方临[[伤门]]**：诉讼伴随强制措施（查封扣押）
4. **[[六合]]生合双方**：调解和解可能
5. **双方临[[死门]]**：案件漫长僵持

### 判决应期
1. **[[开门]]旺相之日**：开庭/判决日
2. **值符/天乙被克之日**：败诉方失利日
3. **[[庚格定应期|庚格]]出现**：诉讼转折时间点

## 实占要领

1. **值符为原告**：打官司必先定位值符（原告）和天乙（被告），这是双方对立的两个核心。
2. **开门看法官**：开庭前的研判——看开门偏向哪一方。
3. **惊门看律师**：律师好坏直接影响诉讼结果，不可忽视。
4. **景门看证据**：诉状和证据是诉讼的基础，景门不利则证据不足。
5. **生克判胜负**：谁旺相谁有优势，谁被克谁可能败诉——简单直白。
6. **六合看和解**：六合（合同、和解）生合双方则有可能庭外和解。
7. **注意角色**：如果是自己当原告，值符就是自己；如果是被告，天乙才是自己——求测人的立场要清楚。

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》书中实例，张志春老师用以讲解官司诉讼/劳动纠纷中主客策略的运用。

### 开悟之门补充：劳动纠纷案例——主客策略的经典运用

《神奇之门》实例六杜新会测劳动纠纷：李师傅首先主动上告了工厂领导（为**客**，主动进攻方）。经过预测判断**原告必胜**，被告虽然当时气势汹汹，但必然会泄气撤火。

基于此判断，为李师傅制定的策略却并非继续进攻，而是让他转为**被动策略**——等待对方来找自己，且要**见好就收、适可而止**。结果工厂不仅没有处分李师傅，反而**答应了他的全部条件**，连过去遗留长期没有解决的问题也给解决了。

> **核心决策智慧**：预测准确之后的决策更加关键。虽然预测原告必胜，但策略上选择"转客为主"、以被动应对主动，让对方自己退让——这种"以退为进"的策略比一味进攻效果更好。"该进则进，该退则退"，预测与决策配合才能取得最佳效果。

**奇门中主客判断的九条原则**（《开悟之门》总结）：
1. 动者为客，静者为主
2. 先动为客，后动为主
3. 积极主动为客，消极被动为主
4. 进攻为客，防守为主
5. 远者为客，近者为主
6. 外者为客，内者为主
7. 天盘三奇六仪为客，地盘为主
8. 甲、乙、丙、丁、戊五阳时利客；己、庚、辛、壬、癸五阴时利主
9. 星门反吟局利客，星门伏吟局利主

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》实例，张志春老师以此讲解诉讼预测中主客策略的决策方法。

### 开悟之门案例：测劳动纠纷（实例六——杜新会测李师傅）

- **时间干支**：见《神奇之门》第359-362页
- **奇门格局**：主客格局；李师傅首先主动上告了工厂领导
- **判断分析**：经过预测，原告必胜，被告虽然当时气势汹汹，但必然会泄气撤火；于是为李师傅决策，让他采取被动策略——等待对方来找自己，而且要见好就收，适可而止；奇门分主客原则：动者为客、静者为主，先动者为客、后动者为主
- **实际结果**：工厂不仅没有处分李师傅，反而答应了他的全部条件，连过去遗留长期没有解决的问题也给解决了

**要点**：预测后需要决策——"急则从神缓从门，动静先后分主客"；原告必胜时采取被动策略反而更能获全胜；见好就收、适可而止是诉讼决策的重要原则

## 金函玉镜补充

### 占词讼吉凶（卷八）

其法以惊、景二门主之。凡有词讼，看惊门乘旺相之气者，讼不息，景门亦然。若二门入墓，落空亡之宫者，主讼不成。

### 占问罪轻重（卷八）

以甲午辛为罪人，开门为问官。如开门落宫生甲午辛之落宫，问官怜悯不加罪。相比者，罪必轻。相冲克及凶格相乘，罪必重。若甲午辛落空亡，得奇门吉格相救者，罪必赦宥。

### 占囚禁（卷八）

以甲午为罪人，辛为天狱，壬为地牢，癸为天网。看日干之落宫下临甲午辛者，主凶禁。甲午辛落宫，下临地盘壬癸者，为误入天牢，待冲破之日，必出。若天盘壬癸之干下临地盘甲午辛者，为天网蒙头，主囚禁。又如天上星仪，落地盘墓库及壬癸者，终不出狱，竟作狱底之鬼。若落空亡之宫者，为空狱，不囚禁。

### 占官司牵连（卷八）

以甲辰壬为螣蛇推之，值符落宫下临甲辰壬、螣蛇，主原告牵连多人。乙奇落宫下临甲辰壬与螣蛇相并者，主被告牵连多人。开门落宫下临甲辰壬、螣蛇者，主问官牵连多人。甲辰壬、螣蛇落空亡之官者，不牵连。若见庚癸大格，纵牵连，不妨。

### 占被审责否（卷八）

以庚格决之。庚金所乘之宫来克值符宫者，主原告被责。克乙奇落宫者，被告受责。克六合宫者，干证受责。若庚金入墓及落空亡之宫，官怒不责。

### 占状词（卷八）

以景门、朱雀为状词。开门为官长，如景、惊二门乘旺相气，再有三奇吉格，主情词恳切。不被开门冲克者，必准。惊、景二门不得奇仪吉格，再与开门冲克者，主官嗔怒，不准；即准，反招罪责。若惊、景二门入墓，主情词不明，不准。惊、景二门落空亡者，主平空捏词，不准。开门入墓及落空亡者，官不动情，不准。

### 占官嘱托（卷八）

以开门为问官，值符为原告，乙奇为被告。值符落宫生开门宫者，主原告有托，乙奇亦然。二宫若被开门冲克，纵嘱托，官必不准。

### 占审官司得理否（卷八）

以开门所落之宫为问官，值符落宫为原告，乙奇落宫为被告，六合落宫为干证。开门落宫生值符者，官向原告，生乙亦然。生六合主听干证之言归结。相生者，得理。相克者，不得理。开门入墓，问官胡涂，审不明白。开门落宫亡，不审。反吟，须换官审。

### 占词讼（卷八）

以值符为原告，值符所落地盘所乘之星为被告。天盘星克地盘星，原告胜。地盘星克天盘星，被告胜。

## 奇门法窍补充

> **source:** [[奇门法窍（锡孟父子）]]
>
> 本节出自《奇门法窍》卷四「占词讼」「占兴讼」「占词状」「占争竞」「占讼狱」「占结案」「占罪轻重」「占囚禁」「占官讼」等章节，系（飞盘体系）飞盘奇门对官司诉讼预测的独特论述。

### 占词讼（飞盘体系）

以**直符**为原告，**天乙**为被告，**开门**为问官，**惊门**为讼师，以生克休囚决其胜负。

### 占兴讼（飞盘体系）

以**朱雀**为讼师，乘**景门**其讼必兴，反此不讼。

**又法**：以惊景二门主之，旺者必成讼，空亡则不成讼。

### 占词状（飞盘体系）

以**开门**为官长，**景门**为文状，生克休囚决之。

### 占争竞（飞盘体系）

以**直符**为先动之人（为客），**天乙**为后动之人（为主）：
- 钱财以**青龙**为主
- 田产五谷衣物以**生门**为主

### 占利息（飞盘体系）

以**庚丙**两家为构讼之人，**甲子戊**为主和之人，并**开门**落宫，以生克休囚决之。

### 占公私两事（飞盘体系）

以**巳**到宫为公事，**未**到宫为私事，看**时干**落宫，落于动宫不能归结。

### 占讼狱（飞盘体系）

以**丙**为本主，**庚**为被治之人，**开门**为官长，以生克旺相休废决之。

### 占带干证如何（飞盘体系）

以**六合**落宫决之。值符用天上之落宫，六合、天乙用地盘六合所在之宫生克决之。

### 占嘱托（飞盘体系）

以**开门**为问官，**值符**为原告，**天乙**为被告，生克决之。

**又法**：天乙宫为求托之人，直符宫为所托之人，直使宫为转托之人，以生克决其济否。

### 占被责否（飞盘体系）

以**庚格**、**刑格**、**击刑**并断之，以生克决其责否。

### 占结案（飞盘体系·庚格定结期）

端以**庚格**决之：
- **阳日**看天盘之庚下临何宫
- **阴日**看地盘之庚上乘天盘之干为结期

### 占罪轻重（飞盘体系）

以**甲午辛**为罪人。辛落地盘带**九天**、**天冲**者必发遣；若天庚加辛或罪人年命日干之宫者必正法。

**又法**：以本人日干宫上星旺门吉并有奇吉格者为轻罪。

**罪之轻重（卷四·占官讼）**：以加八门为主——门生我无罪，门克我有罪；门生彼无罪，门克彼有罪；乘旺来克罪重，休囚者罪轻。

### 占囚禁（飞盘体系）

以**甲午辛**为罪人，**天狱**、**天牢**、**天网**为入狱，专以干支落宫决之。以**日干**落地盘壬癸辛者主囚禁。

### 占捕获罪人否（飞盘体系）

以**开门**为长官，**直使**为公人，以有事之人年命日干，以生克落宫内外为迟速。

### 占起解罪人（飞盘体系）

以**天辛**为主，**直使**为解人。辛落休囚无碍，直使克辛者平安，再为开门宫克制尤妙。

### 占官讼（飞盘体系·五处验生克）

占词讼以**时干**为我，时干直符为中证，时干加门为听讼之官，时干加地盘奇仪为彼，奇仪同宫九星为彼干证。要在五处验其生克，以决胜负。

**官事完结**：以绝日为主，各时干加门属金则寅月日事绝之类。绝之例要论四时衰旺，旺则月论，衰则日论。伏吟主迟，反吟主反覆。

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第十四章 官讼预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

[[值符（八神）|值符]]落宫为原告，[[天乙]]宫为被告，[[开门]]落宫为法官，[[六合]]落宫为证据、证人，[[景门]]落宫为诉讼状、起诉书，[[惊门]]为辩护人、律师。

**原被告胜负判断**：
- 值符落宫克天乙落宫者 → 原告胜
- 天乙落宫克值符落宫者 → 被告胜
- 二宫比和 → 和平解决
- 值符宫生天乙宫 → 原告开始起诉，后来主动求和
- 天乙宫生值符宫 → 被告主动求和

**法官（开门）判断**：
- 开门落宫既克值符宫又克天乙宫 → 法官铁面无情，公平审判
- 开门宫生值符宫 → 法官偏向原告
- 开门宫生天乙宫 → 法官偏向被告
- 开门入墓 → 法官糊涂，审不明白
- 开门落空亡 → 不开庭审理
- [[反吟]] → 需重审或换法官审理

**诉状（景门）判断**：
- 景门落宫旺相、得三奇吉格者 → 情词恳切，不被开门宫冲克者必被受理
- 开门宫冲克景门宫 → 法官不受理
- 景门落空亡，又乘[[玄武]]、[[腾蛇|螣蛇]] → 所诉事情不真实
- 六合逢空亡 → 证据、证人不足或没有证据证人

**受贿判断**：
- 值符落宫临[[六仪（戊己庚辛壬癸）|戊]]、[[生门]]而生开门落宫者，开门宫又来克天乙宫，且六合宫逢空亡 → 证据不足，但原告贿赂法官，法官受贿而偏袒原告，不公平执法，加罪于被告
- 天乙落宫临戊、生门来生开门落宫，六合宫空亡，开门宫又来克值符宫 → 证据不足，但法官受贿于被告，不秉公执法，加害原告
- 开门宫受值符宫临戊、生门来相生，又受天乙宫临戊或生门来相生，并同时开门宫又冲克景门宫 → 法官吃完原告又吃被告，但总是拖延受理时间

### 奇门启悟案例1：为全艺娜女士预测离婚官司实例

- **时间干支**：己卯年壬申月辛亥日壬辰时 阴1局（转盘奇门）
- **值符值使**：值符甲申庚[[天任星]]，值使[[生门]]
- **求测背景**：1999年8月27日上午8点20分左右，全艺娜女士（1970年庚戌年出生）前来求测，坐离位，人显得比较压抑。问"婚姻出问题了，正在闹离婚，最终能否离成"。丈夫1965年8月13日出生
- **分析**：
  1. **断离婚根源在丈夫身上，丈夫在外面有女人了，并偷着藏私房钱，与丈夫相好的女人在过去与全艺娜相识**：乙、庚为夫妻之道，庚落乾宫，乙落巽宫，乾巽对冲，庚为全艺娜年命且临值符（凡是临值符的事情应验率很高）；休门主婚姻，现休门落巽宫为入墓，又被全艺娜年命落宫（乾）来冲克，故必应婚姻不顺闹离婚之事。丈夫年命乙巳，乙落巽四宫沐浴败地（乙木长生在午，沐浴在巳），巽宫地盘又落有丁奇（第三者女人），巽宫还落有休门（主婚姻、休息）→ 丈夫与另外一个女人（丁）暗中住在一起（休门）。休门所带暗干为戊（钱财），戊为休门之暗干，休门又入墓于巽宫 → 丈夫偷着藏私房钱。天盘丁奇落艮宫，艮宫地盘落有全艺娜年命庚，丁、庚同居艮八宫 → 与丈夫相好的女人在过去与全艺娜曾经相识。
  2. **断全艺娜要办离婚手续，但丈夫不同意离婚且矢口否认有外遇，全艺娜没有足够证据，协议离婚行不通只能走法律路，准备起诉丈夫**：全艺娜年命庚落乾宫来冲克丈夫年命乙所落之巽宫 → 想办离婚；巽宫落有休门（主息事、停止）又为水可化泄乾金之克 → 丈夫不同意离婚并回避；巽宫所乘之禽星上带癸水，与地盘形成癸加丁[[腾蛇夭矫|螣蛇夭矫]]凶格，癸为网，丁奇藏于巽宫地盘，天盘又有癸水之网笼罩 → 丈夫必然捂着盖着这件事；巽宫地盘有杜门（主保密），杜门为巽卦为兑卦之反卦，兑为说 → 说假话死不承认。六合为证据，今六合落离九宫来克全艺娜年命庚所居之乾宫 → 没有找到足够证据。值符为原告、天乙为被告，全艺娜年命庚落乾宫临值符必主动起诉（景门为起诉书亦落乾宫），天乙落坤二宫为被告方，坤宫地盘落有丈夫年命乙 → 丈夫必成被告，只能走法律这条路。
  3. **断夫妻有套房约90平方米是套间，产权写全艺娜名字，如真离婚丈夫也要房子产权的一部分但不要孩子，孩子最终由全艺娜抚养**：全艺娜坐离宫，离宫落有生门（房屋），离宫落有六合吉神 → 房子是套间；离宫数目为九 → 约90平方米；生门所带暗干为庚 → 房子产权名是全艺娜。丈夫年命乙落巽宫，巽宫生生门所在之离宫 → 丈夫也想要这房子。时干为孩子，时干壬落坤宫，丈夫年命乙落巽宫克时干壬所落之坤宫 → 丈夫不想要孩子；坤宫（时干壬所落之处）生乾宫 → 孩子愿意和全艺娜在一起生活；乾宫为庚加壬组合且临值符 → 全艺娜抚养孩子已成定局（凡临值符的信息组合都是必然要应验的事情）。
  4. **断丈夫不会主动提出离婚，希望全艺娜起诉提出离婚然后好向她提离婚条件；如果全艺娜不起诉丈夫也不会提出，只会沉默下去，时间久了全艺娜会沉不住气主动起诉成为原告**：丈夫年命乙乘[[天芮星]]落巽宫，年命巳亦在巽宫（年命乙巳）故为伏吟，凡逢伏吟则不会主动行事；巽宫又落有休门亦说明丈夫不会主动提出离婚。天芮星为坤卦，坤为纯阴，阴极必返阳，故最喜乾卦来与之相会，恰全艺娜年命庚落乾宫来冲克巽，乾宫又临值符 → 丈夫希望全艺娜主动起诉提出离婚。丈夫年命乙巳俱落巽宫，生生门所落之离宫 → 房子产权他必要一部分；巽宫克时干壬之坤宫 → 丈夫必不要孩子。丈夫乙乘芮星、休门落巽宫，芮星为坤主静，故不会主动提出离婚，只有被乾宫（值符）来相冲时才会动起来。全艺娜年命庚落乾宫，乾为纯阳卦极易动，又临值符，且格局为庚加壬移荡格 → 全艺娜最终会沉不住气而主动去起诉闹离婚。
  5. **断法院最终判决：房子总价的百分之四十判给男方，百分之六十归全艺娜所有，孩子由全艺娜抚养**：丈夫年命乙乘天芮星落巽四宫，巽宫落有休门，休门上乘暗干戊（钱财、财产）→ 房子总价的百分之四十判给男方。全艺娜年命庚乘天任星落乾六宫，任星与生门同气同属艮卦，艮为房屋，星主大门主小 → 房屋总价的百分之六十归全艺娜所有。乾宫格局为庚加壬，壬为时干代表孩子，乾宫临值符 → 孩子由全艺娜抚养。
- **结果**：全艺娜终究没有坚持住，还是主动起诉了，法院最初给予了调解。最后全艺娜还是坚持要离婚，最终法院判决房子总价的百分之四十归男方，百分之六十归全艺娜，孩子判给全艺娜抚养，男方每月付给一定数目的孩子抚养费。其判决结果与奇门预测结论完全一致。

### 奇门启悟案例2：杨丽测官司胜负预测实例

- **时间干支**：辛巳年丙申月乙卯日壬午时 阴8局（转盘奇门）
- **值符值使**：值符甲戌己[[天柱星]]，值使[[惊门]]
- **求测背景**：2001年8月20日中午12点20分左右，杨丽女士（1970年阴历八月二十五日下午四点多钟出生）前来求测，坐离位。因剖腹产伤口愈合不好遵医嘱在家多休息，上班后被单位以未按规定时间回来上班为由划入下岗人员。想通过法律手段起诉单位领导，问官司能否打赢
- **分析**：
  1. **建议杨丽找医生开病假条，然后拿着病假条去找妇联，妇联会帮她出头讨公正；如果妇联出面也解决不了问题，可通过法律起诉单位领导，最终肯定胜诉，单位必然恢复杨丽的工作**：取坎宫为妇联——坎宫落有[[天辅星]]、[[死门]]又乘[[六合]]，死门为坤卦（坤代表众多、妇女），天辅星为巽卦（亦代表女人，又巽为绳），六合主团体，组合起来可以代表妇女联合会；坎宫地支为子，子为神后亦代表妇女。丁奇乘[[天芮星]]落震三宫来生杨丽年命庚落之离宫——丁为字条，芮星为病神，组在一起便是病假条。代表病假条的丁奇乘芮星落震宫来生杨丽所坐之离宫 → 建议找医生开病假条以做未来开庭打官司时的证据之一；代表妇联的坎宫来生丁奇所落之震宫 → 妇联对杨丽所开出的病假条很重视；开门代表公正，今开门亦与丁奇同落震宫被坎宫（妇联）来相生 → 妇联会帮助杨丽讨公正。从日柱乙卯来查坎宫为空亡，由于六合落坎宫代表妇联今遇空亡恐有闪失 → 妇联出面有可能解决不了问题，所以才建议杨丽走法律这条路。今值符落巽宫代表原告，天乙（天辅星）落坎宫代表被告。杨丽年命庚落离宫，本人亦坐离宫，并且受值符所落之巽宫来相生 → 杨丽适合作为原告来起诉单位领导；被告宫（坎）生原告宫（巽）→ 原告必胜。开门代表法官，今开门、太岁辛均落震宫来生杨丽年命庚及其所坐之离宫 → 杨丽受到法官及社会各界的同情及相助，必能打胜这场官司。开门代表工作、岗位等信息，今开门落震宫来生杨丽年命庚所落之离宫 → 杨丽最终能够恢复工作重新上岗。
- **结果**：杨丽女士找到当地妇联将情况做了如实反映。妇联出面找杨丽单位有关领导交涉此事，让单位领导拿出有关文件来，单位领导拿不出有效的文件只好回避，但又不给解决问题。最后妇联建议杨丽女士用法律武器来维护自己的合法权益，起诉单位领导。在妇联的介入情况下，法院很快便接手了这个案件。不久便开庭审理，最终宣判原告杨丽胜诉，单位必须在一个一个月内安排杨丽的工作，而且要求给安排的工作岗位不能比原来的岗位差。杨丽终于在妇联的帮助下，通过法律这个有力的武器，维护了自己的合法权益，同时也维护了妇女儿童的合法权益不受侵害。

**要点**：刘文元先生在本章提供了完整的官司诉讼用神体系（值符原告、天乙被告、开门法官、六合证据证人、景门诉状、惊门律师），并独创性地提出"法官受贿判断三式"（原告贿赂、被告贿赂、两头通吃）的细致诊断法；取坎宫（天辅星+死门+六合+子）代表妇联的取象方法展示了奇门符号组合对应现代机构的灵活思路；空亡的辩证使用——六合（妇联）落空亡断"出面有可能解决不了问题"但最终仍助杨丽胜诉，说明空亡只是阶段性失力而非全盘无用。
