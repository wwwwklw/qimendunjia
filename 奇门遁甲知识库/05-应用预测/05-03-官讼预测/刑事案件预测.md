# 刑事案件预测

## 定义与基本属性

刑事案件预测是奇门遁甲中用于判断犯罪类型、案犯特征、侦破进展及破案应期的应用。以天蓬星（抢劫杀人）和玄武（小偷）为案犯分类用神，白虎和伤门为公安机关，庚格为破案应期的关键判断依据。

> **核心原则**：天蓬为凶犯（强盗、杀人），玄武为小偷（盗窃）。白虎伤门为公安武装力量。逢庚必变，庚格出现即有破案时机。

## 取用神方法

### 第一步：判断犯罪类型
```
看天蓬星状态 → 旺相且克日干/时干 → 暴力犯罪
看玄武状态   → 临日干/时干     → 盗窃/诈骗
```

### 第二步：判断案犯特征
1. **[[天蓬星]]所临宫位**：案犯所在方位
2. **[[玄武]]所临宫位**：小偷/诈骗犯所在方位
3. **案犯所临八神**：判断案犯身份特征
4. **案犯所临八门**：判断作案手段

### 第三步：判断案件进展
1. **[[白虎]]/[[伤门]]生[[时干]]**：公安在行动，案件有进展
2. **[[白虎]]/[[伤门]]克[[天蓬星]]/[[玄武]]**：公安克制案犯，即将破案
3. **[[天蓬星]]/[[玄武]]生[[白虎]]/[[伤门]]**：案犯自投罗网，或已落网
4. **案犯空亡**：案犯已逃离

### 取用流程
```
排盘 → 看天蓬星/玄武位置 → 判断犯罪类型 
     → 看白虎/伤门位置 → 看公安与案犯生克 
     → 看庚格 → 判断破案应期
```

## 判断要点

### 犯罪性质判断
1. **[[天蓬星]]旺相且临凶门**：重大暴力刑事案件（抢劫杀人）
2. **[[玄武]]旺相且临[[杜门]]**：技术型盗窃（如网络犯罪）
3. **[[天蓬星]]+[[玄武]]同宫**：团伙作案，有组织犯罪
4. **[[天蓬星]]临死门**：案件有人员死亡
5. **[[玄武]]临开门**：案件已公开，受害人多

### 案犯方位判断
1. 天蓬星/玄武落宫方位 = 案犯所在/逃往方向
2. 天蓬星/玄武临[[九天]]：案犯逃往远处
3. 天蓬星/玄武临[[九地]]：案犯潜伏在本地区
4. 天蓬星/玄武空亡：案犯已脱离追查范围

### 侦破进展判断
1. **[[白虎]]克[[天蓬星]]/[[玄武]]**：公安占上风，能破案（▲吉）
2. **[[天蓬星]]/[[玄武]]克[[白虎]]**：案犯嚣张，破案困难（▼凶）
3. **[[伤门]]生日干**：公安主动出击，对求测人有利
4. **[[开门]]临白虎**：案件已公开侦办
5. **[[开门]]临伤门**：公开抓捕行动

### 破案应期判断（庚格）
1. **[[庚格定应期|庚格]]出现**：破案的最强时间信号
2. **白虎克天蓬/玄武之日**：抓捕成功日
3. **天蓬/玄武填实空亡之时**：案犯现身日
4. **马星到白虎宫**：抓捕行动日

## 实占要领

1. **天蓬武玄分清楚**：天蓬星是暴力犯罪（杀人抢劫），玄武是盗窃诈骗——定准性质后再展开判断。
2. **白虎伤门为公安**：公安的行动力量看白虎（威慑力）和伤门（行动力）。
3. **生克定胜负**：白虎能克案犯则能破案，案犯克白虎则破案困难。
4. **庚格看破案**：[[庚格定应期|庚格]]是刑事案件预测的"金钥匙"——逢庚必破。
5. **开门看公开程度**：案件是秘密侦办还是已对公众公开，看开门临何处。
6. **空亡看逃脱**：案犯空亡 = 暂时脱逃，填实之日是抓捕时机。
7. **八神看身份**：案犯所临八神可辅助判断其身份（如太阴为隐秘、螣蛇为虚诈）。

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》实例，张志春老师以此讲解刑事案件预测中内外盘断远近、用神旺衰、庚格定应期等核心方法。

### 开悟之门案例：测北京抢银行大案（实例四）

- **时间干支**：1996年6月3日上午8点多发案，丙子年癸巳月辛未日壬辰时，阳3局，甲申旬（午未空）
- **奇门格局**：年干丙在8宫，月干癸在3宫，日干辛在1宫，时干壬在6宫；天蓬星落8宫（案犯）；白虎和值使死门为公安，分别落在3、4宫；兑7宫庚+壬时格；坤2宫庚上之干为丁；马星寅在艮8宫
- **判断分析**：内盘、外盘和日干、时干一内一外，确定不会很快破案，慢断年月，但因有庚+壬时格又主快，综合断月；天蓬星落8宫为土在巳月为相地（案犯尚强）；白虎在3宫、死门在4宫，月令巳火，3/4宫木处休地，但死门在4宫对应辰巳月当令，公安仍能克案犯；值使死门落巽4宫含3、4、5、8四个数，断至少三个月后破案；按辛未日为阴日，"阴日看庚上之干"，坤2宫庚上之干为丁，应断当年丁月——丁酉月（农历八月）
- **实际结果**：6月3日发案，9月9日（刚入丁酉月）破了案，三个月多一点

**要点**：内外盘定快慢——内盘主快外盘主慢；庚格出现提示可破但需参考其他条件；"阳日看庚下之干，阴日看庚上之干"定破案应期；值使门落宫数判断大致期限

## 金函玉镜补充

### 占捕捉（卷七）

以六合为逃人，以伤门为捕人（全以八门为主，以八门为人盘，主人事也）。如六合宫克伤门宫，不可得，反此易得。伤门宫生六合宫，捕人不实力，必受其赂。伤门、六合同宫，两相通同。值年月日时格，则可获，天网低亦然。

### 占失物（卷九）

以日干落宫为失主，时干落宫为失物，各以类推之。看时干落宫乘旺相气来生日干落宫者，仍得。反吟者，亦得。落空亡、墓、绝之宫，不得。

各宫所主之物：干为金锁、宝物、铜铁、圆圈之物，又为帽缨、为马。坎为水晶、珍珠、笔墨、毛发细软之物，又为猪。艮为山、玉石、器皿、蹬靴之物，又为牛、犬、猫。震为车、船、木器、碧色衣服之物，又为驴、骡。巽为丝紬、缎布细软之物，又为彩色细长成队之物。离为文明图书、手卷、字画、印信、文劵、彩禽、暖衣之物，又为马。坤为铜铁、鼓磬、釜中空有声、象牙之物，又为牛羊。兑为金银、首饰、有口对衿之物，又为羊鸡、飞禽。看其有气，便为活生之物，无气即为死囚废旧之物。

### 占何人盗（卷九）

以蓬元为盗主，神乘旺相气，又得奇门吉格者，乃是贵人为盗。不乘旺相气，不得奇门吉格者，乃是小人为盗。仍配卦以决之：干为老阳，震为长、壮，坎为中男、始壮，艮为少男、童年，坤为老妇，巽为长女，离中女，兑少女。在内为亲近之人，在外为他人。

### 占捕盗贼（卷九）

刦人财物者，谓之盗；杀人取财者，谓之贼。以天蓬为大贼，玄武为小贼，勾陈为捕盗之人，杜门为捕获之方，皆以天盘主之。勾陈落宫克蓬元之落宫者，捕之必获。若蓬元克勾陈之宫，主贼旺，捕人不敢获。蓬元与勾陈宫比和者，必捕人通同为盗。勾陈、蓬、元同宫，必捕人为盗。蓬、元宫生勾陈宫者，捕人受贿，纵之不捕。总以庚格主之，年格年获，月格月获，日格日获，时格时获，不格不获，杜门有格必获，否亦不获。

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第九章 刑事案件预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

[[天蓬星]]落宫为抢劫杀人、奸情杀人、重大贪污受贿、黑社会犯罪等重大案犯；[[玄武]]落宫为小偷小盗、流氓强奸、轻微经济犯罪之人。

**作案方法判断**：
- [[天蓬星]]、[[玄武]]宫临[[伤门]]，或伤门宫生天蓬、玄武宫者 → 用车作案
- 天蓬星、玄武宫临[[景门]]或景门宫生天蓬、玄武宫者 → 使用枪支、火药、各种电器设备作案
- 天蓬星、玄武宫临[[腾蛇|螣蛇]] → 用绳索、链条等作案，或用手掐人致死等
- 天蓬星、玄武宫临甲、乙、伤门、[[杜门]] → 案犯用木棍将人打伤致死等
- 天蓬星、玄武宫临乙奇 → 案犯用各种药物将人致晕昏迷或毒死等

**作案人远近**：天蓬星、玄武落内盘，为本地近处人或本单位内部人作案；落外盘，为外地或外单位人作案，或外地流窜犯作案。[[六合]]为逃犯，杜门宫为藏匿方向。

**尸首信息**：[[死门]]代表尸首。死门临甲子戊，因钱财之事而丧命；死门临乙、庚、丁、壬、丙、桃花者，为奸情所杀而致命；死门乘太阴、六合等，为有不可告人之事被杀、灭口；死门宫临辰午酉亥全者，为被逼自杀身亡；死门宫临乙奇为服药身亡。

**破案时间**：以[[伤门]]、[[白虎]]、值使门落宫为公安捕盗之人。捕盗宫旺相，冲克天蓬、玄武宫者，案件必破；天蓬、玄武宫生捕盗宫者，案件易破；局中有年、月、日、时格者，案件易破，不格者难破。一般情况下，逢年格年内破案，月格月内破案，日格当日破案，时格当时立即破案。

### 奇门启悟案例1：为李贺凌先生预测户国凤女士失踪

- **时间干支**：壬午年戊申月庚申日辛巳时 阴8局
- **值符值使**：值符甲戌己[[天柱星]]，值使[[惊门]]
- **求测背景**：2002年8月20日上午10点左右，北京李贺凌（1967年生）来电求测女友户国凤（1962年生，属虎）失踪6天，头两天手机铃响无人接，第三天手机关机联系不上
- **分析**：
  1. **断户国凤凶多吉少，可能已经死亡**：户国凤年命壬寅，壬落震三宫死地（壬长生在申，死在卯，卯为震），地盘壬落巽四宫为入墓，巽宫又落有[[死门]]，故断凶多吉少。又[[时干]]辛落离宫，克[[日干]]庚所落之兑宫，也是人难回之象。
  2. **断不是自杀也不是仇杀，而是被人劫财遭杀害**：年命壬乘[[天辅星]]落震宫，天地盘没有组成自刑信息，故不是自杀。庚为仇人，庚乘[[天心星]]落兑宫本为旺相，又来冲克年命壬所居之震宫，似乎是仇杀，但兑宫落有吉门[[休门]]，休门旺相之水可化泄兑宫之旺金，又休门主休息，故也不是仇杀。[[天蓬星]]为杀人犯，现天蓬星与[[生门]]同落乾宫，生门所带暗干为戊，乾宫克年命壬所落之震三宫，劫财杀人之象十分明显。
  3. **断尸首被隐藏在东南方向14里或40里的地方，在一条河边的隐蔽处，上面盖满乱草。凶手是年轻人，动机是劫财**：死门落巽四宫，阴遁巽宫为外为远，故断东南方向14里或40里。巽宫地盘落有壬，壬为河流，地盘主隐藏，壬到巽宫为入墓，入墓亦主隐藏，故断河边隐蔽处。巽宫天盘落有乙木，乙木为草，故断上面盖满乱草。蓬星与生门同落乾宫，生门为艮，艮为少年，故凶手是年轻人。生门为钱财，暗干戊亦主钱财，故杀人动机是劫财。
  4. **断户国凤平时喜欢穿高档名牌服装，交往的人多而复杂。凶手认识户国凤，曾与她有过来往**：年命壬乘天辅星与[[景门]]同落震宫，景门主漂亮、名牌，天辅星主服装，壬为太岁主高档。震三宫落有[[六合]]，六合主交往。又月干戊落坎宫，坎宫落有玄武、伤门，坎宫亦来生年命壬所居之震三宫，故交往接触的人多而复杂。年命壬寅，寅为艮卦，天任星、生门亦为艮，今天蓬星与生门（寅）同落乾宫，说明凶手认识户国凤。
  5. **断案子最后一定能破获，在今年寒露节以后（10月8日），一个月内凶手必被抓获**：值使门、伤门代表公安捕盗之人。现值使惊门落离九宫，克天蓬星所落之乾宫。又天蓬星所落之乾宫生伤门所落之坎宫，说明案子一定能破获。六合代表证据，今六合与年命壬同落震三宫，来生值使惊门所落之离九宫，公安人员完全掌握了足够证据。由于户国凤是失踪隐藏状态，藏之者必待冲方能出现。现年命壬落震宫，被地盘值使、值符宫（兑）所冲，兑宫上乘天干庚，故必应当年庚戌月。又巽宫地盘亦落有年命壬，巽宫还落有死门，只有到了"戌"这个时空点上，戌冲辰（巽），才能将其冲出。
- **结果**：2002年西历10月9日下午，案子破了。户国凤确实被人杀害，尸体被藏在东南方约20公里的河边，上边盖了很多乱草，与预测情况几乎一致。杀人犯是一个专门以杀人劫财为主的团伙，共17人，多数从东北吉林、黑龙江来到北京。案发当日户国凤因心情不好喝了不少白酒，案犯几人来酒楼喝酒，发现户国凤有些醉了便开车接走，洗劫现金两万多元及银行卡，后怕举报便合伙杀死，用汽车运往东南方40里左右的河边掩埋。事过两月案犯再次作案时败露被抓获。寒露节后一个月内凶手被抓，完全应验。

### 奇门启悟案例2：为董良先生预测能否抓到逃逸司机

- **时间干支**：乙酉年丁亥月丙午日戊戌时 阴3局
- **值符值使**：值符甲午辛[[天英星]]，值使[[景门]]
- **求测背景**：2005年11月18日晚8点40分左右，安徽易友董良来电求测其弟弟当晚7点多被车撞，昏迷送医抢救，肇事司机逃逸，问有无生命危险及能否抓住司机（弟弟1970年农历三月二十一日早8点多出生）
- **分析**：
  1. **断弟弟恐怕抢救不过来了，伤得太重，流血过多，肋骨也被撞骨折**：董良弟弟年命庚乘[[天蓬星]]凶星与[[死门]]同落兑七宫，兑宫又落有[[白虎]]凶神。兑宫格局为庚加癸大格，极凶之格，并且兑宫与值符震宫相冲克。又当日为丙午日，丙火长生在寅，死在酉（兑），故兑宫既落有死门，又临日干之死气，且又临白虎凶神、庚加癸大凶之格，其死亡信息甚为明了。蓬星为坎，坎为血，兑宫地盘落有癸，癸亦为血，故断流血过多。庚落兑宫为羊刃宫（庚羊刃在酉），庚主骨，兑主骨亦主肋部，故断肋骨骨折（羊刃）。
  2. **断肇事车速度很快，估计时速140公里左右，肇事后司机向东南方向快速逃走，车没有车牌或挂的假车牌，汽车已开往外地**：[[伤门]]落巽宫，代表肇事车辆，巽为风主快。又巽宫落有[[九天]]，也代表车速很快。巽宫数目为四，故断时速140公里左右。巽为东南方向，巽宫地盘藏有杜门，杜门主隐藏、逃逸，故断肇事后司机向东南方向快速逃走。[[景门]]代表车牌，景门落坤宫，被伤门所居之巽宫来克，故断肇事车辆没有车牌。又景门之坤二宫落有[[玄武]]，玄武主欺骗、造假，故断或者是挂的假车牌。
  3. **断这件事也不能全怪肇事司机，弟弟本人也有责任，出事前喝了不少酒。这个案子很难破**：伤门落巽宫又乘九天，巽为风，车速很快。弟弟年命庚落兑宫，兑克巽，说明是弟弟主动去克车辆，当然其本人也有责任了。庚乘蓬星落兑宫，蓬星主贪杯，兑为酉亦为酒，兑又为口为吃喝等信息，兑宫落有死门亦主弟弟喝酒喝多了，人处于醉态，因此才出事。取伤门所落之巽四宫代表逃逸的司机，值使景门代表公安、交警部门。现伤门所落之巽四宫克值使景门所落之坤宫，故案子很难破获。
- **结果**：第二天早晨8点多钟，董良再次打来电话印证：弟弟因伤得太重，抢救无效，在半夜23点30分去世了。医生从血液与尿检中查出他喝了很多酒。从出事那一天起到现在（2007年11月20日），已有两年多时间，案子一直没破，肇事司机依然逍遥法外——"案子很难破"的判断完全应验。

**要点**：年命落宫逢死门、白虎、大格凶神并临日干死地，死亡信息明确；伤门落宫代表肇事车辆，巽为风主快，九天亦主快；景门代表车牌，被克或临玄武则车牌有问题；伤门宫克值使门（公安）宫，案子难破。
