# 射覆占法

## 定义与基本属性

射覆是古代一种用数术猜物的游戏，亦是数术学最高境界的具体展现。所谓射覆，即测试者将事先准备好的各种物品，隐藏到指定的地点、环境、容器中，然后由数术功底较深的术士通过预测，将隐藏的物品测中，此过程便称之为射覆。

> **核心原则**：值使门为时柱干支气数之集注、总汇。来人凡有所求，其意尽显于时柱干支之中。故射覆着重看值使门落宫，以定物品之形态、性质、颜色、数目等。

## 判断方法

### 一、值使门定物品形态（活物死物）

1. **值使门落宫值旺相，又临生气者**：必为**活物**
2. **值使门落宫值休囚死墓，又临死气者**：必为**死物**

### 二、值使门落宫位定物品形状

| 位置 | 形态 |
|------|------|
| 四孟位（寅申巳亥） | 主圆形物 |
| 四仲位（子午卯酉） | 主方形物 |
| 四季位（辰戌丑未） | 主尖形而有破碎之物 |

### 三、值使门旺衰定物品质地

| 旺衰 | 形态 |
|------|------|
| 旺 | 圆而软 |
| 相 | 方而嫩 |
| 死 | 直硬破碎 |
| 囚 | 细碎 |
| 休 | 体轻不全 |
| 旺相 | 新而完 |
| 囚死 | 旧而缺 |

### 四、值使门临十二长生定物品新旧

| 长生 | 物品状态 |
|------|---------|
| 长生 | 物新而小 |
| 沐浴 | 物润泽 |
| 冠带 | 物枯稿 |
| 临官 | 物新而壮 |
| 帝旺 | 物近贵可用 |
| 衰病及胎养 | 皆主废闲故物 |

### 五、值使门临地支定物品特征

| 地支 | 物品特征 |
|------|---------|
| 子午 | 物有眉目 |
| 卯酉 | 物有口肠 |
| 寅申 | 物有毛角 |
| 巳亥 | 物有面貌 |
| 辰戌 | 物有手足 |
| 丑未 | 物有孔窍 |

### 六、值使门五行定物品质地

| 五行 | 物品质地 |
|------|---------|
| 水 | 质地柔软，为近水之物。壬为水物、扁形物；癸、子为有爪、有窍之物 |
| 火 | 质地虚锐之物，或上尖虚心烟火之物。丙、午主物有手足；丁、巳主偏斜有光彩之物 |
| 木 | 直长屈曲草木之物。甲、寅主丛杂之物，似有手足、文色斑点；乙、卯主细长，似有口腹之物 |
| 金 | 质地刚硬之物，或方圆金铁炉冶之物。庚、申主物有四角，或空心物品；辛、酉似有头目，多头绪，或尖圆 |
| 土 | 质地厚重之物，或圆块泥土之物。戊多刚破，或有皮角；己多细碎 |

### 九、虚实判断

1. **值使门为火神**：其物必虚
2. **值使门见水神**：其物必实
3. **值使门落宫有水有火**（如景门落坎宫，或休门落离宫）：其物必半虚半实

### 十、颜色判断

| 类别 | 颜色 |
|------|------|
| 十干颜色 | 甲青、乙碧、丙赤、丁紫、庚白、辛栗、壬黑、癸墨绿、戊黄、己绛 |
| 十二地支颜色 | 子黑、午赤、卯青、酉白、申黑白、巳斑点红、亥淡青、辰戌丑未纯黄 |
| 兼色 | 甲己半青黄，乙庚兼碧绿，丙辛带赤白，丁壬暗惨黑，戊癸灰黄色 |

### 十一、数目判断

> 占数目：甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戌五，巳亥常为四。

## 实例分析

### 奇门启悟案例一：酒桌射覆显易道神威（孙作家包中钥匙）

- **时间干支**：乙酉年壬午月丙寅日丁酉时 阳三局
- **值符**：甲午辛天心星  **值使**：开门
- **格局**：乾宫天盘天冲星、伤门、六合，格局戊加辛青龙折足；乾宫空亡（丙寅日戌亥空）
- **分析**：
  孙作家坐乾位，乾宫天盘落天冲星、伤门、六合，格局为戊加辛青龙折足。乾宫五行属金，地盘辛亦为金。从求测日丙寅查空亡，戌亥空，即乾宫空亡。乾主圆形，逢空亡即为圆环；地盘辛金为精小金属物品；冲星、伤门为震卦，震为卯，卯为门；六合为卯，亦为门之信息，六合主数目多——综合分析：圆形金属圆环上带有精小金属物品，与门有关，必为**钥匙**。
  
  奇门中戊代表钱财信息。乾宫冲星带天干戊，伤门亦带暗干戊，冲星数目为3，伤门数目亦为3，星主大数，门主小数，组合为33；乾宫于夏季午月走死地，且逢空亡，故钱数必不多，断有**330元**人民币。
  
  后孙作家檔包被柳女士拿到离位，离宫天盘天心星、开门、值符，离主虚主空（离中虚），组合仍是圆形金属物品上带精小金属物辛金；开门准确指出该物品具有"开门"功能；柳者卯也，卯为门户——更加肯定包内为钥匙。
- **结果**：包内果然有一串钥匙；现金经清点为332元，与所断330元几乎一致，应验如神。

### 奇门启悟案例二：巧测易友包中所藏之物（丛展包中9本经书）

- **时间干支**：壬午年乙巳月丁酉日丁未时 阳二局
- **值符**：甲辰壬天心星  **值使**：开门
- **格局**：艮宫天心星（带壬）临景门，值符天心星落艮宫
- **分析**：
  **断丛展早晨8点前后打出租车去庙上拜佛**：8点属辰时，丁酉日辰时为甲辰时。丛展年命戊戌均落乾宫，乾宫为日柱马星宫（巳酉丑马星在亥）。乾宫落伤门，伤门主车辆；戊为钱财，戊到乾宫为入墓——必是花钱打车。乾宫地盘壬，正应甲辰壬之信息。乾宫被巽宫所冲，巽主辰巳，辰为阳主动，故应辰时（8点多）。乾宫戌亥间为天门，戌亦代表寺庙；天心星主佛道；天芮星为信徒访道之人——断其打车去庙上拜佛。

  **断中午在庙里吃斋饭**：丛展坐离位，离宫天冲星、六合、开门。中午为丙午时，应离宫地盘丙。开门属金，天冲星属木，金克木为财，财主饮食；冲星为木主素食，六合亦为木又主众多——断吃斋饭。丛姓属木，丛有草木含义，离宫主午，故断丛展中午在庙里吃斋饭。

  **断包里装有经书6本或9本**：值符天心星落艮宫，景门亦落艮宫。天心星主佛，壬代表大智慧（壬为水，水主智，壬为阳，主大智慧），景门为书为经文，景门所带暗干为丙火主大光明。艮卦代表包，故以艮宫判断包中装有从庙里带回的经书。景门为经书，带暗干丙（阳火主大光明）。艮宫天心星上乘壬，壬数为6（丁壬卯酉六），壬数亦为9（十天干之序）——故断包中装有6本或9本经书。
- **结果**：丛展当面拉开包拉链，里面露出很多经书，数了一下正好是**9本**。丛展当天早晨8点10分打车去庙上拜佛，中午在庙里吃斋饭，临走时带回经书放在包里，下午即来拜访——所测全部应验。

## 实占要领

1. **值使门为射覆第一用神**：射覆必看值使门落宫，时柱为先锋门，气数集注总汇。
2. **天盘星为上、八门为中、地盘宫为下**：以三层结构判断物品的内外上下。
3. **旺衰定死活**：值使门旺相临生气为活物，休囚死墓临死气为死物。
4. **四孟四仲四季定形状**：寅申巳亥主圆，子午卯酉主方，辰戌丑未主尖碎。
5. **五行定质地**：水柔软近水，火虚锐烟火，木直长草木，金刚硬金铁，土厚重泥土。
6. **结合求测者所坐宫位**：射覆时求测者所坐之宫，以及物品被移动后的位置宫位，都是重要的辅助信息。
7. **数目看干支先天数与河图数**：以所临天干、地支的先天数目组合推断物品数目。
8. **颜色看天干地支**：甲青乙碧丙赤丁紫等，结合兼色综合判断。
