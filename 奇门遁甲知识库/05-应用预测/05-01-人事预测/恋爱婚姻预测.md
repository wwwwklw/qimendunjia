# 恋爱婚姻预测

## 定义与基本属性

恋爱婚姻预测是通过奇门遁甲中乙庚合、六合等符号，判断男女双方感情发展、婚姻状况、离婚诉讼等问题的应用。其核心原理是"乙庚合为夫妇之象"，以双方落宫生克定吉凶。

> **核心原则**：乙为阴木（妻），庚为阳金（夫），乙庚合金是天地自然之合。恋爱婚姻预测的一切判断都从此展开。

## 核心用神

### 男女双方
| 用神 | 含义 | 五行 |
|------|------|------|
| [[乙奇]] | **女方**（未婚女友/已婚妻子） | 阴木 |
| [[庚（阻隔之神）|庚]] | **男方**（未婚男友/已婚丈夫） | 阳金 |
| [[天干化合|乙庚合]] | 男女结合之象，成婚的征兆 | 金（合化） |

### 辅助用神
| 用神 | 含义 |
|------|------|
| [[日干]] | 求测人（本人） |
| [[时干]] | 所测之事（婚恋之事体） |
| [[六合]] | 媒人、介绍人、婚姻中介 |

## 取用神方法

1. **测自己**：日干为自己，对比乙/庚落宫与自身日干的关系。
2. **测他人**：直接看乙落宫（女方）与庚落宫（男方）的生克。
3. **测婚姻状态**：乙庚两宫相生为和，相克为不和。
4. **测成婚**：看[[天干化合|乙庚合]]是否成立，六合是否生合乙庚。

### 性别切换注意
- 求测人是**男性**：日干为自己（庚方），看[[乙奇]]落宫与己宫生克
- 求测人是**女性**：日干为自己（乙方），看[[庚（阻隔之神）|庚]]落宫与己宫生克
- 测**孩子婚姻**：直接取乙（女）庚（男）两宫判断

## 判断要点

### 婚姻吉凶判断
1. **[[乙奇]]落宫生[[庚（阻隔之神）|庚]]落宫**：女方爱男方，婚姻和美（▲吉）
2. **[[庚（阻隔之神）|庚]]落宫生[[乙奇]]落宫**：男方爱女方，婚姻和美（▲吉）
3. **[[乙奇]]与[[庚（阻隔之神）|庚]]落宫比和**：男女平等，互相尊重（▲吉）
4. **[[庚（阻隔之神）|庚]]落宫克[[乙奇]]落宫**：男方克女方，婚姻不利女方
5. **[[乙奇]]落宫克[[庚（阻隔之神）|庚]]落宫**：女方克男方，婚姻不利男方
6. **两宫相冲**：性格不合，容易争吵
7. **两宫相害**：有心结，难以沟通

### 成婚判断
- **[[天干化合|乙庚合]]成立**：天地盘相合，成婚之象明显
- **[[六合]]临乙庚两宫**：有媒人撮合，婚事易成
- **乙庚两宫逢[[开门]]**：婚姻公开，明媒正娶
- **乙庚两宫逢[[休门]]**：感情休憩，关系松弛
- **乙庚两宫逢[[死门]]**：婚姻死局，难成或无感情

### 特殊格局（重要）
| 格局 | 含义 |
|------|------|
| [[青龙逃走]] | 女方主动离开男方（乙+辛，女主逃走） |
| [[白虎猖狂]] | 男方主动提出离婚（辛+乙，男主疯狂） |
| [[朱雀投江]] | 口头争吵导致离婚，诉讼离婚 |
| [[腾蛇夭矫|螣蛇夭矫]] | 婚姻中有口舌是非，纠缠不断 |
| [[太白入荧]] | 男方出轨 |
| [[荧入太白]] | 女方出轨 |

> **记忆窍门**：青龙=乙（女），逃走=辛（革动）。白虎=庚（男）或辛，猖狂=辛+乙。记住"乙辛相反"即可掌握两种格局。

### 婚姻应期
- **[[天干化合|乙庚合]]成立之日**
- **两宫相生之日**
- **马星发动、填实空亡之时**

## 实占要领

1. **首定性别**：先明确求测人是男是女，否则用神取错全盘皆错。
2. **看乙庚两宫**：不看别的，先看乙奇与庚落宫的生克关系，这是婚姻预测的基石。
3. **看生克方向**：谁生谁、谁克谁，代表感情的流向与家庭地位的高低。
4. **乙庚合为补**：如果生克不够理想，看[[天干化合|乙庚合]]是否有望弥补。
5. **六合为辅**：六合代表外部助力（媒人/长辈），旺相且生合乙庚则婚事有贵人相助。
6. **格局定情形**：特殊格局非常关键——[[青龙逃走]]、[[白虎猖狂]]直接定性婚姻走向。
7. **离婚诉讼看朱雀**：[[朱雀投江]]格局下，离婚靠诉讼解决的可能性极高。

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》书中实例，张志春老师用以讲解恋爱婚姻预测中空亡填实的应期判断方法。

### 开悟之门补充：空亡填实——结婚应期的关键方法

在测婚姻应期时，**空亡填实**是关键方法之一。丈夫所在的宫位如果逢空亡，填实之年自然很可能是结婚之年。

《神奇之门》实例五测外籍医生四柱，判断她大约1967年或1968年结婚。判断逻辑：1967年丁未、1968年戊申，地支未、申所在**坤2宫临庚**（庚为丈夫），但此宫逢**空亡**。空亡表示丈夫尚未实至——填实之年（未年或申年）丈夫由虚变实，自然成就婚姻。

> **核心方法**：配偶用神（男方看庚宫、女方看乙宫）逢空亡时，以空亡填实之年/月为结婚应期。此法简洁直接，关键是先找准配偶所在的宫位。

出处：《开悟之门》

## 开悟之门补充

《开悟之门》中未提供此预测类型的独立完整案例。但张志春老师在书中多处提及婚姻相关判断要点，可参考以下原则：

- **婚期判断**：地支空亡填实之年为婚期——若坤2宫逢空亡（未、申），则丁未年或戊申年为可能的结婚之年（见人生机遇预测中的外籍医生案例）
- **乙庚关系**：乙奇（妻）+ 庚（夫）为婚姻核心用神，乙+庚或庚+乙为刑格，主夫妻不和；乙庚合则为良缘
- **日干相合之干**：也可作为配偶用神的参考，与对方年命落宫综合对比
- **六合吉凶**：六合为媒妁之神，临吉门吉格则婚易成，临凶门凶格则婚难成

## 金函玉镜补充

### 占婚姻（卷七）

以六乙为女，六庚为男，取甲以乙妹娶庚之义也。如乙庚二干落宫两相生合则成，两相克则不成。又以天上六合为媒人，如六合宫生六乙宫媒向女家，生六庚宫媒向男家。六庚宫克六乙宫，女家畏男而不嫁。六乙宫克六庚宫，男家嫌女而不娶。六乙宫带击刑，主女性凶恶；带德合，女性坚贞。六庚宫带凶神，主男性暴烈，带德合，主温厚。

### 占婚姻（卷十）

以庚金为男家，乙奇为女家，六合为媒妁。庚之落宫生乙之落宫，主男家爱女家；乙之落宫生庚之落宫，主女家爱男家。得奇门吉格者，婚姻必成。比和不相克制者，亦成。若庚宫克乙宫，主男家嫌女家，不成。乙宫克庚宫，主女家嫌男家，不成，强成之后必有刑克。庚金入墓而乘凶格者，刑夫。乙奇入墓而乘凶格者，克妻。

### 占纳宠（卷十）

以乙奇为妻，丁奇为妾，太白庚金为夫。若乙、丁奇之落宫生庚之落宫，其女必肯嫁。乙丁落宫克庚之落宫者，不肯嫁。乙丁宫相比和者，主妻妾和谐。如乙克丁宫，主妻不能容妾。或丁克乙宫，主妾欲欺妻。若乙丁入空陷库绝之宫，主不能成，成亦不利。如庚金宫生丁奇之宫，主徒劳无成。

## 上元经补充

### 用神的历时动态变化

《奇门遁甲上元经》婚姻章的最大突破是指出婚恋占测用神随阶段而变化，不能机械地一上来就看乙庚：

| 阶段 | 用神体系 | 依据 |
|------|---------|------|
| **少年情愫（舞勺/破瓜之年）** | 日时 + 桃花之位 | 懵懂初恋非真正婚姻，只是桃花 |
| **谈婚论嫁意向（男女未确立关系）** | 日时生克法 | 一方有意一方尚未表态，不能启用乙庚 |
| **确立恋爱关系/订婚** | 乙庚之合 | 已有和合事实基础（古代：父母之命；现代：身体接触） |
| **决定结婚走向** | 值符落宫（核心） | 乙庚相合的目的是合庚卫甲，值符决定整体走向 |

> **核心原则**：乙庚合的使用是有一定条件的，不能一上来就看乙庚二宫的生克比和。
> 出处：《奇门遁甲上元经》 — 参见 [[奇门遁甲上元经（张大春）]]婚姻章

### 少年情窦初开占法

- 日干临桃花 → 已遇中意之人，该人情况看日干五合之落宫
- 日干下临之干临桃花 → 正在盼望心上人
- 遇壬加己、己加辛、戊加庚、乙加辛等冲击格局 → 桃花为过眼烟云，镜花水月
- 遇吉格吉局 → 心上佳人不久会出现
- 日干临值符 + 临桃花 → 孩子王，仰慕者众多（需观六仪、甲帅明暗两种情况）

### 谈婚论嫁阶段（未确立关系前）

#### 男方求测追求女方

日干 = 男方，时干 = 女方（妻财从属于日干）：

| 关系 | 判断 |
|------|------|
| 时干生助/印比日干 | 女方同意追求 |
| 时干明克暗合日干 | 女方有意，但存在障碍（家庭地位差/索要彩礼） |
| 日干克制时干 | 看是否有宫位暗联→有则可成，无则难度大 |

**特殊：男方追求年长有财富地位的女性**

### 奇门启悟案例一：为滕女士做媒成败预测

- **时间干支**：乙酉年己卯月壬辰日己酉时 阳1局

- **分析**：
  **男孩为亲属**：六合落宫代表媒妁滕女士。今六合落坎宫，坎宫地盘落有戊，正是男孩年命天干戊，坎主血液——断滕女士这个媒人与男孩子（戊午）有血缘关系，是亲属。

### 奇门启悟案例二：为彭先生婚姻状况预测

- **时间干支**：甲申年癸酉月壬子日丁未时 阴1局
- **值符**：甲辰壬天心星  **值使**：开门
- **格局**：值符落巽四宫（壬加丁玉女合狱神）；彭年命壬落巽宫临值符、休门；女朋友年命丁乘天辅星落乾宫（丁加壬）；妻子年命癸丑落艮宫（空亡、伏吟）

  **来意测婚姻**：彭坐坎宫，被艮、坤两宫所克。艮宫天盘乙、地盘庚，坤宫天盘庚地盘乙，乙庚为夫妻之道，今均来克彭坐之坎位，必是婚姻之事令其有压力（坤、艮两宫均来克彭坐之坎宫，克我者为官鬼）。又六合主婚姻，休门亦主婚姻，今休门与值符同落巽四宫，彭年命壬亦落巽宫，值符为先锋门，为测来意所必看之处。休门主婚姻，落巽宫为入墓——婚姻不好之象显矣。彭所坐之坎宫乘六合又临死门——婚姻不利之象。

  **女友不能接受孩子**：时干丁代表小孩，今时干丁与彭年命壬落在一起（巽宫壬加丁、乾宫丁加壬）——不论从任何角度来看，小孩都是要和彭先生在一起的。若离婚，小孩必然判给彭先生扶养。天盘丁乘辅星落乾宫，乾宫冲克巽宫——女朋友（丁）不接受彭先生带小孩这个事实。值符所临之巽宫为壬加丁，又临休门——女朋友能与彭先生结婚（但前提是孩子归另一方）。

  **女友怀孕**：壬子日求测，胎神在午（壬水长生在申，沐浴在酉，冠带在戌……胎在午）。现女朋友年命丁落乾宫，乾宫落有景门，景门本为离卦（午），午正好是日干壬的胎神——景门便是胎神了。彭先生的女朋友怀孕了（年命丁与胎神景门同落乾宫），乾宫正克着彭年命壬所在的巽宫——分手不是一件容易的事。

  **将计就计做流产**：胎神最怕受冲，受冲则必然有堕胎之事。今奇门局中胎神景门落乾宫，正被值符所落之巽宫所冲，值符为天心星，心星代表医院——通过医院来墮胎。下一轮值符（天禽星）所落艮宫之惊门（酉）+景门（午）+ 辅星（辰）+ 乾宫（亥），构成辰午酉亥自刑。艮宫上乘乙奇代表医生，艮宫天芮星代表疾病，驚门为兑为说，女朋友年命丁落乾宫，艮宫生乾宫，艮为土主信——女朋友（丁）会相信医生（乙奇）所说（惊门--兑--兑为说）"胎兒发育不正常"的假话。艮宫为空亡——医生所说为假话。艮宫上乘太阴——暗中策划好了。

  **赔偿4-4.5万**：彭年命壬落巽宫，受女朋友年命丁所落乾宫之克。现只有离九宫能克制住乾宫，使乾宫受制而不克巽宫。今离宫格局戊加己，又临生门——戊与生门均为钱财之符号。离宫数目为9，秋季休囚——数目减半为4.5。又乾宫克巽宫，我克者为财——女朋友（乾宫）向彭先生（巽宫）要求补偿4（巽四宫）这个数字的钱。综合建议：至少得给女朋友四万至四万五千元钱，少了这个数事很难办。
- **结果**：彭先生依计行事，借故让女朋友去医院妇产科检查胎儿发育状况，事先与医院大夫（老同学）通好关系，检查后说胎儿发育不正常建议流产。女朋友自己走进手术室把孩子做掉。事后彭先生一次性给女朋友四万五千元钱，两人这段不该有的情感经历宣告结束。两年后听说彭先生前女友终于找到如意郎君并结婚，2006年春季生下一个健康可爱的儿子。

### 奇门启悟案例三：宋女士为儿子婚事预测

- **时间干支**：己卯年癸酉月庚辰日辛巳时 阴7局
- **值符**：甲戌己天心星  **值使**：开门
- **格局**：男方年命甲寅（癸）落艮宫，女方年命乙落坤宫，艮坤对冲；六合（媒人）落坎宫被艮坤两宫所克
- **分析**：
  **自由恋爱无媒人**：宋女士儿子年命甲寅，现落艮八宫；女朋友年命乙卯，乙落坤二宫。六合为媒为介绍人，现六合落坎一宫，艮、坤宫均来克六合宫——儿子和女友是自由恋爱，没有介绍人。男女双方年命相互落艮、坤对冲之宫——两人近期闹矛盾。景门为离卦，离主相见，现景门落兑七宫空亡之处——近期没有见面。男年命甲寅（癸）落艮宫，艮为止，不动之象；女年命乙落坤宫，坤主静，静止之象——男女双方都静止不动，谁也不理谁。艮数为8，坤数为2，8加2为10——两个人有10天没有通电话，也没有见面了。

  **1997年开始相处，女方母亲一直反对**：艮宫地盘落有乙奇，乙正是女朋友年命。艮宫天盘癸乘芮星并值使开门同落一起，癸为宋女士儿子的年命（甲寅癸）。艮宫有丑、寅二支，但艮宫地盘落有乙奇——应丑年（阳对阳，阴对阴）。开门代表开始，又临值使门——儿子在1997年（丁丑）和属兔的女朋友开始谈对象。女朋友年命乙乘任星落坤二宫，坤宫地盘落有癸水，癸为乙之偏印，坤宫又代表母亲，坤宫上乘有杜门（杜门主不通、阻止、阻碍之意），坤宫和艮宫又为对冲——女方母亲从一开始就反对这件事情，到现在依旧反对。

  **感情基础有不会轻易分手，问题在女方母亲**：儿子年命甲寅（癸）乘芮星落艮宫，女朋友年命乙乘任星落坤宫。艮、坤两宫虽然对冲，但冲而不克；又九星代表人心灵、性格、思想领域等信息，现男女所乘之星（芮星、任星）均属土，亦为比和——男女双方还是有感情基础的，不会轻易分手。坤宫地盘癸水为坤宫天盘乙奇的偏印，对女性来说偏印为母亲，加上坤宫本来就代表母亲。地盘癸水生天盘乙木——女方母亲暗中唆使女儿。坤宫与艮宫对冲，艮为房屋——女方母亲意图甚为明了。从另一个角度看，死门落乾宫来冲克值符所落之巽四宫，巽宫落有生门，生门代表房屋，值符为新房子。又死门所带暗干正是癸水（女方母亲）——女方母亲想向宋女士家索要新房子（值符、生门），而且是要面积较大的房子（值符所落之巽宫上乘天心星、生门，天心星为乾，乾主大，又天心星上乘己，己为太岁亦主大）。

  **现住房是公房**：宋女士坐巽位，巽宫乘值符、天心星、生门，并且心星又乘太岁己。生门为房屋，心星为乾卦，乾为公门，太岁亦代表公家——宋女士现有的房子是单位分的公房。生门属艮卦，艮卦地支中含有丑、寅，寅是儿子年命，生门上所乘暗干为乙奇，乙为儿媳年命。宋女士又坐于此宫，且临值符——宋女士是希望和儿子、儿媳住在一起的。但巽宫被乾宫所冲克，乾宫落有死门，死门所带暗干为癸水，正是女方母亲——此事女方母亲在暗中是反对的。

  **今年年末可结婚**：从儿子年命甲寅（癸）所落的艮宫来看，天盘为癸，地盘为乙，男女双方同落一起——有结合之象。艮宫天盘落有庚，地盘落有乙奇，庚为夫，乙为妻——亦有夫妻结合在一起之象。又艮宫落有值使开门，开门代表公开之意。凡是值符、值使所临之处所对应的信息，只要不空亡，都是绝对要出现的事情。今开门所带暗干为己，正是当年太岁天干，艮宫主丑、寅——今年年末他俩便可结婚。

  **女方父亲急着嫁女出钱买房**：乙奇为女朋友，正印壬水为女方父亲。今壬水乘天沖星落在兌宫，阴遁兌宫为内，沖星本位在震宫，地支为卯，正是女儿之年命。阴遁天沖星本属外盘之星，今落内盘兌宫，星主人的思想、念头、打算、计划等信息。壬为女方父亲，兌宫本来与沖星是相沖的，组合起来便可解读为女方父亲急着（沖星主急性子）把女儿（沖星—卯木—女儿年命）嫁出去（兌沖震即天沖星）。代表女方父亲的壬落兌宫，兌宫地盘落有戊，戊为钱财——女方父亲手中有钱。现戊乘天柱星落震三宫（落外盘），震宫落有休门，休门主婚姻，震宫地支为卯，正是女儿年命——女方父亲愿意为女儿结婚之事花上一笔大钱（戊乘天柱星旺于月令）。震宫与巽宫比和——比和为明之意。

  **新房产权写女方名字**：值符为新房子，生门亦落值符所在之巽宫，生门所带暗干为乙奇，正是儿媳年命——新买的房子的产权名字要写女方名字。
- **结果**：宋女士儿子按给出的主意去女方家说明家里经济状况。女方母亲仍反对，但女方父亲说："不要难为孩子两人了，拿出一部分钱给未来亲家，两方合夥给他们买一处100平米的房子，名字写女儿的名字，事情就这样定下来，今年就把喜事办了。"事后两家合买118平方米新楼，房主名字写女方。宋女士儿子终于在2000年元月16日举行婚礼（农历1999年腊月初十），有情人终成眷属。
