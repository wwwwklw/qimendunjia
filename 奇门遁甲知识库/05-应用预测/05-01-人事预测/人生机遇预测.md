# 人生机遇预测

## 定义与基本属性

人生机遇预测是奇门遁甲中综合性最强的应用，用于判断一个人的一生命运、先天禀赋、事业成就、社会关系等。涉及六亲（年干/月干/时干）、九星（天时）、八门（人事）、九宫（地理）、八神（自然力量）的全面联动，是奇门遁甲最高层次的综合运用之一。

> **核心原则**：日干为本命，年干为父母上级，月干为兄弟同事，时干为子女下级。九星为天时运程，八门为人事际遇，九宫为地利环境，八神为神秘力量。人生预测需要兼看[[年命]]（出生年天干）。

## 取用神方法

### 综合取用流程
```
排盘 → 定位日干落宫（本人） → 兼看年命落宫（先天命数）
     → 看九星（天时运程） → 看八门（人事际遇） 
     → 看九宫（地利环境） → 看八神（神秘力量）
     → 看年干（父母上级） → 月干（同辈） → 时干（子女下属）
     → 综合分析一生运势
```

### 测先天素质
1. **出生时间的奇门格局**：可测一个人的先天禀赋和天赋倾向。
2. **[[年命]]落宫的旺衰**：先天根基的强弱。
3. **[[九星概述|九星]]在天盘与年命宫关系**：天赋特长的方向。

### 测当前运势
1. **日干落宫旺衰**：当前运势的基本判断。
2. **[[年命|太岁]]与日干生克**：当年运势好坏。
3. **[[值符（八神）|值符]]与日干生克**：贵人运的情况。

## 判断要点

### 本人运势（日干）
1. **日干旺相且临吉门吉星**：运势好，万事顺遂
2. **日干休囚且临凶门凶星**：运势差，困难多
3. **日干临[[值符（八神）|值符]]**：有贵人相助，社会地位高（▲大吉）
4. **日干临[[九天]]**：上升期，事业上升，地位提高
5. **日干临[[九地]]**：稳定期，但上升空间有限
6. **日干空亡**：运势虚空，没有方向和目标
7. **日干入墓**：运势受到压制，被困住

### 先天素质（年命）
1. **年命与日干同宫**：先天根基好，与当前生命统一
2. **年命生合日干**：先天禀赋能支持后天发展
3. **年命与日干相克**：先天根基与后天发展有矛盾
4. **年命临[[天辅星]]**：文运好，学业天赋
5. **年命临[[天英星]]**：知名度高，社交天赋
6. **年命临[[天心星]]**：技术型天赋，医学/机械
7. **年命临[[天蓬星]]**：胆大好冒险，军警天赋

### 父母/上级（年干）
1. **年干生日干**：父母爱护，上司提拔（▲吉）
2. **日干生年干**：孝敬父母，尊从领导
3. **年干克日干**：父母压制，上级打压（▼凶）
4. **年干临[[死门]]**：父母身体不好或已故

### 兄弟姐妹/同事（月干）
1. **月干生日干**：兄弟姐妹关爱，同事合作（▲吉）
2. **日干克月干**：控制同辈关系
3. **月干克日干**：同辈竞争打单（▼凶）
4. **月干与日干比和**：同辈关系和谐

### 子女/下属（时干）
1. **日干生时干**：为子女/下属付出，责任大
2. **时干生日干**：子女孝顺，下级服从（▲吉）
3. **日干克时干**：管教严厉，掌控有力
4. **时干克日干**：子女叛逆，下属反抗（▼凶）

### 四维综合判断
1. **天时（九星）生合日干**：天时有利，抓得住机遇
2. **人事（八门）生合日干**：人和际遇好，关系网牢固
3. **地理（九宫）生合日干**：地利佳，居所有利
4. **神助（八神）生合日干**：有神秘力量庇护

### 应期
- 日干由囚转旺之时（运势转好之始）
- [[马星]]到日干宫（人生变动的信号）
- 填实空亡之时（机遇来临）

## 实占要领

1. **日干是核心**：不管看什么，日干始终是人生预测的最核心用神——它代表求测人本身。
2. **年命为根**：出生年份天干（年命）看先天素质——这是定命的基础，不可不查。
3. **四维体系要完整**：九星（天时）+ 八门（人事）+ 九宫（地理）+ 八神（神助）——体系完整缺一不可。
4. **六亲看关系圈**：年干父母上级、月干兄弟姐妹同事、时干子女下级——用六亲断人生关系网。
5. **生克定好坏**：谁生我谁对我有利，谁克我谁对我不利——这是最简单也最重要的判断法则。
6. **旺衰看起伏**：旺相时运势上升，休囚时运势低迷，入墓空亡时运势最低。
7. **出生时间看先天**：如果有出生时间，排当时的奇门格局可测先天禀赋、天赋方向——这是人生预测的最高境界。
8. **不要只看一组**：人生预测是综合性最强的预测，切忌只抓一个用神就下结论。

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》实例，张志春老师以此讲解人生预测中地支填实判断、流年应期的原理。

### 开悟之门案例：测外籍医生四柱（实例五）

- **时间干支**：见《神奇之门》第416-420页
- **奇门格局**：该女1967年丁未、1968年戊申年结婚；地支未、申所在坤2宫临庚（为其丈夫），但逢空亡
- **判断分析**：地支未、申所在坤2宫逢空亡，表示婚姻之事尚未落实；空亡填实之年就是结婚之年——1967年丁未年填实未，1968年戊申年填实申；故断大约是1967年或1968年结婚
- **实际结果**：准确断出其结婚年份

**要点**：地支填实之年为应期——坤2宫未、申空亡，应于丁未年和戊申年；用神逢空亡，填实之年自然就可能是该事发生之年；这是从流年地支角度判断应期的典型方法

### 开悟之门案例补充：地支与流年应期判断

张志春在书中进一步讲解：奇门判断流年、流月、流日、流时，从地支角度可以找到对应宫位来判断。如判断1996年（干支丙子）的事情，首先观察子年对应的坎宫情况；测某人农历八月情况，看兑宫；测辰日情况，看巽宫；测戌时发生的事，看乾宫。这是属静、属阴的特性——十二地支与奇门九宫格的对应关系固定不变。

## 奇门启悟补充

> **source:** [[奇门启悟（刘文元）]]
>
> 本节出自《奇门启悟》第十九章"终身运预测"。刘文元先生在古法基础上系统整理出奇门占终身运的四法（出生时间起局法、求测时间起局法、本命地支起岁法、宫位断运法），并完整披露了六亲体系在终身运预测中的具体应用，弥补了古法"具体断流年、定六亲之方法未能详尽披露"的缺憾。

### 理论补充：古法引文

《金函玉镜奇门遁甲秘笈全书》中关于终身运的论述为古法代表，摘录如下：

> 凡占人生贵贱，其法先明戴九履一，细寻接气超神，八门配合九宫，九宫要带三奇，年月日时要旺相，八门九宫须推移。离宫头面，乾艮两足，肩耳坤巽，震兑左右手筋。坎为阴肾，中为心腹。年干父母，月干兄弟，日干本身，时干属儿，推及妻妾。但看乙丁之落宫，庚为夫定不移，要详细其强弱，即能决其荣枯。旺相得奇，且富且贵；死囚墓绝，极贱极贫。格局要分轻重，命运验其得失……生门产业，要得门奇。成败分于内外，生克决其得失。生门太白逢冲陷，背祖离乡之客……开门有奇，应是文职；伤门得令，定系虎臣。生门得奇，石崇富足；景门合局，丹天文明……八门推来最怕反吟，伏吟亦是凶神。

然古法具体断流年、定六亲之方法未能详尽披露，更难以在经典古籍中找到完整的占断终身运的详细案例，致使多数奇门研习者难以登堂入室。[[奇门启悟（刘文元）]]中刘文元先生将研究十几年的奇门占终身运的方法、心得奉献出来。

### 理论补充：奇门占终身运四法

**第1法：以求测人的出生时间（年月日时）起局**

日干为我（求测人），生我者为父母，我生者为子孙，我克者为妻财，克我者为官鬼，与我（日干）五行相同者为兄弟。形成六亲体系后便可进行占断。

**男女六亲对应表**：

| 六亲 | 男性对应 | 女性对应 |
|------|----------|----------|
| 正印 | 母亲 | 父亲 |
| 偏印 | 父亲 | 母亲 |
| 食神 | 儿子 | 女儿 |
| 伤官 | 女儿 | 儿子 |
| 比肩 | 兄弟 | 姐妹 |
| 劫财 | 姐妹 | 兄弟 |
| 正财 | 妻子 | —— |
| 偏财 | 情人 | —— |
| 正官 | 祖母 | 丈夫、祖父 |
| 偏官 | 祖父 | 情人、祖母 |

> **六亲符号重复的区分法**：女性正官既为丈夫又为祖父，需以"外盘正官代表丈夫，内盘正官代表祖父"或"天盘正官代表丈夫，地盘正官代表祖父"区分。其他六亲符号重复时均仿此类推。

**第2法**：以求测人前来求测的时间起局，以日干为我，按上述六亲体系断之。

**第3法：本命地支起岁法**——以求测人本命地支位起一岁，顺时针逐宫断流年。如甲午年生人前求测，以其求测时间起局，以日干为求测人形成六亲关系，再以年命地支午位（离宫）起一岁，坤宫为二岁、三岁，兑宫为四岁，乾宫为五岁、六岁……如此任何一年运气皆可推出。

**第4法：以宫位进行判断**

| 性别 | 少年运 | 中年运 | 长年运 | 老年运 |
|------|--------|--------|--------|--------|
| 男性 | 艮宫 | 坎宫 | 震宫 | 乾宫 |
| 女性 | 兑宫 | 离宫 | 巽宫 | 坤宫 |

当求测者年命介入某宫，或落坐于某宫时，则以该宫之星、门、神、格局来论其对应人生阶段的运气。

### 奇门启悟案例一：为郑刚先生断终身运

- **时间干支**：乙酉年戊寅月壬申日己酉时阳2局（2005年农历正月初九傍晚6点左右）
- **值符值使**：值符甲辰壬天心星，值使开门
- **求测人**：郑刚，1962年（壬寅）生；妻子曹女士1963年生，同坐求测（郑刚坐巽位，曹女士坐离位）
- **格局**：郑刚年命壬乘天心星加临值符落震三宫；庚加癸大格（在兑宫冲克值符震三宫）；巽宫死门带暗干戊；艮宫癸加丁螣蛇夭矫；巽宫有申子辰三合局组合
- **判断分析**：
  1. **断是官场正职**：年命壬乘值符落震三宫（值符主领导、正职），巽宫天盘乙为当年太岁（乙酉）亦为当官符号，太岁主正职（一把手）
  2. **断8岁秋天上小学、9岁当班干部、14岁当主要班委**：年命寅在艮宫起一岁，兑宫为8岁（乘天辅文曲星冲动年命壬之震三宫，兑主秋天）；9岁在乾宫（地盘壬即年命，乾为地盘值符主官）；14岁流年走震宫（1975乙卯），震宫天盘壬乘天心星值符且为年命，故断当主要班委
  3. **断20岁（1981辛酉）父亲车祸去世**：取庚为父（庚为日干壬之偏印），天盘庚落兑宫为自身羊刃宫（庚羊刃在酉），格局庚加癸大格正冲值符震三宫；地盘庚在巽四宫临死门凶门、天蓬凶星；兑宫乘白虎主道路、震三宫为车辆符号，震兑相冲主车灾；辛酉年兑宫当令故应此年
  4. **断父亲有学问、清高抗上、受群众拥护**：庚乘天辅星主有学问；庚在兑宫冲克值符震三宫主清高抗上；时干己落坤二宫乘六合来生庚之兑宫主受群众拥护
  5. **断没能读大学**：年命壬落震三宫临值符，但天辅星临庚在兑七宫冲克震三宫；兑宫为太岁酉位主高等学府，酉为亚魁星主高考，这些信息冲克日干震宫故断未能读大学
  6. **断学校成绩不错**：震宫乘景门生丁奇所落之离宫（景门为考试题目，丁奇为考生答卷）
  7. **断1982（壬戌）年参加工作并介绍女朋友但分手**：1982壬戌，乾宫藏戌、地盘临壬（既是年干又是年命），乾宫为开门本位主工作；落乾宫的生门暗干为丁，丁与壬合、丁为壬正财故断处对象；时为寅月生门旺相主女方经济条件好；壬申日戌亥空亡即乾宫空亡，故双方分手；又郑刚坐巽位被乾宫冲克，乾宫信息是否认郑刚的
  8. **断24岁（1985乙丑）相处一女友（戴眼镜、内向），1987年分手**：艮宫藏丑寅，艮宫地盘丁为阴干应阴年1985（乙丑）；丁为日干壬之正财主女友；艮宫格局癸加丁螣蛇夭矫，丁为目、癸为水、水克火故女视力不好戴眼镜；丁奇到艮宫为入墓、艮宫落杜门故女性格稳重内向；1987丁卯年震宫应卯，震宫克艮宫（克主否认），故断从相处到分手两年时间，且是郑刚主动提出（震宫克艮宫）
  9. **断1987（丁卯）年被提升**：年命壬乘值符天心星落震三宫，值符为领导权力象征，震宫应1987年丁卯
  10. **断1987年和曹女士相处、1988（戊辰）上半年结婚**：震宫落景门通气于离宫（曹女士所坐），景门为离卦地支午，午中有丁，丁为日干壬之正财；曹女士年命癸卯，卯亦在震宫；外应曹女士用右手拍郑刚左后背（震卦）正应离宫信息动态传到震宫；巽宫天盘乙、地盘庚为夫妻符号，巽宫乘死门带暗干戊，巽宫地支辰巳，巽宫有申子辰三合局组合（地盘庚为申-甲申、天蓬星为坎为子、巽宫地支有辰），故1988戊辰年结婚；应上半年者，巽宫主辰、巳月
- **实际结果**：郑刚确为厂长兼党委书记；1969年秋8岁上小学；1975年14岁任团支部书记；1981年父亲车祸去世；1982年秋参加工作；1985年末经介绍相处1963年生女友（戴近视镜、稳重），1987年阴历二月中旬分手；1987年阴历五月经介绍与曹女士相识，1988年五·一结婚

### 奇门启悟案例二：为蔡文英女士预测终身运

- **时间干支**：壬午年庚戌月乙卯日乙酉时阴8局（求测时间2006年春节期间；蔡文英1942年西历10月29日傍晚6点左右出生，按其出生时间起局）
- **值符值使**：值符甲申庚天心星，值使开门
- **求测人**：蔡文英女士，1942年生，坐离位
- **格局**：日干乙乘天英星落艮八宫；坤二宫天盘丙地盘丁（丙为伤官主儿子、丁为食神主女儿）；震三宫丁奇乘天芮星、景门、丁加癸朱雀投江；离九宫天盘庚地盘乙（乙庚夫妻合）；艮宫冲坤宫（值使开门所在）
- **判断分析**：
  1. **断7岁上学、学校在北边、父亲骑车送**：年命壬午从离宫起一岁，坎宫为7岁；坎宫落天辅星（学校）、伤门；坎宫为北边、阴遁坎为外盘主远；壬为日干乙之正印代表父亲；伤门为震为足、坎为轮，足在旋转故为自行车
  2. **断10岁（1951辛卯）大病发烧38℃、上小学三年级**：10岁流年走震宫，震宫落天芮星（病神）、景门；景门为离卦为午即年命地支，芮星克日干乙之艮宫故大病；芮星上乘丁奇、震宫景门均为火，故发烧；震宫数目为东方三八木，故烧到38℃；乙奇代表医药落艮宫被天芮震宫所克，故吃药不管用
  3. **断性格急、热情、与同学相处好、不听老师话、替同学保密**：日干乙乘天英星主急躁；英星为火主热情；艮宫落六合吉神，月干庚落离宫来生艮宫主同学相处好；天辅星（老师）落坎宫，艮宫克坎宫故不听老师话；月干庚（同学）落离宫临惊门（兑为缺为错），坎宫天辅星要冲克离宫（批评同学），艮宫却克（制止）坎宫，艮宫落杜门主杜绝保密
  4. **断13岁（1954甲午）当学生干部**：13岁流年宫位落值符离九宫；离宫地盘日干乙，天盘庚为乙之正官，离宫临值符故当学生干部；丁奇为文章、景门为试题，丁奇景门均落震宫来生离宫故学习成绩好；庚为月干（同学），乙庚同宫相合故人缘不错
  5. **断19岁（1960庚子）保送师范学校**：19岁流年落坎宫；坎宫天辅星主高等学府，辅星上乘壬为太岁故为国家正规学府；坎宫十二消息卦为地雷复卦，故断人生走向很好开端
  6. **断25岁（1966）结婚、丈夫是高中同学、医务工作**：25岁流年落离九宫；离宫地盘日干乙，天盘庚为乙之正官，庚加乙为奇格亦为合格，乙庚为夫妻之合，离宫临值符故该年结婚；庚为月干主同学，地盘庚落乾宫，乾宫天冲星为震为卯，卯为日柱地支为夫妻宫，乾宫为17、18岁流年宫位，卯（蔡）与庚（夫）曾在乾卦相遇故为高中同学；庚乘天心星主医院医疗，地盘乙奇主医生医药，故丈夫从事医务工作
  7. **断1967（丁未）生儿子、1971年生女儿**：日干乙代表蔡文英，丙丁火代表子女；丙乘蓬星落坤二宫（坤宫值使开门主必然经历之事），丙为日干伤官主儿子；坤宫地盘丁（食神主女儿）代表未来要出现的事；坤为母、坤为产室，先天后地，故先生儿子（丙）后生女儿（丁）；坤宫有未申二支、地盘丁，故应丁未年生儿子；丙乘蓬星主大眼睛；坤宫开门、九天主个头高；开门为乾为父、暗干庚，故儿子像爸爸；地盘丙落坎宫乘太岁壬、天辅文曲星故儿子成才考上好大学
  8. **断女儿体弱、戴眼镜、内向、喜欢看书、离家在外发展**：丁奇乘芮星落震三宫，景门带暗干乙（日干），芮星为坤为母与日干同宫故女儿长得像蔡；丁奇乘天芮星克日干乙之艮宫，故女儿身体不好；震宫丁加癸朱雀投江，丁为目乘芮星故女儿视力不好戴眼镜；芮星为坤主静、震宫落太阴故性格内向；丁奇、景门同气相求（同为火神）故喜欢看书；天辅星乘太岁壬落坎宫来生丁奇之震宫，故学业不错为大学生；阴遁震宫为外盘，故女儿要离开家在外发展
  9. **断工作能力强、能管"坏学生"**：日干乙乘天英星落艮宫，英星代表女强人、英明果断善谋；值使开门代表重要工作，艮宫冲坤宫（开门值使所在）说明能胜任重要工作；艮为山为高为阻碍，英星旺于艮宫（我生之处为旺）说明工作能力强能胜任阻力较大的工作；值符落离宫来生艮宫说明工作受领导认可；日干乙、时干乙同气，故与学生打成一片；天盘时干乙为表现好的学生，地盘时干为"坏学生"，地盘时干落离九宫上乘庚（最坏信息），天辅星（老师）落坎宫与地盘时干离宫对冲说明老师讨厌该坏学生，但地盘时干离宫来生日干乙之艮八宫，故坏学生也能乖乖听话
- **实际结果**：蔡文英7岁上学、学校在北边10多里、父亲骑车送到小学四年级；10岁（1951辛卯）全身出麻疹发烧38-39度、休息一月余；性格急性子、热心肠、曾替同学向老师请病假；13岁（1954甲午）小学六年级任班长；19岁（1960庚子）保送师范学校；25岁（1966）秋天结婚、丈夫为高中同班同学、医学院毕业做医生；1967年生儿子（哈工大毕业、在哈尔滨工作）、1971年生女儿（体弱多病、戴眼镜、内向、喜看小说、大连外国语学院毕业、在外企工作常出国）；年年获奖、坏学生也听她话
