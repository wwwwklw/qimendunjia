# 体育竞赛预测

## 定义与基本属性

体育竞赛预测是奇门遁甲的应用之一，脱胎于军事占测——以主客场或攻守双方划分主客，以时令长短分胜负。其核心在于主客判断：反吟利客（进攻方），伏吟利主（防守方/主场方）。

> **核心原则**：竞赛如战场，主场为守、客场为攻。反吟格局下客方获胜概率大，伏吟格局下主方获胜概率大。

## 核心用神

### 竞赛双方
| 用神 | 含义 |
|------|------|
| 日干落宫 / 主场方 | **主方**（主场队伍、防守方） |
| 时干落宫 / 客场方 | **客方**（客场队伍、进攻方） |

### 赛事用神
| 用神 | 含义 |
|------|------|
| [[庚（阻隔之神）|庚]] | **比赛器械**（球类比赛的球、赛车比赛的车辆、兵器比赛的武器） |
| [[景门]] | 比赛成绩、得分情况 |
| [[开门]] | 比赛场馆 |
| [[时干]] | 比赛这件事体 |

## 取用神方法

### 第一步：划分主客
1. **主场队伍 = 主方 = 日干落宫**
2. **客场队伍 = 客方 = 时干落宫**
3. 如果没有主场之分：日干为我方（关注方），时干为对方

### 第二步：看格局定倾向
1. **[[反吟]]格局**：利客（进攻方/客场有利）
2. **[[伏吟]]格局**：利主（防守方/主场有利）

### 第三步：判断胜负
1. **谁旺相谁赢**：旺相方占优
2. **谁克对方谁赢**：克对方方占优
3. **格局加持**：反吟+客方旺相=客赢概率极高

### 取用流程
```
排盘 → 判断是否是反吟/伏吟 → 划分主客 
     → 对比双方旺衰 → 看主客生克 → 看庚（器械） 
     → 看景门（成绩） → 综合判断胜负
```

## 判断要点

### 格局判断（最重要）
两个特殊格局直接影响竞赛结果：

| 格局 | 含义 | 对竞赛的影响 |
|------|------|-------------|
| [[反吟]] | 反复变化，动象强烈 | **利客方**，客队胜率高 |
| [[伏吟]] | 静止不动，平稳保守 | **利主方**，主队胜率高 |

### 力量对比判断
1. **日干（主方）旺相，时干（客方）休囚**：主方占优
2. **时干（客方）旺相，日干（主方）休囚**：客方占优
3. **日干落宫克时干落宫**：主方能克制客方（▲主方有利）
4. **时干落宫克日干落宫**：客方能克制主方（▲客方有利）
5. **双方比和**：势均力敌，可能平局

### 器械判断（庚）
1. **[[庚（阻隔之神）|庚]]生日干（主方）**：器材对主方有利
2. **[[庚（阻隔之神）|庚]]生时干（客方）**：器材对客方有利
3. **[[庚（阻隔之神）|庚]]临[[伤门]]**：器材可能出问题或有人受伤
4. **[[庚（阻隔之神）|庚]]临吉星**：器材状态好，比赛质量高

### 成绩判断（景门）
1. **[[景门]]生日干**：成绩偏向主方
2. **[[景门]]生时干**：成绩偏向客方
3. **[[景门]]临[[九天]]**：高分比赛
4. **[[景门]]临[[九地]]**：低分比赛

## 实占要领

1. **反吟伏吟第一看**：这是竞赛预测最重要的格局长——反吟利客，伏吟利主。
2. **主客分清**：主=我关注的方，客=对方/对方队——立场要明确。
3. **旺衰定实力**：双方落宫旺衰直接反映实力对比，这个比生克更直观。
4. **主客生克为辅**：主克客（主方克制客方），客克主（客方克制主方）。
5. **庚看器械**：球类比赛重点看庚——庚是球、是比赛器械，旺相则比赛精彩。
6. **景门看成绩**：比赛结果与景门的关系密切。
7. **综合判断不偏废**：反吟伏吟只是倾向，还要结合双方旺衰综合判断。

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第十五章 体育竞技胜负预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

不论何种体育竞技比赛项目，均以[[值符（八神）|值符]]为裁判，[[时干]]为参赛运动员。通常以地盘时干为主队，天盘时干为客队，以各自落宫之旺相休囚、格局吉凶来定其胜负。

**核心用神**：
- [[庚（阻隔之神）|庚]] → 比赛器械
- [[辛（罪错之神）|辛]] → 金牌、奖牌
- [[景门]] → 战略、技术

**胜负基本判断**：
- 地盘时干宫克天盘时干宫者 → 主胜
- 天盘时干宫克地盘时干宫者 → 客胜
- 地盘时干宫与天盘时干宫相比和者 → 双方战成和局

**足球比赛取象**：以离九宫落有[[天冲星]]、[[开门]]代表足球——天冲星为震卦，震为足为跑动；开门为乾卦，乾为圆形为球，组合在一起便可代表足球。

**主客划分（跨国比赛）**：根据奇门遁甲基本原理"静则只察值符、值使，动则专看方向，盖动者机之先见者也"。如两国球队都不在各自国土上比赛（如在中国举办的第三国对决），则以各国对应方位取本位星——例如巴西位居中国西南以坤宫对应，本位星为[[天芮星]]，以天盘天芮星代表巴西队；德国位居中国西北以乾宫对应，本位星为[[天心星]]，以天盘天心星代表德国队。

**应期推断**：起局必须按比赛现场当地太阳时起，需要将北京时间换算成当地时间（例如德国慕尼克当地经度为东经11.5度，需通过公式换算）。

### 奇门启悟案例1：预测2005年欧洲冠军联赛1/8决赛首回合拜仁慕尼黑 vs 阿森纳胜负

- **时间干支**：乙酉年戊寅月丁丑日庚戌时 阳9局（转盘奇门，按德国慕尼克当地比赛时间起局）
- **值符值使**：值符甲辰壬[[天辅星]]，值使[[杜门]]
- **求测背景**：2005年2月22日晚8点多钟，香港易友田伟鸿（主攻六爻、四柱，喜欢博彩）来电求助。2月23日凌晨3点45分欧洲冠军联赛1/8决赛首回合足球赛，德国拜仁慕尼黑主场对阵英格兰阿森纳客场。各赌博公司标准盘口平均赔率2.25 3.17 3.11，印尼让球参考盘口为1.975 0/0.5 1.925。田伟鸿准备下重注
- **分析**：
  1. **主客队落宫状态分析**：以地盘时干庚为主队代表拜仁慕尼黑，地盘庚落坤二宫，坤宫落有[[天辅星]]吉星、[[休门]]吉门，格局为壬加庚天岳倚势格（凡事耗费而后吉）；以天盘时干庚为客队代表阿森纳，天盘庚落乾宫，乾宫落有[[天芮星]]凶星、[[伤门]]凶门，格局为庚加丁太白受制格（凡事无一成就）。主队星吉门吉又临值符，客队星凶门凶，主队状态明显好于客队。
  2. **断主队拜仁采取技术型打法以守为主，客队阿森纳采取强攻速战**：主队坤宫天辅吉星与杜门同气，杜门主技术，休门代表休息、节省体力 → 避实就虚、以逸待劳战术；客队乾宫天芮星贪功、伤门主积极跑动、主动进攻、杀伤力强，庚亦为主动进攻，乾宫亦主进攻积极前进 → 强攻速战打法。
  3. **断主队锋线只安排一名前锋打防守反击，客队会安排三名前锋**：主队坤宫落有休门，休门主一数；客队乾宫落有伤门，伤门主三数。
  4. **断上半场主队以守为主、打防守反击为辅，下半场死守前提下抓漏洞出奇破门；客队上半场以攻为主急于破門配合失误多，下半场继续强攻但体力消耗大致漏洞多必被破门**：天盘信息代表上半场，地盘信息代表下半场。主队坤宫天盘天辅星主文雅柔顺、休门主休息等待 → 上半场以防守为主；坤宫地盘庚为攻击、地盘藏死门主死守 → 下半场以死守为主抓漏洞进攻。客队乾宫天盘天芮星主贪毒、伤门主激进速度快攻击性强 → 上半场以攻为主；伤门所带暗干为辛金主错误 → 队员跑错位置配合失误；天芮星主弊端漏洞 → 体力消耗大致漏洞多。乾宫地盘天心星、开门均属乾卦，乾者健也 → 下半场仍以进攻为主；地盘藏有开门 → 客队下半场必被主队破门失球。
  5. **断裁判至少出示八张以上黄牌，客队队员会有头部、右腿受伤**：景门代表裁判手中红黄牌，景门落艮八宫，景门所带暗干为戊（土主黄色）→ 艮八宫之景门为黄牌；艮宫数目为八，日干支丁丑亦落艮八宫与值符所居坤二宫对冲，艮为山为止主结束 → 这场比赛结束后裁判至少出示八张以上黄牌。乾宫为客队，乾宫落有芮星、伤门，芮星主病、伤门主受伤，乾主健乾为头，乾宫亦主右腿 → 客队队员会有头部、右腿受伤的现象出现。
  6. **关键胜负判断——离宫（足球）生主队坤宫克客队乾宫，主队必胜客队输球**：取离九宫落有天冲星、开门代表足球（天冲星为震卦震为足，开门为乾卦乾为圆形为球）。今足球（离九宫）生主队坤宫，克客队乾宫，故这场比赛主队必胜，客队输球。
  7. **空亡辩证——主队坤宫空亡为何能取胜**：从日柱干支丁丑来查，申、酉空亡，主队坤宫空亡。但日柱丁丑均落于艮宫来对冲坤宫，**冲空则实**，坤宫被填实而不作空论。赛场如战场，值符落宫为守城方，庚落宫为攻城方，今断客队会强攻为主要的打法之判断，源于此理。
- **结果**：田伟鸿未听劝阻，朋友四人共投注100万港币到阿森纳队。2月23日凌晨3点45分拜仁慕尼黑对阵阿森纳的现场直播，最终拜仁慕尼黑以3:1大胜阿森纳。预测结果完全应验。整场比赛战术与事先分析一样：拜仁上半场打防守反击锋线只放一个前锋；阿森纳一开场便狂轰乱炸气势逼人，下半场依旧以进攻为主，最终因体力消耗过大漏洞百出；阿森纳队果然设有三个前锋，完全打进攻战术，后防线便有漏洞。整场比赛裁判一共给了九张黄牌。阿森纳队一名队员头部被撞出血，还有一名队员右腿被撞伤而换下场。一切均如所测。经一年多时间预测总结，准确率在百分之七十九左右。

### 奇门启悟案例2：预测2007年女足世界杯冠军得主

- **时间干支**：丁亥年己酉月丁卯日庚戌时 阴1局（转盘奇门，按上海虹口体育场当地比赛时间起局）
- **值符值使**：值符甲辰壬[[天心星]]，值使[[开门]]
- **求测背景**：2007年女足世界杯决赛，2007年9月30日晚20点在上海虹口体育场进行巴西队与德国队争夺冠军。许多球迷易友致电问测，9月30日白天先后接到16个问测电话
- **分析**：
  1. **主客划分——以地理位置取本位星**：巴西属于南美洲国家位居中国西南以坤宫对应，本位星为天芮星，以天盘天芮星代表巴西队；德国属于欧洲国家位居中国西北以乾宫对应，本位星为天心星，以天盘天心星代表德国队。代表德国队的天心星落艮八宫并临值符、景门；代表巴西队的天芮星落乾六宫并临太阴、伤门。离九宫落有天冲星、开门代表足球。
  2. **关键胜负判断——离宫（足球）生德国艮宫克巴西乾宫，巴西大门必被攻破**：从日柱干支丁卯来查，戌、亥空亡，即乾宫空亡，空亡则不吉。代表足球的离九宫生艮八宫，离九宫来克乾六宫 → 乾宫（巴西队）不利，巴西队大门必被攻破（空亡）。代表德国队的天心星临值符落艮八宫，天心为吉星、值符为吉神，景门主策略战术，艮为止为稳重 → 德国队注重防守、战略战术打法正确，不失球（离宫生艮宫）。代表巴西队的天芮星临太阴落乾六宫并临伤门，天芮为凶星、伤门为凶门 → 巴西队临场发挥状态不好；乾宫临空亡对巴西队是最不利的信息；足球离九宫克乾宫 → 足球必会进入巴西队大门；乾宫临伤门也说明巴西队球门要被对方攻破。
  3. **综合判断——德国女足最终击败巴西女足成为2007年女足世界杯冠军**：代表德国女足的天心星临值符落艮宫，值符便是全局的能量主流；天心星为乾卦，乾为首为第一为冠军。
- **结果**：晚间8点坐在电视机前观看现场直播。果然这场巅峰对决打得十分激烈，德国队以不失一球的骄人战绩一路杀进了决赛，最终2:0完胜巴西队，成功卫冕，荣获2007年女足世界杯冠军。

### 奇门启悟案例3：2007年女足世界杯四分之一决赛中国 vs 挪威胜负结果预测

- **时间干支**：丁亥年己酉月庚申日丙戌时 阴7局（转盘奇门，按武汉体育中心体育场当地比赛时间起局）
- **值符值使**：值符甲申庚[[天禽星]]，值使[[死门]]
- **求测背景**：2007年9月23日晚20点整，中国对阵挪威的四分之一决赛在武汉体育中心体育场进行。比赛对中国女足非常重要——取胜则进入下一场亚季军争夺赛，战败则是告别赛。全国各地球迷纷纷前往武汉观看现场比赛。深圳易友陈育（铁杆球迷）一天连打三次电话问预测结果
- **分析**：
  1. **主客划分与表面信息**：这场比赛由于在中国进行，故中国队为主、挪威队为客。地盘时干丙代表中国队落离九宫，天盘时干丙代表挪威队落巽宫。地盘时干丙落离九宫上面落有值符天禽星并落有开门，星吉门吉本为大吉之象，但细致观察格局不好——庚加丙[[太白入荧]]凶格（又名贼格，占贼贼必来），又开门主门开，足球比赛最忌门被打开，故吉中藏凶。天盘时干丙落巽宫上乘[[天英星]]（主刚烈、凶猛、迅速、急进），巽宫落有[[惊门]]，表面看起来星凶门凶，但格局为丙加辛[[奇仪相合|奇神相合]]吉格（谋事可成，名利称心，万事大吉），因而不能轻以凶来断。
  2. **火焰外焰温度原理——挪威队气数比中国旺**：从易理角度讲，时干丙火代表队员。地盘丙火落离宫，离主虚（离中虚），禽星主守 → 中国队在防守上必有漏洞，必会被挪威队偷袭（庚加丙贼格，占贼贼必来），门被攻破（离宫乘开门）。天盘时干丙乘天英星落巽宫，巽为木、英星为火、丙亦为火，巽宫木火通明火势旺。学过物理化学的人都知道，火焰的外焰温度比内焰温度高。地盘丙为内、天盘丙为外 → 挪威队比中国队气数旺，其必会取胜。
  3. **帝旺无上升空间vs冠带有上升空间**：地盘丙落离九宫为帝旺之地（丙火长生在寅，帝旺在午），说明中国女足已尽全力（帝旺）去拼搏，但帝旺已无上升空间。天盘时干丙乘天英星为自乘帝旺（英星属离卦，离为午，丙帝旺在午），但巽宫为丙火冠带、临官之乡，气数正常仍有上升空间。离宫之火为帝旺之火，离宫天盘落有禽星、芮星二位土星，火生土，火气必损。相比之下，巽宫火势更旺。
