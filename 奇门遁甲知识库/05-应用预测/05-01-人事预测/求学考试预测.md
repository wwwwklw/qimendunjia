# 求学考试预测

## 定义与基本属性

求学考试预测是通过奇门遁甲判断考生学业运势、考试成绩、录取可能以及适合的学校和专业方向的应用。以天辅星（文昌星）为核心，配合丁奇（文书）、景门（试卷），形成完整的学业判断体系。

> **核心原则**：天辅星为文昌星，主学业文运；丁奇为文书、信息；景门为试卷成绩。三方联动，判学业之成败。

## 核心用神

### 三大核心
| 用神 | 含义 | 作用 |
|------|------|------|
| [[天辅星]] | **老师**、**学校**、文昌星，主文运学业 | 教育力量 |
| [[丁奇]] | **文书**、考卷、学历证书、录取通知书 | 考试内容 |
| [[景门]] | **试卷**、成绩、考试过程 | 考试结果 |

### 辅助用神
| 用神 | 含义 |
|------|------|
| [[日干]] | 考生本人 |
| [[时干]] | 考试这件事 |
| [[值符（八神）|值符]] | 主考官、招生办 |
| [[年命|年干]] | 父母（代测子女时） |

## 取用神方法

1. **测自己**：日干为考生，看日干与天辅星、丁奇、景门的关系。
2. **测孩子**：年干为父母测子女，时干为孩子（子女宫）。
3. **测录取**：看景门与日干的生克关系。
4. **测考试难度**：看[[天辅星]]旺衰（旺则题易，衰则题难反常规）。

### 取用流程
```
排盘 → 定位日干落宫 → 看天辅星落宫（学校/老师） 
     → 看丁奇落宫（文书/考卷） → 看景门落宫（成绩） 
     → 看三者与日干的生克 → 综合判断
```

## 判断要点

### 学业能力判断
1. **日干生[[天辅星]]**：学生好学上进，喜欢老师（▲吉）
2. **[[天辅星]]生日干**：老师赏识学生，学校有利（▲吉）
3. **日干克[[天辅星]]**：学生不尊重老师，自学为主
4. **[[天辅星]]克日干**：学校/老师对学生不利，学业压力大

### 考试成绩判断
1. **[[丁奇]]/[[景门]]生日干**：考试对考生有利，成绩理想（▲吉）
2. **日干生[[丁奇]]/[[景门]]**：考生适应考试，但需努力（△中）
3. **[[丁奇]]/[[景门]]克日干**：考试对考生不利，成绩不理想
4. **[[景门]]旺相且临吉门**：考试成绩优异
5. **[[景门]]休囚且临凶门**：考试失利

### 录取判断
1. **[[值符（八神）|值符]]（考官）生日干**：考官欣赏，录取有望
2. **[[开门]]生日干或与日干比和**：公开录取机会大
3. **[[丁奇]]临开门**：通知书到达之象
4. **日干临[[死门]]**：录取无望

### 应期判断
- [[丁奇]]旺相日（通知日）
- [[景门]]旺相日（成绩公布日）
- [[开门]]临日干之日（开学/报到日）

## 实占要领

1. **分清角色**：日干是考生、天辅是老师学校、丁奇是文书、景门是考卷——四个角色不能混淆。
2. **考试类看景门**：景门是考试预测的第一参考，旺衰吉凶直接反映成绩。
3. **学业类看天辅**：测长期学业运势，天辅星比景门更重要。
4. **重点盯生克**：景门、丁奇、天辅与日干的生克关系是判断的主线。
5. **旺衰辅助**：各用神旺相时力量大，休囚时力量小——同一生克关系旺衰不同，结论可相差很大。
6. **八神看环境**：临[[值符（八神）|值符]]有贵人相助（如保送），临[[太阴]]暗中有助力（如特殊政策）。
7. **代测注意**：测孩子学业时，取时干为孩子（辅以年命），再按上述方法判断。

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》实例，张志春老师以此讲解考试预测中定应期的方法。

### 开悟之门案例：测在美国考行医执照（实例五）

- **时间干支**：1997年
- **奇门格局**：杜新会判断叶教授女儿最终能被录取；八门伏吟主迟；日干丁落外盘3宫、时干癸落内盘9宫，日时一内一外也主迟；迟断年月，断年不合事理故定断月；丁奇为通知书，天盘丁奇在3宫，地盘丁奇在4宫；巽4宫辰、巳逢空亡
- **判断分析**：空亡藏有玄机——通知书什么时候来，看巽4宫辰巳空亡何时填实；戌冲辰，故断阴历九月（戌月）；按1997年阳历10月8日交寒露节进入戌月，故断10月7日以后才能收到录取通知书
- **实际结果**：10月9日收到通知书（比预测晚1天）

**要点**：空亡填实/冲实为应期——辰巳空，戌冲辰即应期（戌月填实）；以节气定月份比以阴历定月份更准确（若按阴历九月断10月2日以后，与实际差7天；按节气戌月断10月8日以后，与实际仅差1天）

### 开悟之门案例补充：定应期以节气为纲

- **判断分析**：奇门判断应期时，应以节气为主、以阳历时间为主；二十四节气与八宫等分后，与阳历时间的对应更为稳定（最多相差一两天）；杜新会在本例中断10月7日以后收通知书，正是基于交寒露节气进入戌月这一判断
- **实际结果**：10月9日收到通知书，判断基本准确

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第十章 考学升学预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

[[日干]]、[[年命|年命]]落宫为考生，[[天辅星]]为考试院，[[值符（八神）|值符]]为主考官，值使为监考，[[丁奇]]为考生文章，[[景门]]为试卷、试题，年干为录取学校。

**考生录取判断**：
- 考生落宫旺相，得三奇、吉门吉格，又得天辅星、值符、年干落宫来相生者 → 必能考上理想学校
- 考生年命落宫旺相、乘吉门、吉格、得三奇来克天辅星、值符、年干落宫者 → 也能考入较理想的学校
- 考生落宫休囚无力，又不得奇门吉格者，但得天辅星、值符、年干落宫来相生者 → 虽考试成绩不佳，但也能被录取
- 考生落宫逢死、绝、休囚、入墓、空亡，又得凶门凶格，又受天辅星、值符、年干宫来相克者 → 必名落孙山

**学科对应八门**（刘文元先生实践总结）：
| 八门 | 所主学科 |
|------|----------|
| [[休门]] | 数学 |
| [[生门]] | 生物学、生理学 |
| [[伤门]] | 体育、运动类学科，又主音乐、舞蹈类、歌唱类学科 |
| [[杜门]] | 物理、化学、气象学等学科 |
| [[景门]] | 美术、语文、摄影等学科 |
| [[死门]] | 地理、历史 |
| [[惊门]] | 语言类学科、专业（落内盘主播音、主持人、演讲等；落外盘主外语类学科） |
| [[开门]] | 政治 |

**定分数方法**（刘文元先生独创）：以景门落宫定大数，丁奇落宫定小数（零头数目）。这是刘文元在多年预测高考、中考的大量实践中摸索出的一种具体定分数的方法，比较精确。

### 奇门启悟案例1：为董辰璐2007年高考预测实例

- **时间干支**：丁亥年甲辰月己丑日戊辰时 阳5局
- **值符值使**：值符甲子戊[[天禽星]]，值使[[生门]]
- **求测背景**：2007年4月25日上午8点20分左右，于平女士（三年前曾来为女儿中考预测过，2004年女儿以628分考入重点高中）前来为女儿董辰璐（1989年农历8月25日早8点左右生）求测，再过40多天面临高考，问今年高考考得怎么样，估计能考多少分
- **分析**：
  1. **断今年高考考得不错，估计总分620分左右，报考一本重点院校没问题**：[[丁奇]]为考生文章，[[景门]]为试卷试题。董辰璐年命己乘[[天心星]]吉星与景门同落乾宫。丁奇落坤二宫，景门落乾宫，坤宫生乾宫，说明考试题多数都能答好。丁为太岁，亥居乾宫，亦为太岁，太岁丁落坤宫生年命己所居之乾宫，说明必能考上大学。又年命己落乾宫为太岁宫（亥），加之年命地支巳在巽宫，巽宫上乘[[天辅星]]文曲吉星、[[休门]]吉门、[[太阴]]吉神，这些信息都充分说明今年高考必能考得很好。景门所乘暗干为壬，景门与年命己同落乾六宫，丁落坤二宫，丁与壬数自为六，乾宫数自为六，故大数必为六，说明高考分数最少600分；丁奇落坤二宫数自为二，丁奇落宫定小数，故定高考分应在620分左右。
  2. **断北京外国语大学与北京语言大学都能考上，但最终被北京语言大学录取的可能性最大**：丁奇太岁代表录取学校，坤二宫格局为丁加丁，丙、丁为朱雀，朱雀主语言类学校。年命己落乾宫，被丁奇所居之坤二宫来相生，故断肯定能被录取。又[[值符（八神）|值符]]落艮八宫来生乾宫，艮宫落有[[惊门]]，惊门亦主语言类学校。区分方法：从内外角度区分，丁奇落坤二宫为外，故坤二宫之丁奇代表北京外国语大学；惊门落艮八宫，艮八宫又临值符，由于艮宫为内，惊门主语言类，故惊门所居之艮八宫代表北京语言大学。由于从日柱干支来查，坤二宫为空亡，故北京外国语大学可能会落空；而代表北京语言大学的艮八宫临值符来生年命己落之乾宫。故断最后被北京语言大学录取的可能性较大。
- **结果**：高考结束后考生们先自估分数，然后填报志愿。董辰璐考试后对照标准答案的自估分数与预测分数很接近，于是较有把握地把北京语言大学填作第一志愿。填报志愿完毕后不久，具体考分出来了，董辰璐实际高考分数考了615分，最终被北京语言大学对外汉语系录取。预测的620分与实际615分仅差5分，定分数方法十分精确。

### 奇门启悟案例2：为鲍昱霖2007年高考一事预测实例

- **时间干支**：丁亥年丙午月丁丑日戊申时 阳3局
- **值符值使**：值符甲辰壬[[天柱星]]，值使[[惊门]]
- **求测背景**：2007年6月12日下午4点左右，王晓琳老师带着崔女士前来求测。崔女士女儿鲍昱霖（1988年农历八月初八出生）于6月7、8、9日三天刚参加完高考。来意一是估计考试分数，二是指点报考哪个方向的学校更有把握。因考生本人未到，根据母亲崔女士求测时间起局，结合考生年命落宫为主线判断
- **分析**：
  1. **断高考分数应在460分至470分左右，利于报北边的高校，容易被录取**：[[景门]]落巽四宫，鲍昱霖年命地支辰在巽宫，故景门的信息必是鲍昱霖之信息。巽宫数目为四，故大数为400分。[[丁奇]]乘[[天英星]]落坎宫，坎宫为北方一、六水，可取数目为一或六，因丁奇落宫定小数目、零头数目，所以由景门所落之巽宫与丁奇所落之坎宫可组成410分或460分这两种组合数目。又坎宫所落之丁奇定小数目，坎宫为北方一、六水，一加六为七，故470分之断缘于此。太岁落宫代表录取学校，今太岁丁奇落坎宫，来生景门所居之巽四宫，景门为分数线，故北方的学校能接受鲍昱霖所考的分数，所以断利于报北边的高校，容易被录取。
  2. **建议将吉林华侨外国语学院填报为第一志愿，最有把握考上**：鲍昱霖年命戊乘[[天冲星]]落地盘值符兑宫。兑宫上乘[[开门]]，开门藏有地支亥（开门为乾卦，乾卦地支有戌、亥），亥为太岁，代表高等院校。兑为口为说，代表语言类学校。阳遁兑宫为外，故兑宫代表外国语。又从日柱干支来查空亡，申、酉为空亡，兑为金，金空则鸣，必为外国语学校之类。戊乘天冲星，冲星为木为林，冲星为吉星，故应吉林；又戊为土，兑为口，土加口亦为"吉"，冲星为木为林，亦应吉林二字。综上所述，鲍昱霖把吉林华侨外国语学院填作第一志愿是最有把握考上的。从另一角度看，年命戊于地盘落震宫，震宫上乘值符[[天柱星]]，柱星为兑卦，震为木，震宫落有[[杜门]]，杜门亦为木，杜门为巽卦，巽卦翻过来看便是兑卦，这些都是吉林华侨外国语学院的明显信息标志。
- **结果**：6月19日中午12点左右，王晓琳老师来电说当天下午就得填报志愿，现有辽宁工业大学、吉林华侨外国语学院、大连工业大学三所学校供选择。刘文元在电话中建议把吉林华侨外国语学院填报为第一志愿。不久考生的具体考试分数出来了，鲍昱霖2007年高考成绩总得分为470分，比她自己对照标准答案估算的分数高出近30分。由于听了建议，将吉林华侨外国语学院填报为第一志愿，最后被录取。而大连工业大学的录取分数线最后定在500分以上，当时鲍昱霖曾经想把大连工业大学填报为第一志愿，幸亏被否定，不然就上不了大学了。460-470分的预测与实际470分完全吻合。

**要点**：刘文元先生独创的"景门落宫定大数、丁奇落宫定小数"定分数法，在实践中精度极高；区分同类学校（如两所语言类大学）用内盘外盘的角度来分辨；空亡宫位的学校可能落空（录取不到）；用神类象组合（如戊+兑口="吉"，冲星木="林"）锁定具体学校。
