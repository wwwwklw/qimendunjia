# 行人走失预测

## 定义与基本属性

行人走失预测用于判断走失人员的方向、状态、安危以及归期。根据求测人与走失人的关系，取不同天干为用神——父母测子女用[[时干]]，测同辈用[[用神|月干]]，测长辈用[[年命|年干]]。这是六亲关系在走失预测中的典型应用。

> **核心原则**：以六亲定用神（年/月/时干按辈分），以六合定方向，以杜门定躲藏方位。吉门多则不思归，凶门多则易自回。

## 核心用神

### 走失人（按求测关系）
| 关系 | 用神 | 记忆法 |
|------|------|--------|
| 父母测子女 | [[时干]] | 时干为子息宫 |
| 测同辈/配偶 | [[用神|月干]] | 月干为兄弟宫 |
| 测长辈/父母 | [[年命|年干]] | 年干为父母宫 |
| 通用补充 | [[年命]] | 走失人的出生年份天干 |

### 方位与去向
| 用神 | 含义 |
|------|------|
| [[六合]] 落宫 | **走失方向**（六合主动、之行） |
| [[杜门]] 落宫 | **躲藏方向**（杜为封闭、躲藏） |

### 状态用神
| 用神 | 含义 |
|------|------|
| [[日干]] | 求测人 |
| [[时干]] | 事体（兼看） |

## 取用神方法

### 第一步：确定走失人用神
```
求测人是谁 → 确定与走失人关系 → 取对应天干为用神
父母测子女 → [[时干]]
测同辈     → [[用神|月干]]  
测长辈     → [[年命|年干]]
补充       → [[年命]]（走失人出生年天干）
```

### 第二步：确定方位
```
[[六合]]落宫方位 → 走失方向
[[杜门]]落宫方位 → 躲藏/隐蔽方向
```

### 第三步：判断状态
```
用神临吉门（开休生）→ 安全
用神临凶门（死伤惊）→ 有危险
用神临[[杜门]]→ 自行躲藏不出
用神临空亡 → 可能不在寻找范围内
```

### 取用流程
```
排盘 → 六亲定位用神 → 看用神落宫吉凶 
     → 看六合落宫（方向） → 看杜门落宫（躲藏） 
     → 看八门吉凶（回否） → 看庚格/马星/空亡（归期）
```

## 判断要点

### 去向判断
1. **[[六合]]落宫方位** = 走失人前往的方向
2. **[[杜门]]落宫方位** = 走失人躲藏/隐蔽的方向
3. **六合与杜门同宫**：走失人在较为封闭的地方

### 归否判断（八门定归心）
| 用神所临 | 判断 | 原因 |
|----------|------|------|
| [[开门]]、[[休门]]、[[生门]]、[[杜门]] | **不思归** | 安全无事/躲藏不出，不会主动回来 |
| [[伤门]]、[[景门]]、[[死门]]、[[惊门]] | **易自回** | 有困难危险，反而容易主动回家 |

> **记忆法**：吉门+杜门（四门）外出舒服，不思归；凶门四门外受困苦，愿回。

### 安危判断
1. **用神临[[九天]]**：走失人去了远处/高处
2. **用神临[[九地]]**：走失人去了近处/地下室
3. **用神临[[死门]]**：走失人有生命危险
4. **用神临[[伤门]]**：走失人可能受伤
5. **用神临[[惊门]]**：走失人受到惊吓

### 归期判断
1. **[[庚格定应期|庚格]]出现**：归期的最强信号——逢庚即回
2. **[[马星]]到用神宫**：走失人在移动中，快被找到
3. **用神空亡填实**：空亡期结束即归
4. **用神临[[反吟]]**：去而复返，反复走动
5. **用神临[[伏吟]]**：停留在某处不动

## 实占要领

1. **六亲定位第一**：取错用神全盘皆错。父母测子女→时干，测同辈→月干，测长辈→年干。
2. **六合定方向**：六合主出行走动，其落宫就是走失方向。
3. **杜门定躲藏**：如果是离家出走/故意躲藏，重点看杜门落宫。
4. **八门定归心**：四门不思归（开休生杜）、四门易自回（伤景死惊）——此是走失预测的独特规律。
5. **吉凶看用神**：走失人用神的宫位吉凶直接反映走失人的处境。
6. **归期看三信号**：庚格（最强）、马星（移动）、空亡填实（时间节点）。
7. **年命为补充**：如果知道走失人的出生年命，作为用神的补充参考。

## 开悟之门补充

以下案例引自《开悟之门》，原案例来自《神奇之门》实例，张志春老师用以讲解行人走失预测中八门吉凶判断、用神旺衰、庚格定应期等核心方法。

### 开悟之门案例：测女儿离家出走（实例五）

- **时间干支**：卯月（1997年3月7日离家）
- **奇门格局**：时干壬落巽4宫临死门；死门落4宫受木制，且卯月木旺土死；日干、时干一内一外主慢；值使开门落2宫；时干壬临天禽阳星；坎1宫庚下之干为戊
- **判断分析**：开始一见死门按凶断就错了；实际上死门落4宫受木制，卯月木旺土死，凶门根本凶不起来；用神临死、惊、伤、景四门反而容易回来；值使门落宫数大致卡在10天或12天内；按时干临阳星看"庚下之干"法找见戊日，查万年历3月17日为戊午日即为应期
- **实际结果**：女儿在男朋友家住了十天，因患重感冒，于3月17日自己回到家中

**要点**：凶门在失令受克时凶不起来；行人走失用神临死惊伤景四门反而容易回来（物极必反）；庚格法定应期——时干临阳星看庚下之干

### 开悟之门案例：测女孩失踪被害（实例七）

- **时间干支**：未月
- **奇门格局**：时干乙落兑宫临死门；死门为土，生兑宫之金，凶门生宫；未月死门旺相；上乘白虎凶神；乙落兑为绝地；乙+壬为日奇入地凶格
- **判断分析**：凶门生宫，事更凶；未月死门旺相，凶上加凶；白虎凶神加临，主血光之灾；乙落绝地，日奇入地，均主绝命入土之象，故断失踪女孩被人害死埋到地下
- **实际结果**：确已被害身亡

**要点**：凶门生宫事更凶；死门旺相（月令）决定凶的程度；多凶符叠加（白虎+绝地+日奇入地+死门旺相）判断必死

### 开悟之门案例：测外甥女失踪（实例九）

- **时间干支**：辰月（4月5日清明节后，刚入辰月，头九天乙木当令）
- **奇门格局**：用神时干辛落巽4宫；临死门、天柱凶星；甲午辛+甲子戊为困龙被伤格，但子午冲，冲则不为入墓；辰月土生金，时干辛为入辰库（非墓）
- **判断分析**：开始未细分墓、库区别，一律按入墓断，加上临死门、天柱凶星，错判"凶多吉少，恐已被害"；实则辰月土生金，辛金旺相，入辰库不为入墓；子午冲解了困龙被伤格；刚入辰月头九天乙木当令，木旺金囚土死，天柱星、死门均凶不起来；用神临死门反而容易找回
- **实际结果**：此女孩被安全找回

**要点**：入库与入墓必须严格区分（旺相入为库，休囚入为墓）；月令五行旺衰决定星门吉凶程度；用神受冲不为入墓；行人走失用神临死门有反归之机

### 开悟之门补充：用神临死门反易回——凶门反断法详解

《神奇之门》实例五测女儿离家出走是对"死门逢凶必死"惯性思维的**经典纠错**。时干壬落巽4宫临**死门**，初学者一见死门就按凶断——实际断错。纠正逻辑：

1. **五行生克决定凶力**：死门（土）落巽4宫（木），**木克土**，死门被宫所制（宫克门为"制"），凶不起来。
2. **月令决定旺衰**：卯月**木旺土死**，死门在月令上处于死地，更加无力。
3. **凶门在走失预测的反断规则**：行人走失中，用神临**死、惊、伤、景**四门反而容易回来——走投无路时会自己回家。

> **核心教训**：不能一见死门就断凶。必须综合分析：门被宫制则凶力大减；月令决定门的实际旺衰；特定预测类别（行人走失）中凶门有反断规则。

实际结果：女儿在男朋友家住了十天，因患重感冒，于3月17日自己回到家中。

## 金函玉镜补充

### 占走失（卷七）

以时干为失主（与六壬之用干同理），六合为逃走之物，俱以落宫论之。又以六合宫与时干落宫，看在内外以分远近。如日干、六合俱在内，易寻；俱在外，难寻。六合在外，时干在内，难寻。又以六合所在之宫为方向，如得旺相星，又乘开休生杜四门，不可得，反此可得。乘九地、太阴，有人潜藏；乘九天远走，乘玄武被人盗去，乘螣蛇有人盘诘羁縻，乘朱雀有信，勾陈有勾引而去。又看六庚，年格则年获，月格则月获，日格则日获，时格则时获。

### 占走失奴婢（卷十）

男仆专责天盘天蓬之宫，女婢专责天盘天芮之宫，寻之必获。阳日责地盘蓬、芮之宫决之，逢格必获，不格不获。若与六合相并者，必被拐去。二神入库，有人隐藏难寻。落空亡者，必不能获。

### 占走失何方（卷十）

失去小儿，阳遁于天盘六合所在之方，阴遁于地盘六合所在之宫决之。若失女婢，阳遁于天盘太阴所在之方，阴遁于地盘太阴所在之宫定之，看此二神，即知其人所在之方矣。阳遁在坎艮震巽四宫为内，为近；落离坤兑干为外，为远，阴遁反此。若二神落日干之墓库者，远近难寻。落空亡者，其人又往他方去，之后再以干合神之宫寻之，必获。

### 占行人在外（卷十）

法以行人年命日干决之。年命日干落在坎艮震巽，阳遁为内，为近；离坤兑干为外，为远，合而决之。年命落于四维甚远，落坤艮者，为极远。阴遁以离坤兑干为内，为近，坎艮震巽为外，为远。年命日干落于休废，其人在外必不如意，非困即病。若年命日干落于墓库、空亡之宫，再乘死绝之气，其人必不在。如年命日干乘旺相之气，再得奇门吉格，行人在外发财如意。

### 占行人归期（卷十）

法以行人年命专责庚格，阳日以庚下临之干主之，阴日以庚上乘之干定之。年格年来，月格月来，日格日来，时格时来，不格不来。何谓不格？乙庚为合不为格。庚金入墓或临空亡，不为格。

## 奇门法窍补充

> **source:** [[奇门法窍（锡孟父子）]]
>
> 本节出自《奇门法窍》卷四「占行人」「占行期」「占远信」「占回乡」「占人走失」「占走失六畜」等章节，系（飞盘体系）飞盘奇门对行人走失预测的独特论述。

### 占行人（飞盘体系·九星来期）

以本人**年命**合当局中干支为行人，以**支宫**为宅舍，左右为来之迟速，其日以地方远近决之。

**又法（卷四·占行人）**：

| 用神 | 含义 |
|------|------|
| 时干 | 行人 |
| 时干加八门 | 所往之方 |
| 时干加地盘九星 | 来期 |
| 直符 | 占事之人 |

**判断要点**：
- 时干克门 → 主已动；时干生门有成 → 未成主未动
- 门克时干 → 此事不宜，已往他方；门生时干 → 有人勾引未动
- 时干克直符 → 不思归家；直符克时干 → 主在半路
- 时上生直符 → 立至；直符生时干 → 主将动身
- 伏吟不来，反吟已来

### 占行期（飞盘体系）

以**时干**为起行之人，**日干**为牵缠之人，**开门**为起行之期，以时干在内、在外并开门下干决定。

### 占远信（飞盘体系）

以**丁**为信，**时干**内外为迟速（外迟内速）；如人在北方，占南方信息，一宫得**景门**者信到。

### 占在外虑家中安否（飞盘体系）

以**日干**为主，**时干长生处**为家（如甲木长生在亥，亥属乾宫），无凶为平安。

### 占回乡（飞盘体系）

以本人**年命**占时入局中，人已在外方，占时其年命已落内界，未回以干支定其日期。

### 占在外人安否（飞盘体系）

以外宫上下二盘得三奇吉门及诸吉格者安，反此不安。

### 占未出门先定归期（飞盘体系）

以出行**日干长生之方**定之。若甲乙日出行，须看乾方地盘所在之干为归家之期。

### 占出行经商地方吉否（飞盘体系）

以其所往之方得三奇吉格生年命日干落宫者为上吉。

### 占登舟船主善恶（飞盘体系）

以**震宫**为船，所得星为船主之善恶，以九星吉凶决之。

### 占道途吉凶（飞盘体系）

以**时干**所落之宫得**蓬**为盗贼；如蓬不遇，再时干所加本宫得三奇吉门旺相诸吉格，不妨。

### 占谋害（飞盘体系）

**庚**为仇人，**甲**为己身，生克决其有无谋害。

**行路遇人同往善恶**：以**时干**为己身，看上得何星临之，以九星吉凶决其善恶，休旺定其吉凶。

### 占出行水陆吉凶（飞盘体系）

以**休门**、**景门**所乘之宫分水、旱二路，二门落宫、天地二盘得奇仪吉格相乘为吉。

### 占人在外不知何方（飞盘体系）

以行人**年干**决之，本人年干落于何宫即何方，落内者近，外者远。

### 占久出存亡（飞盘体系）

以**年命**落宫定之：乘旺带奇吉者平安；休囚为困苦；空亡为其人不在。

### 占久出外信虚实（飞盘体系）

以**景门**、**朱雀**决之。景门为文书之神，朱雀为口舌信息之神，得奇吉者实。

### 占行人何日归来（飞盘体系）

端以**庚格**决之。以本人年命落于何宫，即在何方。落内者近，外者远。

### 占人走失（飞盘体系）

小儿走失，阳日看天盘**六合**落宫，阴日看地盘六合所在之宫——在天盘内四宫近，外四宫远。
- 奴仆专以**天蓬星**主之，落于坤宫归于父母之家，以空亡墓库为难寻
- 婢妾以天盘**太阴**主之，或以**天芮**落宫决之

### 占走失六畜（飞盘体系）

| 六畜 | 用神 | 方位 |
|------|------|------|
| 骡马船车 | 伤门、天冲 | 伤门落何宫即往何方寻 |
| 牛羊 | 坤宫死门、天芮 | 死门隐于何宫即何方 |
| 马匹 | 乾宫所得之神、天盘天蓬 | 天蓬在何方即何方寻 |

### 占避难逃避方向（飞盘体系）

以**杜门**、**丁己癸**、**六合**、天上**太冲**及**生门**所临之方，又生本时干则吉；再有三奇吉星大吉，反此不利。

### 占出差平安（飞盘体系）

以**日干**落宫为出差之人，**时干**落宫为所差之事，以生克决之。

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第十一章 行人走失预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

以走失行人之[[年命]]为用神，是为正宗。兼看四值，长辈人看[[年命|年干]]，同辈人看[[用神|月干]]，小辈人看[[时干]]。

**行人状态判断**：
- 行人年命用神落宫旺相、乘吉星吉门吉格者 → 人在外平安
- 用神落内盘 → 人走不远；用神落外盘 → 走得很远
- 方向以行人年命落宫决定
- 用神宫受太岁、月干、日干、时干宫生扶 → 在外有贵人帮助
- 用神落宫乘凶星、凶门、凶神、凶格、入墓、空亡、六仪击刑等 → 不吉，大凶之象

**行人走失后能否回来**：
- [[日干]]与[[时干]]同宫，或时干宫生日干宫者，行人年命落宫生求测者年命落宫者，或行人年命落宫生求测者坐宫者 → 行人容易找到或自己回来
- 日干宫生时干宫，日干宫克时干宫，或时干宫克日干宫，求测者年命宫生行人年命宫，求测者年命宫克行人年命宫，或行人年命落宫克求测者年命落宫者 → 行人不易回来

**内外盘定远近**：
- 阳遁时，行人年命落在坎、艮、震、巽宫为内为近，离、坤、兑、乾宫为外为远
- 阴遁时，行人年命落在离、坤、兑、乾为内为近，坎、艮、震、巽为外为远

**八神定状态**：
- 行人年命落宫乘[[九地]]、[[太阴]] → 有人潜藏
- 乘[[九天]] → 远走高飞
- 乘[[玄武]] → 被人拐骗
- 乘[[腾蛇|螣蛇]] → 有人盘查、羁留
- 乘[[白虎]] → 可能有刑伤、血光
- 乘[[值符（八神）|值符]]、[[六合]] → 安全无恙
- [[伏吟]] → 人难回；[[反吟]] → 人必回

**归期判断**：旬空者，以填实之时日或冲实之时日为应期；逢冲者以合为应期；逢合者以冲为应期；又可以[[庚格定应期|庚格]]来定应期：逢年格者年内归，月格者月内归，日格者当日归，时格者本时即回。又阴日看庚上之干，阳日看庚下之干为应期。

### 奇门启悟案例1：为陈志胜预测女儿出走实例

- **时间干支**：庚辰年辛巳月壬申日乙巳时 阳1局（飞盘奇门）
- **值符值使**：值符甲辰壬[[天禽星]]，值使[[生门]]
- **求测背景**：2000年5月14日上午10点左右，陈志胜（1961年生）前来求测，坐离位，言语很少显得深沉，问"最近遇到了麻烦事，如果不说明来意，能否测出"
- **分析**（刘文元先生以测来意切入，结合求测者坐宫与外应综合判断）：
  1. **测来意——断陈因女儿的事在烦恼**：求测人坐离宫，离宫格局为壬加乙，又临[[死门]]。壬为[[日干]]代表陈志胜，乙为[[时干]]代表所问之事。乙木为日干壬水之子（水生木），壬为阳水，乙为阴木，阳生阴异性，故乙木必为陈的女儿。从外应看，陈进屋后坐离位，点燃香烟吸在嘴里深深吸了一口吐出烟雾——香烟点燃为离卦，吐出烟雾为巽卦。时干乙木乘[[天英星]]落巽宫，英星属火，正应陈点燃香烟这一举动。
  2. **断女儿离家出走，不上学了**：巽宫格局为乙加辛[[青龙逃走]]凶格，有出走之象。巽宫克艮宫，艮宫落有[[天辅星]]（主学校），故断女儿离家出走不上学了。值使[[生门]]落乾宫临朱雀来冲克乙奇所落之巽宫，必应出走之事。
  3. **断陈志胜被学校老师找去了**：年命辛乘天辅星落艮八宫，艮宫上落有[[休门]]，休门主谒见，艮宫地盘落有丙，丙主相见，天辅星为老师，故断被学校老师找去了。
  4. **断责备女儿并动手打女儿**：巽宫格局乙加辛龙逃走，乙为女儿，辛为陈志胜。辛金克乙木，为陈打女儿之象。又乾宫临值使生门加临朱雀来冲克巽宫，生门为艮卦，艮中有丑，丑为陈的年命地支，朱雀主骂，证明陈不仅责备了女儿，并且动手打了女儿。
  5. **断女儿出走四天**：巽宫为乙加辛青龙逃走，又被乾宫冲克，乾宫天盘为己，巽宫天地盘均为阴（乙加辛），故取巳，又巽宫数自为四，说明女儿是己巳日离家出走的。从己巳日到壬申日正好是四天。
  6. **断陈最怕女儿寻短**：巽宫地支有辰，天盘英星中藏有午，天盘惊门中藏有酉，值使生门落乾宫正冲克着巽宫，乾宫有亥，如此辰、午、酉、亥自刑构全，故恐有自杀寻短之可能性。
  7. **断女儿没有走远，今天中午一定能回来**：女儿年命乙丑，天盘乙落巽宫，阳遁巽宫为内，故没有走远。值符为先锋门，落离宫，格局为壬加乙，壬为日干为求测人，地盘乙为时干为女儿年命，离宫应午时。从大象看，天盘乙（女儿）在巽宫，生日干壬所在之离宫，为女儿回来之象。凡是临值符的信息，只要不空亡，都是必然要应验的信息。
- **结果**：陈志胜急忙赶回家，过了中午12点37分，陈给刘文元打来电话说女儿到现在也没回来。刘文元看了看时间，午时还没结束，让其再等一会儿，坚信一点钟之前女儿会回来。果然中午12点50分，陈志胜打来电话说女儿刚刚回来。后来陈志胜讲述：女儿被责备后离家出走，找到男朋友想办法，男朋友把陈女儿安排在市内东南方向的一个旅馆内暂住，后女儿赌气离开旅馆并与男朋友提出分手。

### 奇门启悟案例2：毛女士问孙颢小朋友失踪预测实例

- **时间干支**：乙酉年壬午月甲戌日壬申时 阳9局
- **值符值使**：值符甲子戊[[天英星]]，值使[[景门]]
- **起局方法**：未按问测时间起局，而是按孙颢小朋友出走的时间起局（转盘奇门）
- **求测背景**：2005年6月20日上午9点30分左右，毛女士来电求测。同事小孩孙颢（男，1998年戊寅年出生）于6月19日下午3点多钟放学后出去玩，一宿没回家，孩子才8岁。问小孩子是不是出事了，什么时候能回来
- **取用经验**：刘文元先生的经验是，主要看走失小孩的年命落宫为最根本的参考依据，再结合时干落宫来参断。而传统的以六合落宫代表走失小孩的方法，经大量实践觉得并不好用。
- **分析**：
  1. **断小孩凶多吉少恐有意外，没走太远，在家东南或南边一个有水的地方**：孙颢年命戊落巽四宫，日干甲戌己落乾宫，日干宫克用神宫，人难回之象。又时干壬与死门同落震三宫，亦被日干所落之乾宫所克，都是人难回之象。因年命戊所落巽宫地盘有壬水，戊又乘天英星（离卦），故断小孩在东南方向（巽）或南方（英星—离卦）有水的地方（壬）。因巽宫阳遁为内盘，故断离家不远。因时干壬与死门同落震三宫，故断恐有意外。
  2. **断不是被人拐骗、绑架，也不是迷路，而是滑落到水库中，自己不小心跌入水中，被淤泥或岩石拌住不能动弹，估计人已死亡**：[[玄武]]代表拐骗，今玄武落坎宫，生年命戊所落巽四宫，故不是被人拐骗。[[腾蛇|螣蛇]]代表绑架，现螣蛇落离宫，也不来克年命戊所落的巽四宫，故也不是被人绑架。[[景门]]为道路，又临值符，且年命戊乘天英星值符落四宫来克景门所临之艮八宫，英星、景门均为离卦相互通气同气，故也不是自己迷路了。巽宫临值符，值符为事物机之所现。值符天英星中藏有地支午，巽宫所落之惊门中藏有地支酉，地盘壬中藏有辰，地盘值符离宫中落有开门，开门中藏有地支亥，而离宫地盘落有年命戊。如此辰、酉、午、亥自刑全矣——辰午酉亥自刑组合意味着自己不小心跌落入水中（自刑）。离宫格局（地盘值符）为庚加戊伏宫格，戊为年命，被庚乘芮星所伏在其上而动弹不得。又庚为甲申，戊为甲子，自有申子半合水局之象，离宫上乘螣蛇有羁拌之象，芮星主泥土，申子半合水局故应淤泥，庚为坚硬故又可应岩石。日干甲木长生在亥，死在午，午为日干之死气，午为离卦对应天英星、景门，现年命戊落巽宫且乘天英星，英星即为午，故年命乘日干之死气。种种信息都说明孙颢可能已经死亡了。
  3. **断明天（丙子日）便能找到孙颢，还是在这水库里**：奇门断应期中，有合待冲应之说。由于孙颢是失踪状态（隐藏不现），故取离宫地盘戊（年命）为其信息，离宫格局为庚加戊伏宫格（大凶之格），有申子半合之象；天盘戊乘天英星（午）落巽四宫又临值符，巽宫格局为戊加壬，有子辰半合之象。明天为丙子日，子冲午（子冲天英星）则孙颢必现。
- **结果**：6月20日上午10点30分开始下水寻找，找了2个多小时没找到。下午三点左右又雇了两个水手下水，找到晚上六点仍然没找到。毛女士已不相信预测结论，问有没有可能离开本地了。刘文元坚持说明天（丙子日）便能找到，还是在这水库里。第二天（6月21日）中午12点30分左右，毛女士来电说上午八点多钟有人看见水库上漂着一具小孩尸体，报案后大家赶往水库一看果然是孙颢。先后雇了四个水手下去打捞居然连个人影也没找到，等到不找的时候他竟然从水里漂了上来。丙子日找到的预测完全应验。

**要点**：刘文元先生实践总结的取用经验——以走失小孩年命落宫为最根本参考依据，比传统以六合落宫代表走失小孩的方法更准确；辰午酉亥自刑组合判断自己不小心跌落入水中；"合待冲应"定应期——子冲午（天英星）则尸体必现；坚持奇门局的判断不被外界质疑动摇。
