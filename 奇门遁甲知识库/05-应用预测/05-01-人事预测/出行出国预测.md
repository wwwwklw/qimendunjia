# 出行出国预测

## 定义与基本属性

出行出国预测是通过奇门遁甲判断出行是否顺利、交通工具安全程度、归期以及出行方向的吉凶。按照交通工具分为陆路、水路、空路三类，各自有不同的用神体系。

> **核心原则**：日干为出行人，所往方向与日干生克关系为主线。不同交通工具各有专属用神——伤门为车，休门为船，九天为航线，开门为飞机。

## 取用神方法

### 出行取用流程
```
排盘 → 定日干落宫 → 定目的地所在方位之宫 → 看生克 
     → 定交通工具用神 → 看交通工具旺衰与日干关系 
     → 看八门八神 → 综合判断吉凶
```

### 归期取用流程
```
排盘 → 看庚格位置 → 看马星是否发动 
     → 看日干是否临开门 → 看空亡填实 
     → 综合判断归期
```

## 判断要点

### 出行吉凶判断
1. **所往方向之宫生日干**：出行顺利，目的地有利（▲吉）
2. **日干生所往方向之宫**：出行辛苦但最终到达（△中）
3. **所往方向之宫克日干**：出行不利，有危险（▼凶）
4. **日干克所往方向之宫**：可控但艰辛
5. **两宫相冲**：途中必有事端

### 交通工具安全判断

#### 陆路（车 + 公路）
1. **[[伤门]]（车）生日干**：车辆安全，驾驶顺利（▲吉）
2. **日干克[[伤门]]**：有驾驶风险，但人可控制
3. **[[伤门]]克日干**：车有问题，可能出事故（▼凶）
4. **[[景门]]（道路）生日干**：路况好，畅通
5. **[[景门]]克日干**：路况差，拥堵或封路
6. **伤门临[[死门]]**：严重交通事故的警示
7. **伤门临[[白虎]]**：车祸前兆，需特别注意

#### 水路（船 + 水路）
1. **[[休门]]（水路）生日干**：水路畅通，航行安全（▲吉）
2. **[[休门]]克日干**：水上风险，可能晕船
3. **休门临[[惊门]]**：水路有风波
4. **休门临[[天蓬星]]**：水上事故的警示

#### 空路（飞机 + 航线）
1. **[[九天]]（航线）生日干**：飞行顺利，天气好（▲吉）
2. **[[开门]]（飞机）生日干**：航班正常，起降安全
3. **[[九天]]克日干**：航线有湍流，飞行不适
4. **开门临[[死门]]**：航班可能取消或延误
5. **开门临[[白虎]]**：航空事故的先兆预警

### 出发日期判断
1. 看[[开门]]下临地盘之干对应的天干日（如甲子日、乙丑日等）。
2. [[开门]]旺相之日为最佳出发日。
3. [[马星]]发动之日为出发信号。

### 归期判断
1. **[[庚格定应期|庚格]]出现**：归期将至的有力信号。
2. **马星临日干宫**：归心已动，即将返程。
3. **空亡填实**：如日干空亡，填实之时为归期。
4. **日干临[[反吟]]**：去而复返，很快返回。
5. **日干临[[伏吟]]**：迟迟不归，归期延后。

## 实占要领

1. **先查安危**：出行预测的第一要务是判断安全，看目的地宫与日干是否相克、看交通工具用神是否克日干。
2. **工具分类**：先确定出行方式——陆路看伤门+景门，水路看休门，空路看九天+开门。
3. **方向定吉凶**：所去方向之宫是第一判断基准。生我则去，克我则慎。
4. **白虎为凶兆**：任何交通工具用神临[[白虎]]，都是事故的前兆，需要特别警示。
5. **庚格看归期**：『逢庚必变』——庚和庚格是判断归期的关键参考。
6. **马星看动身**：动身与否看马星，马星不动，计划再多也走不了。
7. **死门看取消**：所选用神临死门，行程很可能取消。

## 金函玉镜补充

### 占出外预定归期（卷八）

其法以四维长生决之，看出门之日干系何干？即看四维是何干长生之宫？以本宫地盘之干，即回家之日也。

### 占出外不知家安否（卷八）

其法专以四维决之。四维者，乃四长生之方也。倘甲乙日看干宫，此四大长生之根也。若得门、得奇、吉格，则吉；凶格，俱凶。

### 占出外之人安否（卷七）

先定方向，看其方上下二盘得三奇吉门天地二门俱有奇门及诸吉格者，安；反此不安。

### 占出行水陆吉凶（卷八）

以休、景二门所乘之宫分水旱二路。休门落空，合天地二盘有三奇相乘者，水路吉；景门有三奇者，旱路吉，行船忌。青龙逃走、白虎猖狂凶格，主风暴。螣蛇妖矫，主凶灾。朱雀投江，主沉溺。

又以伤门为船，伤加休上为浮、为顺；休加伤上，为舟行水底，主沉溺。景门为旱路，又以伤门为马、为车，忌太白入荧，主盗。荧入太白主火惊，玄武、天蓬主失盗。水路忌惊门来克，恐伤船，艮无水，利旱路。休加景主泥泞难行。若二门入墓，主关梁阻隔，行动艰难。

### 占出行（卷八）

以日干落宫为出行谋干之人，所往何方，有吉门、吉格来生日干之宫者，往必大利。或不得奇门吉格来生，而与日干比和者，亦利，反此不利。再被凶门、凶格来冲克日干者，大凶。若临空亡、入墓之方，或日干年命刑、墓、空亡方位者，不利。

## 奇门法窍补充

> **source:** [[奇门法窍（锡孟父子）]]
>
> 本节出自《奇门法窍》卷四「占行期」「占道途吉凶」「占谋害」「占出行水陆吉凶」「占避难逃避方向」「占登舟船主善恶」「占出行经商地方吉否」「占出差平安」等章节，系（飞盘体系）飞盘奇门对出行预测的独特论述。

### 占行期（飞盘体系）

以**时干**为起行之人，**日干**为牵缠之人，**开门**为起行之期，以时干在内、在外并开门下干决定。

### 占出行经商地方吉否（飞盘体系）

以其所往之方得三奇吉格生年命日干落宫者为上吉。

### 占登舟船主善恶（飞盘体系）

以**震宫**为船，所得星为船主之善恶，以九星吉凶决之。

### 占道途吉凶（飞盘体系）

以**时干**所落之宫得**蓬**为盗贼；如蓬不遇，再时干所加本宫得三奇吉门旺相诸吉格，不妨。

### 占谋害（飞盘体系）

**庚**为仇人，**甲**为己身，生克决其有无谋害。

**行路遇人同往善恶**：以**时干**为己身，看上得何星临之，以九星吉凶决其善恶，休旺定其吉凶。

### 占出行水陆吉凶（飞盘体系）

以**休门**、**景门**所乘之宫分水、旱二路，二门落宫、天地二盘得奇仪吉格相乘为吉。

### 占避难逃避方向（飞盘体系）

以**杜门**、**丁己癸**、**六合**、天上**太冲**及**生门**所临之方，又生本时干则吉；再有三奇吉星大吉，反此不利。

### 占出差平安（飞盘体系）

以**日干**落宫为出差之人，**时干**落宫为所差之事，以生克决之。

### 出自

《奇门法窍》卷四·占行期、占出行经商地方吉否、占登舟船主善恶、占道途吉凶、占谋害、占出行水陆吉凶、占避难逃避方向、占出差平安（锡孟父子），参见 [[奇门法窍（锡孟父子）]]。

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第十二章 出行预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

以[[日干]]、[[年命]]落宫为出行之人，以所往之方向为目的地。

**出行吉凶判断**：
- 所往方宫位生日干、年命落宫者吉，出行必顺利
- 所往方宫位克日干、年命落宫者凶
- 所往方向宫与日干、年命宫比和者，出行也顺利
- 日干、年命宫乘吉门、吉星、吉格、吉神来克所往之方向，也可出行，出行吉利
- 所往方乘吉门、吉格、吉星、吉神来克日干、年命宫，最好不要远行，勉强出行必不顺利
- 所往方乘凶门、凶星、凶格、凶神来克日干、年命宫，切莫出行，出行则必遭不顺，会有灾难

**交通工具分类判断**：
- **乘车出行**：以[[景门]]落宫为道路，以[[伤门]]落宫为车辆，日干、年命落宫为出行之人。遇太白入荧主遭盗贼。临[[天蓬星]]、[[玄武]]主路上丢失财物或遇小偷、劫匪
- **乘船出行**：以伤门为船只，[[休门]]为水路，日干、年命落宫为出行之人。若遇[[青龙逃走]]或[[白虎猖狂]]凶格，必遭遇风暴。逢[[朱雀投江]]、[[腾蛇夭矫|螣蛇夭矫]]凶格，则有沉船之危险
- **乘飞机出行**：以[[开门]]落宫为飞机，以[[九天]]落宫为航线，日干、年命落宫为出行之人。九天宫生开门宫，开门宫生日干、年命宫，出行顺利

### 奇门启悟案例1：为徐研成先生出行敦煌预测实例

- **时间干支**：己卯年丁卯月丙戌日癸巳时 阳6局
- **值符值使**：值符甲申庚[[天任星]]，值使[[生门]]
- **求测背景**：1999年4月4日上午9点40分左右，朋友徐研成（1956年丙申年出生，喜欢画画、收藏字画、写毛笔字）前来求测。当晚要乘飞机去甘肃敦煌市，问坐飞机安全否，能否顺利拿回想要的古画（那边有熟人帮忙联系好了）
- **分析**：
  1. **断今天上不了飞机，明天也走不成，这次去敦煌只是玩玩而已，想要的古画也搞不回来**：日干为求测人，年命亦为求测人。今徐研成年命丙与日干都为一个信息符号，丙乘[[天辅星]]落乾宫，乾宫格局为丙加戊[[飞鸟跌穴]]，丙到乾宫又为三奇入墓，又[[开门]]落乾宫为[[伏吟]]，入墓为不动之象，伏吟亦是不动之象。开门代表飞机，伏吟当然不动了。乾宫地支为戌、亥，求测日为丙戌，明白丁亥，这两个日子都属乾宫所管辖的时空段，故断今天上不了飞机，明天也走不成（乾宫三奇入墓、开门伏吟）。[[景门]]代表字画，今景门落离宫来克日干及年命丙之乾宫，又景门所落之离宫为日柱之空亡宫，故想要的古画也搞不回来。
  2. **断今天走不成的原因是天气不好，雾太大，能见度太低，今天晚间（丙戌日）的航班肯定取消**：开门为飞机，九天落宫为航线，今九天落离九宫，离宫落有[[天蓬星]]、景门，蓬星又上乘天干壬，壬为水，蓬星亦为水。景门为火为能见度。蓬星于卯月为旺，壬水、蓬星在景门火的作用下必见升腾之气，卯月这个季节东北地区很少下雨，必是大雾。又九天所落之离宫克开门（飞机）所居之乾宫，即航线（九天宫）克飞机（乾宫），景门受壬水、蓬星之克，故能见度太低，今天的航班肯定取消（伏吟不动）。
  3. **断第二天晚间（丁亥日）仍然走不了，只有到了第三天晚间（戊子日）雾才能散开，飞机才会恢复正常航行**：第二天丁亥日仍属乾宫所管辖之时空段，乾宫依然受航线（九天）离宫所克制，又丁亥日之日干丁落兑宫，九天所居之离宫（航线）依旧来克兑宫，这些信息足以说明第二天（丁亥）仍然走不了。第三天为戊子日，子午相冲，离宫之雾气被子相冲则必然散开。年命丙落乾宫为入墓，开门居乾宫为伏吟，戊子日的日干戊落巽宫来对冲乾宫，入墓、伏吟被冲则必出、必动。所以代表飞机的开门遇冲必然动起来。又开门所乘之干为起行之日，今开门上乘暗干戊，故必应于戊子日飞机能够起飞。
- **结果**：徐研成不信，认为自己摇过六爻卦一切顺利平安，执意要走。第二天（丁亥日）早上8点多钟来电说昨晚飞往敦煌的航班取消了，由于这边放大雾，能见度太低，飞机无法起飞。问今天晚间能否走成。刘文元断今天晚间仍然走不成，只有到了明天（戊子日）雾才能散开。第三天（戊子日）早上徐研成又来电说在沈阳又住了一个晚上，如果今天晚上再走不了就返回瓦房店不去敦煌了。刘文元断今天晚上肯定能走成，飞机会按正点准时起飞。第四天（己丑日）早上8点左右，徐研成从敦煌来电说昨晚飞机正点起飞，天上的雾也散了，只是有风。在敦煌见到不少古画，可就是没找到想要的那几幅画，这次就算去旅游了。整个出游过程全部测准。

### 奇门启悟案例2：张永宏从日本东京乘飞机回国预测实例

- **时间干支**：丁亥年庚戌月己丑日辛未时 阴3局（起局时间为第二天飞机起飞时间）
- **值符值使**：值符甲子戊[[天冲星]]，值使[[伤门]]
- **求测背景**：2007年10月21日上午，学生张永宏（壬子年出生）从日本来电，明天要从东京乘坐飞机到大连周水子国际机场下飞机，飞机在东京起飞时间换算成北京时间是13点20分。问坐飞机顺利否
- **分析**：
  1. **断明天下午乘坐飞机回国会一路平安，可以放心起程**：[[开门]]为飞机，现开门落震三宫。[[九天]]为航线，九天落坤二宫。震宫克坤宫，即开门（飞机）宫克九天宫（航线），故飞机很安全。张永宏年命为壬子，壬乘[[天任星]]吉星落巽宫，巽宫又落有吉门[[休门]]。巽宫格局为壬加乙小蛇得势，女人柔顺，男人通达。巽宫与开门之震宫相比和，故断乘飞机回国会一路平安，可以放心地起程。
  2. **建议将日元分散开放置在不同行李中，所带日元数目为6或7，下飞机后经过检查出站口会很顺利地走出来，不会任何风险**：这个判断结论是从申时（下午3点40分以后到达机场时间）的奇门局中得出来的。在申时的奇门局中，[[杜门]]落离九宫代表检查部门，[[景门]]代表眼睛、寻视等信息。张永宏年命壬子均落坎宫，并乘天任吉星、开门吉门。坎宫冲克离宫，故可以轻而易举地躲过检查。坤二宫（景门落宫）虽来克坎宫，但坤二宫逢空亡（己丑日午未空亡），故不克。由此可知，下飞机走出检查站口时会很顺利地走出来，不会任何风险。建议所带日元数目为6或7，因6数为乾六宫，7数为兑七宫，乾、兑两宫均可化泄景门所居之坤二宫对年命壬子所落之坎宫的克制，从而最大限度地保证携带数额较多的日元能够顺利地走出检查站口。
- **结果**：10月22日下午4点40分左右，张永宏从大连来电说从日本东京上飞机一直到大连周水子机场下飞机，最后走出机场出站口，都十分顺利，没有出现半点差错和不顺。

**要点**：乘飞机出行以开门为飞机、九天为航线，开门宫克九天宫（飞机克制航线）则飞机安全；年命落宫旺相乘吉星吉门则出行平安；入墓、伏吟主不动，逢冲则动——这是判断飞机能否起飞的关键；可通过所带物品数目对应宫位来化泄克制，从而降低风险（如带6或7数对应乾兑宫化泄景门宫克制）。
