# 工作就业预测

## 定义与基本属性

工作就业预测是通过奇门遁甲判断求职成败、岗位适合度、工作环境优劣、升迁调动等问题。以开门（事业之门）为工作的核心用神，开门与日干的生克关系是判断一切就业问题的主线。

> **核心原则**：开门为工作单位/事业之门，日干为求职者。开门生合日干则工作对求测人有利，反之则不利。

## 核心用神

### 主要用神
| 用神 | 含义 |
|------|------|
| [[开门]] | **工作单位**、事业、岗位、职位 |
| [[日干]] | 求职人/求测人本身 |

### 辅助用神
| 用神 | 含义 |
|------|------|
| [[时干]] | 所测之事（求职/升迁这件事） |
| [[值符（八神）|值符]] | 上级领导、老板、总经理 |
| [[年命|太岁]] / [[年命|年干]] | 最上级领导、单位的主管部门 |
| [[值符与值使|值使]] | 人事部门、直属上级 |
| [[用神|月干]] | 同事、同级别员工 |
| [[时干]] | 下属、基层员工（兼看） |

### 不同情况
| 情况 | 用神选择 |
|------|----------|
| 求职面试 | 日干 + 开门 + 值符 |
| 在职升迁 | 日干 + 开门 + 太岁/年干 |
| 工作调动 | 日干 + 开门 + 马星 |
| 辞职能否 | 日干 + 开门 + 时干 |
| 与同事关系 | 日干 + 月干 |

## 取用神方法

1. **测求职**：看[[开门]]与日干的生克关系。
2. **测面试**：看[[值符（八神）|值符]]（面试官）与日干的生克。
3. **测升迁**：看[[年命|太岁]]/[[年命|年干]]（上级领导）与日干的生克。
4. **测调动**：看[[马星]]是否在日干或开门宫发动。

### 取用流程
```
排盘 → 定位日干落宫 → 定位开门落宫 → 看生克关系 
     → 看值符/年干（领导） → 看八门八神旺衰 
     → 综合判断吉凶应期
```

## 判断要点

### 求职成败判断
1. **[[开门]]生[[日干]]**：工作单位欢迎求职者，求职成功（★★★★★ 最佳）
2. **[[日干]]生[[开门]]**：求职者向往单位，能否进去不确定（△中）
3. **[[开门]]与[[日干]]比和**：求职顺利，人与单位匹配（▲吉）
4. **[[日干]]克[[开门]]**：求职者可掌控局面，但可能不满意
5. **[[开门]]克[[日干]]**：单位排斥求职者，求职失败（▼凶）

### 工作环境判断
1. **开门临[[休门]]**：工作清闲，但可能没发展
2. **开门临[[生门]]**：工作有收获，效益好
3. **开门临[[伤门]]**：工作辛苦劳累，易有工伤
4. **开门临[[杜门]]**：工作技术性强，但可能闭塞
5. **开门临[[景门]]**：公开透明，适合文职策划
6. **开门临[[死门]]**：单位死气沉沉，没有前途
7. **开门临[[惊门]]**：单位竞争激烈，压力大

### 领导关系判断
1. **[[值符（八神）|值符]]/[[年命|年干]]生日干**：领导赏识，有提携之象（▲吉）
2. **日干生[[值符（八神）|值符]]/[[年命|年干]]**：迎合领导，但未必有效
3. **日干克[[值符（八神）|值符]]/[[年命|年干]]**：不服领导，可能导致矛盾
4. **[[值符（八神）|值符]]/[[年命|年干]]克日干**：领导打压，职场不利（▼凶）

### 升迁调动判断
1. **日日相生，马星到日干宫**：工作变动在即
2. **马星临[[开门]]**：单位有变动（重组/搬迁）
3. **日干临[[九天]]**：有升迁之象
4. **日干临[[九地]]**：稳定不动，难以升迁
5. **日干临[[开门]]+[[九天]]+马星**：升迁调动的最佳组合

### 应期判断
- [[开门]]旺相临日干之日（入职上班日）
- 马星发动之日（人事变动日）
- [[值符（八神）|值符]]生日干之日（面试通过日）
- 空亡填实之日（等待期结束日）

## 实占要领

1. **先定位开门**：开门是工作预测的第一用神，先看它在哪一宫、旺衰如何。
2. **生克定吉凶**：开门与日干的相生相克是判断一切就业问题的主线。
3. **生门看收入**：如果关注工资待遇，兼看[[生门]]（利益）与日干的关系。
4. **八门看环境**：开门所临八门，直接反映工作单位的氛围和性质。
5. **值符看领导**：面试/晋升必看值符（主考官/直属上级），年干/太岁看更高层领导。
6. **马星看变动**：马星是关键——没有马星参与，调动升迁都不会发生。
7. **八神看趋势**：九天主上升、九地主稳定、值符主贵人、螣蛇主变数。

《开悟之门》中未提供此预测类型的独立完整案例。但张志春老师在书中的劳动纠纷案例（见官司诉讼预测）和开店经营案例（见经营求财预测）中涉及工作就业相关判断，可参考以下核心要点：

- **天辅星文职、天冲星武职**：日干临天辅旺相得奇则文职有成；临天冲旺相得奇则武职有成

- **工作变动**：戊+庚或庚+戊格局（值符飞宫/伏宫）主换地方、换人
- **急则从神缓从门**：紧急情况下可从值符方位采取行动，从容情况下可选吉门吉方行事

## 上元经补充

### 科举/应试取仕的核心判断体系

《奇门遁甲上元经》职占章指出，科举取士不是单纯的考试——最终决定权在上级官员或皇帝手中。因此**丁火、景门只反映了试卷答题情况，不能决定是否被录取**。

#### 决定录取的第一因素：符使

| 组合 | 结果 |
|------|------|
| 符使俱吉 | 金榜题名 |
| 符凶使吉 | 名不位前（主要官员不认可，名次居末尾） |
| 符吉使凶 | 好事成空（考前上峰有意录取，具体操作环节横生事端） |

> **注意**：符使在科举试占中有先后顺序——符为天象在先，使为人盘在后，最终结果看值使落宫。

#### 决定录取的第二因素：太岁

- 一年之内，太岁影响力大于值符
- 但跨越年度（如笔试→次年面试）时太岁更替，旧太岁不再发挥作用
- 太岁生助日主 → 需同时与值符形成符号关联才能发挥推荐效能（太岁不会越过值符直接跟值使商量）

> **案例**：年轻精英竞聘，董事长口头说"我很欣赏你"，但没有交代人力部门在行动上支持 → 晋升成镜花水月。太岁单方面生助日主 ≠ 实质帮助。

#### 符使与日主的关系：不排斥克制

古代官场讲究上克下——上级对下级具有克制才是权力运行的基础。符使克制日主合乎常理。唯独符使与太岁构成三合/三会来冲克日主 → 所有决定录取的因素都站在了对立面 → 录取可能性极低。

### 科举中符使与日主的关联判断

1. **宫内干支符号相通**：如考生宫壬加乙 + 值符宫乙加戊 → 通过乙/戊符号连接
2. **宫位合会关系**：三合力最强，可抵消个别宫位凶象。符使与日主三合成局 → 即使符使某宫出现凶象，也被三合抵消。

> 出处：《奇门遁甲上元经》 — 参见 [[奇门遁甲上元经（张大春）]]职占章

### 与考试/文章相关符号的精细区分

| 符号 | 层次 | 角色 | 特殊性 |
|------|------|------|--------|
| **天辅星** | 星盘（天） | 文曲星，代表先天学习潜质/顶层高端文化 | 必须与考生同宫才算直接助力（自宫星力最强，外宫星力量有限） |
| **朱雀**（飞盘独有） | 神盘 | 笔锋锐利、观点鲜明 | 双面：优秀文章 vs. 因言获罪 |
| **六合** | 神盘 | 文章旁征博引、融合多观点 | 中庸平和，衰弱则东拼西凑类抄袭 |
| **丁奇** | 人盘（干——阳动） | 考前→书写之象（试卷"还没写"用丁） | 上元经首次明确区分丁与景的时序差异 |
| **景门** | 人盘（门——阴静） | 考后→阅检之门（试卷"已写完"用景） | 也可表示负责收卷阅卷的机构 |

**丁与景的组合判断（主客观差异）**：
- 丁吉景吉 → 主观感受与阅卷人感受一致，双方满意
- 丁吉景劣 → 自我感觉良好但分数不理想
- 丁劣景良 → 有贵人帮忙（房师力荐），文章不好但被推荐

> **重申**：丁、景不能决定最终录取结果（决定权在符使、太岁）。

### 科举监察——开门在考试中的特殊角色

开门在科举考试中类似现代监察机构，负责检验考生资格及维护考场秩序。开门不能用来断是否被录取：
- 开门逢空 ≠ 没被录取
- 开门克制日主需满足两个条件：(1)直接冲克不能明克暗合 (2)开门与值符或太岁通过合会构成内在联系

### 孩童前途代占

古代孩子出生后家长代占前途：

| 用神 | 反映 |
|------|------|
| 年命宫星辰 | 先天品性与基因 |
| 年命宫所临之门 | 以后人生道路/社会人际关系 |
| 天盘天干 | 能力大小与能达到的高度（壬加戊 = 小蛇化龙上升过程；壬加辛 = 由阴入阴，结局不好）|
| 落宫月令旺衰 | 是否有施展抱负的舞台 |

**符使在终身预测中的作用**：
- 值符 → 事业拼搏中能达到的顶尖高度
- 值使 → 最终结局/人生归宿

> 年命、符使必须同看：符为高点，使为结局，两者俱佳才是圆满人生。

**职业方向选择**：分别观察八门落宫的吉凶旺衰，选择搭配最好的宫位为"出路"。不一定是开/生/休三吉门最佳——死门丁加戊落离宫临天英 = 名医之象。如多门吉凶程度相似，以和合年命落宫者优先。

### 进士及第后所授官职的判断

#### 以开门判断工作单位

开门落宫内部搭配 → 单位好坏（如壬加乙落乾宫 = 单位效益扭亏为盈）：

| 开门与日主关系 | 辩证判断 |
|---------------|---------|
| 开门冲克日主 | 不一定是职位不利 —— 格局吉祥时 = 工作压力大而非被革职（类似子平七杀） |
| 开门生合日主 | 不一定是利 —— 开门壬加己且天干五合合于日主 = 负能量意象合到自己身上 |
| 开门印比日主 | 不一定是帮助 —— 开门格局破败 = 即将破产的公司 |

#### "文职看开，武职看杜"之批判

该说是主客不分、阴阳未分的错误：
- 开门可指代工作机构——无论多封闭的单位，工作的人必须通过大门进入 → 开门指代工作具有普遍性
- 杜门是封闭/阻塞 → 切断涉密人员与外界联系 → 落脚点在于人员本身
- **杜门临于日干或年命且宫内格局适当** → 才可断从事保密性质的工作

#### 官职升降任免（核心）

**两大决定因素**：(1)上级态度（太岁、值符）(2)自身能力

太岁与值符力量合与不合：
- 岁月同宫 → 力量一致，吉凶易辩
- 岁月相左 → 观值使（值使倾向于命主 → 提拔手续和流程正在进行）
- 二克之下 → 仍有擢升可能（唯见于不世之才落于旺相之宫 + 月令之助——极端条件）

> 现代文明社会时干宫最重要（时干=人民群众），封建社会时干宫作用不大。

#### 职位调动的判断

**调动的前提**：主客双方通过马星引动形成合会关系。

| 条件 | 说明 |
|------|------|
| 仅单宫临马星 | ≠ 调动（只表示策划变动或因事情来回奔波） |
| 日干/年命（主）+ 开门/值使/时干（客）+ 马星引动 | 主客共同引动才能表达调动之象 |

**必动格局**（单个宫位的格局意象）：
- 戊加庚（飞宫）、乙加辛（龙逃走）、丙加庚（必去）、庚加丙（贼必来）、庚加壬（移荡）
- 庚加戊 ≠ 必动（"伏宫"——想动也动不了，处处受打压）
- 壬加庚 ≠ 必动（太白擒蛇，无移动象意）

**大象阴阳 + 格局不能简单对应升降**：
- 阳性格局（戊加丁、戊加丙等）→ 工作得心应手，施展才能 ≠ 一定升迁
- 阴性格局（己加辛、壬加辛等）→ 工作不顺利、阻碍 ≠ 一定辞职开除

**开门逢冲击与变动**：
- 开门辛加戊落坎宫（子午两重暗冲）≠ 调动（"困龙被伤"中"困"字导致移动困难）
- 开门九天 ≠ 调动（需得格局支持或马星引动合会）
- 开门击刑 ≠ 辞职（是外在伤害/人际关系倾轧，需格局决定是否构成移动）
- 开门天干入墓 → 真墓（死气沉沉）和假墓（马星引动/合会出墓→先抑后扬）

**开门落震巽二宫门迫的差异**：
- 震宫力强 → 波澜较多、棘手的麻烦事 → 遇到多重负能量时工作干不长
- 巽宫力柔和 → 进退维谷、面临多个选择（大学生找工作）、反复不定（反吟非马上变动）

> 出处：《奇门遁甲上元经》 — 参见 [[奇门遁甲上元经（张大春）]]职占章

### 新岗位与旧岗位的二选一判断

**前提**：必须确认新工作是否为真（不是上级空口许诺）：
- 太岁、值符是否对日主有实质性支持
- 日主或时干是否空亡（空 = 镜花水月）

**新旧工作的用神定位**：
- 开门 → 现有工作（占测时已在原单位，开门反映与原工作密切相关的信息）
- 时干 → 新工作（时干既有即时性表述，又有新近事物意味）

> **纠偏**：不是开门地盘干转宫后看新工作（开门作为没有生命力的物质系统，不能主动随时间变化）。

### 犯事入狱的占断体系

#### 己测（自由状态下自测）

- 不以辛金为主要用神（辛为锁链→当事人尚为自由身）；只有被控制后代占，辛才能指代当事人
- 首观日干/年命宫内搭配旺衰 → 吉旺则无事；负能量符号（己加庚、庾加己、癸加辛、壬加辛 + 击刑/入墓/伤死杜门）→ 必受惩罚

#### 代占（已失去自由后）

辛金为用神：
- 天盘辛 → 案件处于收集证据阶段，尚未正式刑罚，有翻盘可能
- 地盘辛 → 已判刑，需观察是否还有上诉机会

**阴干牢狱意象区分**：
| 符号 | 意象 |
|------|------|
| 辛 | 细锁链，身带刑具之人 |
| 庚 | 肉刑/刑罚，庚下之干 = 刑罚应期 |
| 壬（阳水） | 有一定活动空间的劳役场所 |
| 癸（阴水） | 完全限制自由的狭窄囚室 |
| 癸加辛 | 阴上加阴，看不到光明希望，难出头 |

**辛逢冲的判断**：
- 暗支刑冲 → 出问题的原因或与其他囚犯矛盾，不是出狱
- 辛加戊落坎宫（辛暗支午冲坎宫子）→ 有出去的可能，但需年命/值符等其他宫助力才能正常出狱（否则为越狱逃出）
- 癸落坤宫（三杀并临：墓/刑/冲）→ 更凶恶，非冲网而出
- 壬落乾宫（旺而逢冲）→ 更换关押地点
- 庚辛同宫 → 暴力打斗意象（屈打成招）

## 奇门法窍补充

> **source:** [[奇门法窍（锡孟父子）]]
>
> 本节出自《奇门法窍》卷四「占升迁」「占徵召」「占朝觐」「占上官」「占考绩」「占所任地方吉凶」「占官幕」「占差遣」「占谋馆有无」等章节，系（飞盘体系）飞盘奇门对工作就业预测的独特论述。

### 占升迁（飞盘体系）

以**开门**为官，加生旺宫有奇格者必升；**岁干**乘吉格来生年命日干宫者均吉。生擢武官看**杜门**同论。

**又法（卷四·占升迁）**：上官以克直符为官星，以直使之下为地方，以分野决其何处。官克宫门 → 此地不宜，另图别处；若宫门克官星 → 官尚未升迁，主迟。

### 占徵召（飞盘体系）

以**太岁**为皇恩，**月建**为铨部，**日干**为己身，生克决其召否。

### 占朝觐（飞盘体系）

以**岁干**为天子，为引见之人，以生克日干宫者吉凶决之。

### 占上官（飞盘体系）

以上官时所向之方所得宫神，如吉格生旺则吉，休囚废没则凶，乘凶格更凶，主罢黜。

### 占考绩（飞盘体系）

以**直符**为大宪，**开门**为官，生克吉凶决之。

### 占所任地方吉凶（飞盘体系）

以**禽**落宫为帝畿，余为升地，各宫奇仪为分野。以**开门**落宫上看：
- 上有**天蓬** → 为盗贼
- **庚** → 为兵乱
- **丙壬** → 旱涝
- 不犯此者平安

### 占投武（飞盘体系）

以**天冲**为武士，**直符**为帅主，生克决其收用。

### 占干谒（飞盘体系）

以**休门**宫为所见之人，**时干**宫为干谒之人，以生克吉凶决之。

### 占官幕（飞盘体系）

以**辅星**为求幕之人，**甲子戊**为官长，**开门**亦为官长，以生克决之。

### 占求荐（飞盘体系）

以**甲子**为求荐之人，**天乙**为推荐之人，生克决之。

### 占差遣（飞盘体系）

专以**开门**之星决之。看应差之人何年干、日干为开门——所冲者去，不冲者不去。

### 占退役（飞盘体系）

以**开门**为官长，**日干**为退役，生克决之。

### 占应役（飞盘体系）

以**开门**为官长，**日干**为应役之人，以生克旺相决之。

**又法**：以**直使**为己身，以生克休囚断之。

### 占投主（飞盘体系）

以**甲子戊**落宫为本人**日干**落宫决之，以甲子戊生者宜投。

### 占卸事能否（飞盘体系）

以**日干**落宫为卸事之人，**时干**落宫为所卸之事，比者不能卸，生克决之。

### 占领文迟速（飞盘体系）

**丁**为文件，与**直符**相生速，克则迟。丁在何宫相生即以本宫干支定其日期。

### 占官事缓急（飞盘体系）

以**时干**为己身，**直符**为官长，**六丁**为公文，**直使**为公差，以内外宫并生克决之。

### 占给假（飞盘体系）

以**直符**为尊长，**天乙**为卑小，克者不准。

### 占废员起用（飞盘体系）

以**岁干**为天子，**日干**为引见之人，生克乘奇吉旺相决之。

### 占保劾（飞盘体系）

以**日干**宫为保举之上司，**日干**为应保劾之人，论生克决之。

### 占谒陵（飞盘体系）

以**杜门**为山陵，**岁干**落宫为天子，冲旺生者为谒。

### 占税务衰旺（飞盘体系）

以**生门**落宫为关税，**日干**为收税之人，**开门**为税官，以生克旺相休囚决之。

### 占掣签远近（飞盘体系）

以**开门**落宫为省分，为掣之人，落内四宫者近，外四宫者远。

### 占简放（飞盘体系）

以**岁干**落宫为天子，**日干**落宫为应放之人，生合者吉，休克者否。

### 占派差务否（飞盘体系）

以**月干**为落宫为上宪，**时干**落宫为委派之人，生克决之。

### 占文武官补否（飞盘体系）

以**开门**为文职，**杜门**为武职，以生克休旺决之。

### 占在任动静（飞盘体系）

以**开门**落宫为动静，**月干**为上宪——比和者不动，带奇吉生者主升，克者不利。

**又法**：以**开门**为上司，**日干**为本身，生合者吉。

### 占捐劝踊跃否（飞盘体系）

以**开门**为官长，**生门**为富户，以生克决之。

### 占谋馆有无（飞盘体系）

以**天辅**为师长，为求馆之人，**天芮**为东主，以生克决之。

### 占奏事准驳（飞盘体系）

以**景门**落宫为陈奏之事，**日干**为奏事之人，**岁干**为天子，以奇吉生克决之。

### 理论补充

刘文元先生在大量实践中发现，仅以[[开门]]代表工作、单位、岗位，以[[杜门]]代表武职部门工作、岗位，远不能满足现代社会种类繁多的工作、职业、岗位的预测需求。必须细致分类，将九星、八门对应到具体工作部门，方能满足现代社会复杂的求职预测。

**辅助用神定位**：通常以[[年命|年干]]代表上级领导，以[[值符（八神）|值符]]代表直接上司，[[用神|月干]]代表同事，[[日干]]、[[年命]]为求测人，以[[时干]]代表下级及单位员工。

**求职成败判断**：
- 日干、年命落宫旺相，又得吉门、吉格、吉神、吉星者 → 自身条件好，再得用神来相生（如求测者欲从事教育事业，取天辅星为用神），则求职求工作必顺利
- 日干、年命落宫克用神落宫 → 经过努力也能得到工作岗位
- 日干、年命落宫不得吉门、吉星、吉格、吉神，又不乘旺相气者，且又受用神宫来冲克者 → 求职求工作必然不遂
- 日干、年命与所求工作之用神落同宫（如求测人年命为丙寅，其欲选择的工作岗位是设计院，而年干丙与景门落同宫），若该宫不空亡 → 此工作求之必成

### 奇门启悟案例1：为范广利预测工作及运气实例

- **时间干支**：丙子年辛卯月壬戌日丁未时 阳9局（飞宫法起局）
- **值符值使**：值符甲辰壬[[天辅星]]，值使[[杜门]]
- **求测背景**：1996年3月26日下午2点多钟，范广利（1960年庚子年出生，身着紫红色上衣）前来求测，坐巽位，显得沉静、压抑，未报生日时辰。问"近期工作上遇到了麻烦，想调换工作"
- **分析**（刘文元先生以测来意切入，结合坐宫与年命综合判断）：
  1. **测来意——断范肠道有病经常肚子疼已四年、从事财务工作、近期受单位一把手二把手挤兑想调换工作**：范坐巽宫，巽宫格局为庚加壬[[小格（上格）|小格]]，庚乘[[天芮星]]（病神），巽主肠道，庚主大肠，巽宫落有[[死门]]主疼痛，巽宫数目为四，又巽宫格局为庚加壬，92年壬申年到96年正好四年，年命庚子，故断肠病四年。范坐巽宫为地盘值符之宫（甲辰壬），值符主财务；年命庚落坤宫地盘，格局为戊加庚，戊为钱财；年命地支子在坎宫，坎宫落有生门亦为钱财，故断从事财务工作。值符落乾宫正冲克巽宫，值使落兑宫也来克巽宫，值符为一把手、值使为二把手，故断受两位领导挤兑。年命庚落巽宫形成庚加壬[[小格（上格）|移荡格]]，又被日柱壬戌落乾宫相冲，地盘庚落坤二宫又临日柱马星宫（寅午戌马在申），动象明显，但巽宫临死门，故不能马上调走。
  2. **断去年年末一管财务女同事想以工作名义动用五万元公款，范按程序未同意，那女同事与一把手有特殊关系**：时干宫为先锋门，时干丁乘[[天心星]]加[[开门]]落艮八宫，冲动坤二宫，坤宫格局为戊加庚[[飞宫格]]，戊为资金，庚为范年命；艮宫格局为丁加乙，开门主工作；乙为去年太岁岁干（乙亥年），艮宫主丑寅二支，丁乙为阴，故断去年年末；丁为玉女，艮宫又乘太阴，故断女同事；戊落坤宫，坤主二五八数，戊乘天英星火生土土旺取五数，故断五万元。丁乘天心星落艮八宫临太阴生值符乾宫，太阴主暗中阴私，地盘丁奇落乾宫与天盘值符辅星所带天干壬相合，丁与壬为淫荡之合，故断女同事与一把手有特殊关系。
  3. **建议范主动调往北边单位是最佳选择，到新单位继续做财务，新领导会器重他，清明节后30天内可到新岗位上班**：范坐巽位年命庚亦落巽宫，从奇门择吉来讲，只有震宫（与巽比和）和坎宫（生助巽宫）有利。震宫有二个弊端：被值符宫来克、被值使宫来冲克。坎宫为水生范年命庚及所坐巽宫，坎宫被值符宫（乾）、值使宫（兑）来相生，坎宫又临太岁（子），并且落有[[天任星]]吉星、生门吉门，又临乙奇，恰好范年命子也在坎位。巽宫格局为庚加壬移荡格（小格），正被值符乾宫所冲克，巽宫申辰半拱水局（甲申庚、甲辰壬），合待冲、冲待合，既然巽宫被值符宫所冲，故必有申子辰三合水局之应，子位（坎宫）是其不二之选择。坎宫格局为乙加己，乙乘天任吉星，坎宫又落有生门吉门，生门主财，故断到新单位后继续做财务。新值符（未来领导）天禽星落兑宫生坎宫，故新领导会器重范。范坐巽宫格局为庚加壬移荡格，求测日为壬戌日故也为日格，且巽宫为内盘事必应速。求测时正值辛卯月，过了清明节便是壬辰月，正应庚下之壬，辰亦在巽位，即庚见到壬（壬辰月）便要移荡（调动工作）了。
- **结果**：4月8日（乙亥日），范广利高兴地打来电话：工作调成了，正是所测的北边那个单位，还是让管财务，单位领导对他很好。整个预测完全应验。

### 奇门启悟案例2：用奇门预测帮助迟骋选择工作单位实例

- **时间干支**：丁亥年庚戌月辛巳日癸巳时 阴9局（转盘奇门）
- **值符值使**：值符甲申庚[[天柱星]]，值使[[惊门]]
- **求测背景**：2007年10月14日上午10点左右，学生姜淑英带着徐淑英女士前来为儿子迟骋（1985年乙丑年农历4月出生）求测工作选择。迟骋就读于中国民用航空大学飞行器动力工程专业大四，面临多家用人单位预签合同：中国南方航空、海南航空、香港九龙航空、大连/沈阳/成都等多家航空单位，还有留校任教选择（50多名应屆生报名仅录7人）。徐淑英不知所措，希望预测帮助儿子定位
- **分析**：
  1. **建议迟骋选择留校任教成为大学老师是最理想选择**：由于是徐淑英前来为儿子求测，故取时干落宫及儿子年命落宫为参考主线。时干癸乘[[天辅星]]落坎一宫，迟骋年命乙亦落于坎宫地盘。坎宫落有[[休门]]为门伏吟，有继续留在学校任教（天辅星为老师）之象。时干癸于地盘落巽宫，巽宫又临值符天柱星，柱星为兑卦，兑为说，巽主教化，迟骋留校任教信息甚明。从年命落宫分析：迟骋年命乙于天盘乘[[天蓬星]]落坤宫，坤宫又落有[[死门]]，星门俱凶不利；又从日柱辛巳来查空亡，坤宫为空亡宫，即天盘年命乙所落之处为落空亡。迟骋年命乙于地盘落坎宫，坎宫上乘天辅星，坎宫又落有休门，星门俱吉且乘[[六合]]吉神，格局为癸加乙[[华盖逢星]]，贵人禄位，常人平安，门吉则吉，门凶则凶。由此可知：迟骋年命在天盘（坤宫）不利（既乘凶星凶门又落空亡）→ 应聘各大航空公司均为不利（航空公司主要以天上事为主，故以天盘来应）；年命在地盘（坎宫）既乘吉星又乘吉门还有吉神，并且不逢空亡 → 应聘于留校任教（天辅星）是最理想选择。
  2. **断虽有50多名报名留校任教、名额仅7人，但迟骋最终必被学校选中录用**：月干为同学、同行竞争者，今月干庚乘[[天柱星]]凶星落巽宫，虽临值符，但巽宫落有[[杜门]]有不通之义，又逢庚加癸[[大格]]大凶之格百事凶；太岁丁落乾宫，乾宫冲克月干庚所落巽宫，太岁代表大学，故同学、同行竞争者处于劣势。迟骋年命乙乘天辅文曲吉星落坎宫，又逢休门吉门、六合吉神、癸加乙吉格，更重要的是太岁丁奇落乾六宫来生坎宫，即学校看中、认可迟骋各方面的条件。景门为面试，今景门落离宫来生迟骋年命乙所落之坤宫，故面试必能通过。辅星为学校、老师，于坎宫里辅星与迟骋年命乙同宫，又受太岁丁之乾宫来生扶，迟骋必会被学校选中录用而成为一名大学老师。
- **结果**：经过一番指点，徐淑英最后让儿子迟骋报名参加留校任教的考核。10月19日上午10点左右，姜淑英再次来电说当天下午4点进行面试考核，问能否过关。刘文元断面试一定顺利通过。果然迟骋顺利通过学校面试等考核，于2007年11月9日经过最后一个考核项目——体检，最后体检也完全顺利通过。迟骋终于被中国民用航空大学正式录用，成为一名合格的大学老师。

**要点**：刘文元先生独创的九星八门对应工作部门分类表，突破了传统仅以开门（文职）杜门（武职）两分法的局限，使求职预测能精准对应现代社会种类繁多的职业岗位；测来意时重视求测者所坐方位、值符值使与坐宫关系、年命落宫与值符值使关系、时干时支宫"四点合参"法；为子女代测求职时，取时干落宫及子女年命落宫为参考主线，以天盘应天上事（航空公司）、地盘应地上事（留校任教）的分辨法是关键。
