# 军事事件预测

## 定义与基本属性

军事事件预测是奇门遁甲最原始的用途。上古时期黄帝与蚩尤之战中，九天玄女授奇门遁甲于黄帝，最初就是为了军事战争。因此，军事预测是奇门遁甲的"本行"，所有应用预测皆从此衍生。庚为攻方（兵器）、值符为主方（统帅），九天九地定攻守之势。

> **核心原则**：九天之上好扬兵（居高临下利攻击），九地之下可伏藏（隐匿埋伏利防守）。此乃军事预测的最高准则。

## 取用神方法

### 第一步：分清攻守
```
判断是谁先发动战争 → 先发动者为攻方（庚）
我方 = 值符（主方/统帅方）
敌方 = 庚（进攻方/来犯之敌）
```

### 第二步：看攻守态势
```
[[九天]]临何宫 → 该宫方适合采取攻势
[[九地]]临何宫 → 该宫方适合采取守势
```

### 第三步：判断胜负
```
值符旺相克庚 → 主方胜
庚旺相克值符 → 攻方胜
双方比和 → 相持不下
```

### 取用流程
```
排盘 → 定位值符（主方/我方） → 定位庚（攻方/敌方） 
     → 看九天九地落宫 → 定攻守策略 
     → 看双方生克旺衰 → 判断胜负 
     → 看八门八神 → 综合判断战术细节
```

## 判断要点

### 攻守策略判断（九天九地）
| 用神临 | 策略 | 古文 |
|--------|------|------|
| [[九天]] | **采取攻势**，主动出击 | "九天之上好扬兵" |
| [[九地]] | **采取守势**，埋伏防守 | "九地之下可伏藏" |

> **注意**：九天和九地不是按主客方分的，而是按落宫判断——九天在哪个方位，哪个方位适合主动进攻。

### 胜负判断
1. **[[值符（八神）|值符]]旺相，[[庚（阻隔之神）|庚]]休囚**：主方占优，能取胜
2. **[[庚（阻隔之神）|庚]]旺相，[[值符（八神）|值符]]休囚**：敌攻方势大，主方危险
3. **[[值符（八神）|值符]]克[[庚（阻隔之神）|庚]]**：主方能克制敌方（▲主方胜）
4. **[[庚（阻隔之神）|庚]]克[[值符（八神）|值符]]**：敌方克制主方（▼主方败）
5. **[[庚（阻隔之神）|庚]]临空亡**：敌军虚张声势，实力不强
6. **[[值符（八神）|值符]]临空亡**：主方准备不足，不宜应战

### 战术细节判断
1. **[[伤门]]临白虎且克敌方**：打歼灭战的好时机
2. **[[杜门]]旺相**：防御工事坚固
3. **[[太阴]]临九天**：适合夜袭
4. **[[六合]]生合己方**：有盟军支援
5. **[[腾蛇|螣蛇]]临庚**：敌军使诈，不要轻信
6. **[[景门]]临九天**：情报准确，可行动
7. **[[景门]]临螣蛇**：假情报，不要上当
8. **[[死门]]临己方**：有重大牺牲，需谨慎
9. **[[休门]]临己方**：需要休整，不宜再战

## 实占要领

1. **九天九地为第一法则**：军事预测的根基是九天九地——"九天之上好扬兵，九地之下可伏藏"。这是不可违背的军事原则。
2. **分清主客**：值符是己方、庚是敌方——自己站哪一边要清楚。
3. **旺衰定实力**：双方落宫旺衰直接反映军事实力对比。
4. **生克定胜负**：谁克谁谁就有可能获胜。
5. **九地看防守**：九地下可伏藏——防守方要善用地势，攻方要谨防敌方埋伏。
6. **九天看进攻**：九天之上好扬兵——居高临下、势如破竹。
7. **八神看战术**：太阴（隐秘）、六合（联军）、螣蛇（诡计）——不同八神提示不同战术手法。
8. **死门最凶**：死门临任何一方的用神，都意味着该方将付出惨重代价。

## 奇门法窍补充

> **source:** [[奇门法窍（锡孟父子）]]
>
> 本节出自《奇门法窍》卷四「占攻贼」「占间谍」「占行诈」「占攻城」「占守城」「占盗贼」「占贼临境否」「占胜败」「占捕盗贼」「占捕亡」「占出兵吉凶」「占剿匪迟速」「占解饷平安」「占监狱平安」「占有无贼窝」等章节，系（飞盘体系）飞盘奇门对军事预测的独特论述。

### 占攻贼（飞盘体系）

以**六庚**旺相得**开门**加中五，其贼可擒；又地盘**天禽**所临之宫得旺相吉门，其贼自败；若休囚废没凶门者，守将不吉。

### 占间谍（飞盘体系）

以**直符**为主者，**丙**为自己，**庚**为仇人。以月将加时与直使所得之干支冲则动，不冲不动；庚旺无益。

### 占行诈（飞盘体系）

以**六丙**为己，**六庚**为敌，**朱雀**为谣。落旺宫六丙克六宫者其术得行，反此不行。

### 占攻城（飞盘体系）

以**六庚**为攻者，**天禽**为守者，以旺相生克决之。

### 占守城（飞盘体系）

以**天禽**为守者，**天蓬**、**六庚**为攻者，以天禽生旺为不破。

### 占盗贼（飞盘体系·来期）

以占其何时去看**六庚**：在内四宫者为不去，在外四宫者为去；以庚之地盘干支年月日时为之来期。

### 占贼临境否（飞盘体系）

以**时支**宫为客，**时干**宫为主，看其生克。

### 占胜败（飞盘体系）

凡战阵以**惊景二门**主之，当以**直符**落宫为主，**六庚**落宫为客，生克决之。

### 占捕盗贼（飞盘体系）

以**元武**、**天蓬**为盗贼，**伤门**为捕人，**时干**为物主，以生克决其难易。

### 占捕亡（飞盘体系）

以**六合**宫为逃亡之人，**伤门**宫为捕者，以生克决之，逢格必获。

### 占出兵吉凶（飞盘体系）

以**日干**落宫为从军之人，**直使**为统军之宫，**元武**为贼，各以生克决之。

### 占剿匪迟速（飞盘体系）

以**元武**落宫为流贼，**直使**之宫为剿贼之官，以生克休囚旺相决之。

### 占解饷平安（飞盘体系）

以**生门**落宫为饷，**天蓬**为贼盗，**直使**为护解之官，以生克决之。

### 占监狱平安（飞盘体系）

以**甲辰**落宫为狱，**开门**为有狱之官，**甲午辛**为罪人，生克决之。

### 占有无贼窝（飞盘体系）

以**天蓬**落宫为贼窝，**日干**为包庇之人，**勾陈**为捕役，生克决之。

## 奇门启悟补充

> 出处：《奇门启悟》第三篇 第十六章 战争、战事预测 — 参见 [[奇门启悟（刘文元）]]

### 理论补充

由于奇门遁甲的起源与战争有关，因此将奇门遁甲数术模式用于预测战争胜负，具有重要的意义。

**核心用神**：
- [[值符（八神）|值符]]落宫 → 守方（被攻击方）
- [[庚（阻隔之神）|庚]]落宫 → 攻方（攻击方）
- [[六合]]落宫 → 联合国安理会
- [[天蓬星]]、庚 → 攻城方
- [[天禽星]]（中五宫）→ 守城方

**胜负判断**：
- 值符宫克庚宫 → 守方胜（攻方难以入侵）
- 庚宫克值符宫 → 攻方胜
- 值符宫与庚宫同宫 → 主客同宫，双方相互对峙，短兵相接
- 旺相者胜，休囚者负

**攻城判断**：
- 以天禽星为守者，天蓬星、六庚为攻者
- 天禽宫得休、生、开、景，又旺相，有六丙 → 其城不破
- 无旺相及吉门，再犯天蓬六庚入中宫 → 该城必守不住

**敌兵来否判断**：
- 以六庚为用神，六庚落内盘主来，落外盘主不來
- [[太白入荧]]主贼兵来，[[荧入太白]]主贼兵去
- 六庚克所落之宫，又逢[[玄武]]、[[天蓬星]]、[[白虎]] → 必有大战
- 庚得[[九天]] → 大张声势鸣鼓而进
- 庚得[[九地]] → 偃旗息鼓而來
- 贼兵已境占何时去：六庚落内盘为不去，落外盘为去
- 以六庚地盘干支年月日时为来去之期

**开战应期判断**：
- 关键看攻方（庚、天蓬星）落宫所对应的节气时间
- 如天蓬星落震宫，震宫对应春分、清明、谷雨，故必待卯月春分点开始之后战争才有可能爆发
- 艮宫（丑、寅）主静，艮宫格局纵凶但庚在艮宫地盘主静不动，且庚在艮宫为入墓，故寅月不能开战
- 震宫与开门所落之兑宫对冲，开门主开始，逢冲必动，故震宫对应的时空点必爆发战争

### 奇门启悟案例1："水兵事件"能否引发美英对伊朗开战

- **时间干支**：丁亥年癸卯月丙寅日己亥时 阳6局（转盘奇门）
- **值符值使**：值符甲午辛[[天英星]]，值使[[景门]]
- **求测背景**：2007年3月23日伊朗海军在海湾水域以非法入侵为由扣押15名英国士兵。英国数度要求释放未果，伊朗态度强硬欲治"间谍罪"。美英调集多艘航母战斗群至海湾，驻海湾美军地面部队增至17万。4月2日晚间21点30分央视《今日关注》播出"水兵事件升级，美军箭已上弦"，北京易友王述达（某部队处级干部）来电问测这场战争哪一天能开战
- **分析**：
  1. **守方伊朗（值符）落兑宫、攻方美英（庚）落巽宫，兑宫克巽宫理论上伊朗主动打击美英，但实际不可能**：值符天英星落兑七宫，兑宫落有生门，格局为辛加己[[入狱自刑]]格（诉讼难伸，凡为主破败，暗地受灾殃，诸事虽然吉祥须先耗费而后有益）。己为时干代表英军水兵，己的本位在兑宫为外盘，而天盘己却落入坎宫（坎为水代表海域），阳遁坎宫为内 → 英军水兵（己）越境进入伊朗水域境内是不争的事实。庚为攻方代表美英军队，今庚乘[[天任星]]落巽四宫，与天禽星同居四宫有联盟之象，上乘玄武，格局为庚加丙[[太白入荧|白入荧]]（占贼贼必来）正应美国增兵行动。
  2. **关键判断——兑宫（伊朗）克巽宫（美英），攻方很难入侵；美英只是想从气势上给伊朗压力并非真想动武，战争肯定打不起来**：代表伊朗的值符天英星落于兑宫，代表美英的攻方庚金乘天任星落于巽宫。兑宫克巽宫，理论上应该是伊朗主动去打击美英军队，但这是不可能的事情。兑为说为辩 → 伊朗方面有充分的说辞能证明英军水兵入侵伊朗海域的事实，使英方（包括美方）陷入理屈词穷的窘境，使英美找不到一个合理的借口进行开战。代表伊朗的值符兑七宫生时干己所落之坎宫 → 伊朗方面最终一定会释放被抓的15名英军士兵。庚乘天任星，任星为艮卦，艮为止，又艮为庚之墓库，巽宫落有玄武 → 美英虽然增兵至海湾地区又开了数艘航母，无非是想在气势上给伊朗以压力，并非想真的动武；况且于2003年开战的伊拉克战争已经使美军深深地陷入泥潭，此时再向伊朗开战对美国必为不利。
  3. **对王述达六爻卦的不同解读——师卦变解卦，师代表兴师动众集兵海湾，变卦解者散也说明即将燃起的战火慢慢消散**：王述达摇得地水师变雷水解卦，认为师卦代表兴师动众、大战前的集兵行动，四爻官鬼丑土临白虎发动大战在即。刘文元则解读：师卦代表美军兴师动众集结兵力屯积于海湾地区，但变卦为解，解者散也，说明即将燃起的战火又慢慢地消散了。现在的海湾局势是只打雷不下雨，美伊之间不会打起来，伊朗也会在近期释放被扣押的15名英军士兵。
- **结果**：4月2日，被伊朗扣押的15名英国海军士兵在伊朗电视台播放的电视画面上都已经承认是非法进入伊朗水域。4月4日，伊朗释放了因非法进入伊朗水域而被扣留的15名英军水兵。在伊朗首都德黑兰，英军水兵在被释放后与媒体见面，伊朗总统艾哈迈迪·内贾德与英军水兵握手并接见了被扣的15名英军水兵。4月5日上午，15名被释放的英军士兵在德黑兰的麦赫拉巴德机场乘坐一架飞机启程返回英国。时至今日（2007年12月1日），美英也没有对伊朗开战。预测完全应验。

### 奇门启悟案例2：预测美英联军何日对伊拉克开战

- **时间干支**：癸未年甲寅月庚午日丙戌时 阳6局（转盘奇门，按央视播出美英联军进入伊拉克境内新闻的时间起局）
- **值符值使**：值符甲申庚[[天任星]]，值使[[生门]]
- **求测背景**：2003年2月26日晚间7点多钟，从央视新闻联播中得知美英等国联军首次进入伊拉克境内，随时有向伊拉克开战的可能。某部队一位姓孙的团长来电问测："美英联军哪一天能够对伊拉克正式开战？我估计三五天之内战争就能打响"
- **分析**：
  1. **主客同宫——美英联军已进入伊拉克境内双方必短兵相接**：于传统奇门中，以值符为主、以六庚落宫为客，以生克决胜负。今值符落巽宫，庚亦落巽宫，是为主客同宫，双方相互对峙之象。庚落巽宫为内，庚为敌兵 → 敌兵（英美联军）已经来到伊拉克境内。巽宫格局为庚加丙[[太白入荧]]（占贼贼必来）→ 英美联军必然要来到伊拉克。值符为守方代表伊拉克，庚为攻打方代表美英等国联军，今值符与庚落同宫 → 双方必短兵相接、近距离作战，也说明攻方（美英联军）十分猖狂竟然进入伊拉克境内。
  2. **联合国安理会不同意美英联军攻打伊拉克**：六合落宫代表联合国安理会。今六合落兑宫，克庚所落之巽四宫 → 联合国安理会并不同意美英联军攻打伊拉克。
  3. **关键判断——美英联军虽已进入伊拉克但战爭并不能马上开战，应于2003年3月21日（春分点）开始算起随时都能开战，在此之前战争打不起来**：传统奇门中以天禽星为守城方，天蓬星、庚为攻城方。今庚落巽宫且临值符，天蓬星落震三宫，均落内盘 → 敌人（美英联军）攻打伊拉克是箭在弦上一触即发。这里取地盘天禽星为守城方代表伊拉克，以天盘庚、天蓬星落宫代表美英等国联军。地盘天禽星位居中五宫上乘乙奇 → 伊拉克方面已经做好充分的应战准备。天蓬星落震三宫，震三宫克中五宫，又震三宫与开门所落之兑宫对冲，开门主开始逢冲必动 → 从理论上讲只有到了震宫所管辖的时空才能冲动开门而开战。震宫所对应的时间为春分、清明、谷雨，故必待卯月春分点开始之后战争才有可能爆发。孙团长及其他来电询问的易友们都不太相信这个预测结果，大都认为近期几天内就能开战。
- **结果**：美英联军进入伊拉克后并没有急于开战，而是连日发动了规模空前的攻心战术，散发了大量传单奉劝伊军不要抵抗缴械投降和美军合作。仅3月17日一天美军就向伊拉克境内散发了140万份劝降传单。终于布希总统没有耐性了，美国东部时间3月19日晚10点15分布什在白宫椭圆形办公室发表电视讲话正式对伊拉克宣战。2003年3月20日美英等国以伊拉克隐藏有大杀伤武器并暗中支持恐怖主义为借口绕开联合国安理会公然单方面决定对伊拉克实施大规模军事打击。实际开战日比预测的3月21日提前了一天，但从历法角度讲地球上不同地方的节气交接时间是有差异的，这便是导致预测应期与实际状况稍有差异的原因所在。

**要点**：刘文元先生在战争预测中的核心创新——（1）以"值符为守方、庚为攻方"的核心判断法，主客同宫则短兵相接近距离作战；（2）以六合落宫代表联合国安理会，其与攻方庚宫的生克判断国际社会对战争的态度；（3）"震宫对应春分点必开战"的节气应期判断法——以攻方落宫所对应的二十四节气时间作为开战应期；（4）"艮宫主静、艮宫庚入墓不能开战"的入墓静止原则；（5）六爻与奇门对比解读的差异——同一师卦变解卦，王述达读"大战在即"，刘文元读"师代表集兵、解代表战火消散"，奇门以值符宫克庚宫为根本依据，更准确；（6）时干（己）落宫可断被扣押人员的实际位置——己本位兑宫外盘但天盘己落坎宫（水、海域）内盘 → 英军水兵越境进入伊朗水域境内是事实。
